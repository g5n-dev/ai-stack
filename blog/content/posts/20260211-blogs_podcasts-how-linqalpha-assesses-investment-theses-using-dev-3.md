### 实践 1：构建结构化的投资论据输入

**说明**:
在使用 Devil's Advocate（唱反调者）模式之前，必须确保输入给大语言模型（LLM）的投资论据是结构化且数据驱动的。仅提供模糊的描述会导致生成的反驳缺乏深度。应将论据拆解为核心假设、市场机会、竞争优势和风险溢价四个维度，并为每个维度提供具体的量化数据（如 TAM、CAGR、毛利率等）。

**实施步骤**:
1. **数据标准化**：建立一个 JSON 或 Markdown 模板，强制要求输入包含“假设”、“数据支撑”、“潜在风险”三个字段。
2. **上下文增强**：在 Prompt 中明确告知模型其角色是“一位持怀疑态度的资深投资人”，并要求其基于输入的财务数据寻找逻辑漏洞。
3. **多源验证**：在输入中包含第三方数据源链接或摘要，以增加论据的可信度。

**注意事项**: 避免在输入中包含过多的情感色彩或营销话术，这会干扰模型对核心逻辑的判断。

### 实践 3：迭代式 Socratic Questioning（苏格拉底式提问）
