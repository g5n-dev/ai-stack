## 核心结论

来源称，Sand.ai 于 11 月 25 日发布音视频统一模型 MAGI-2。旗舰版采用 MagiMoE 混合专家架构，总参数量 480B，预训练使用约 4 万亿 tokens，单次推理每个 token 激活约 28B 参数。

官方及合作渠道的 1080p API 定价为每秒 0.5 元人民币，海外渠道约为每秒 0.08 美元。模型支持单次生成 4—30 秒、1080p、25fps 视频，并联合生成画面、对白口型、动作音效和环境声。

需要注意，480B 旗舰版全量权重在发布时尚未开放下载；已经以 Apache 2.0 协议开源的是 114B 的 MAGI-2-preview。旗舰版主要通过官方及合作平台提供托管 API，全量权重仍属于后续开放计划。

## 能力机制

MAGI-2 的计算成本设计来自“大总参数、小激活”的 MoE 路线：480B 参数用于承载模型容量，单个 token 仅激活约 28B，以降低推理阶段的计算量。该机制可以解释其低价策略，但不能据此推导所有部署环境都能达到相同速度。

视频生成能力方面，模型支持 6 种主流画幅。单次请求最多可混用 20 份参考素材，包括 10 张图片、5 段视频和 5 段音频，用于维持角色一致性、动作节奏及声场风格。

音视频在同一基座中联合生成，改变了视频生成后再分别制作配音、拟音、背景音乐并手动对齐口型的传统流程。来源将其概括为减少部分后期环节，但实际项目中的成片效果仍需自行验证。

在 Artificial Analysis Video Arena v2.1 的图生带音频视频维度，来源记录 MAGI-2 得分约 1165 Elo，与 Seedance 2.5 并列榜首。

## 快速开始

以下是基于来源可确认事实的试用流程，不包含未经来源给出的接口命令或参数：

1. 通过官方或 Higgsfield、Kie.ai、Pollo AI 等托管渠道申请 MAGI-2 API。
2. 按每秒 0.5 元人民币的国内渠道价格准备测试预算，并确认实际计费口径。
3. 从 4—30 秒、1080p、25fps 的支持范围内选择测试规格。
4. 根据需要配置图片、视频和音频参考素材，单次总数不超过 20 份。
5. 记录抽卡次数、可用镜头成本、对白口型同步情况及后期处理量。
6. API 密钥应通过环境变量注入；来源没有提供接口地址、SDK 或环境变量名称，因此不列出示例命令和密钥值。

若按每秒 0.5 元估算，单次抽取 3—5 次时，对应生成成本为每秒 1.5—2.5 元。来源认为这适合用于 AI 短剧、广告素材和自媒体短片的前期试错。

## 适用边界

来源事实显示，114B 预览版权重仓库约 307GB，标准推理配置通常需要 8 张 Hopper GPU 或 4 卡驻留节点。480B 规模即使只激活约 28B 参数，仍涉及显著的显存和通信开销，不适合按消费级单卡或双卡本地部署估算。

预览版还依赖上游大语言模型将简短提示词扩展为结构化长描述，并与提示词工程、底层路由和定制注意力机制耦合。接入 ComfyUI 等本地创作管线仍需等待社区插件和封装成熟。

工程建议是：先使用托管 API 测试出片率、角色一致性、口型同步和单位可用镜头成本；待 480B 权重正式上传、社区量化或蒸馏方案稳定后，再评估自建集群。低价 API 也不等同于私有化部署，也不代表所有素材或推理数据都不会离开所选服务环境，相关数据处理边界仍应以供应商条款为准。

## 核验清单

- 核验当前提供的是 114B 预览版还是 480B 旗舰版，避免混淆开放状态。
- 核验 480B 全量权重是否已进入官方仓库，并记录实际许可证与下载时间。
- 核验 API 的分辨率、帧率、时长、画幅及参考素材数量限制。
- 核验每秒 0.5 元人民币是否为 1080p 国内渠道价格，并确认海外渠道计价方式。
- 核验不同渠道的实际生成成功率、失败计费及是否支持音频输出。
- 对同一提示词进行多次测试，分别记录抽卡次数和可入片成本。
- 抽查角色一致性、动作连续性、对白口型及环境声效果。
- 评估从 114B 到 480B 的显存、通信和运维要求，不以 28B 激活量代替完整部署资源需求。
- 本地接入前确认社区插件、量化模型、路由组件及依赖模型的可用状态。
