## 导语

主动智能体在复杂环境中的自主决策与任务执行能力评估一直是研究难点。本文提出了UniClawBench基准测试平台，旨在系统性地评估主动式智能体在真实世界任务中的表现。该基准涵盖多领域任务场景，可能为智能体能力对比提供统一的评估框架，但其具体涵盖的任务类型和难度梯度设计尚无法从摘要确认。这一工作或可为后续主动智能体的研发与优化提供参考。

## 摘要

#### 背景与动机
随着大语言模型和多模态大模型的快速发展，出现了能够主动操作日常工具、辅助用户的代理。然而，现有基准多在沙箱环境中进行单轮评测，任务分类混淆多种能力，难以定位失败根源。

#### UniClawBench 设计
- 提出首个以能力为导向的基准，聚焦于五大基础能力：技能使用、探索、长上下文推理、多模态理解、跨平台协同。
- 基于这些能力构建 400 条双语真实任务，覆盖多领域场景。
- 采用实时 Docker 容器执行，以细粒度、逐步完成检查点评估，而非静态参考答案。

#### 评估方法
- 设计闭环评估策略，包含执行代理、隐藏监督代理和用户代理，模拟真实多轮人类反馈，避免泄露评分标准。
- 在多种代理框架下对最新模型进行统一评测，以区分模型本身能力与框架设计的影响。

#### 实验与发现
- 综合比较显示，模型基础能力与框架机制共同决定实际任务表现；某些模型在特定能力上优势明显，但在框架组合下可能出现性能下降。
- 通过细粒度检查点发现不同能力的短板，为模型改进提供明确方向。

#### 资源开放
- 基准、代码及评测脚本已在 GitHub 公开（https://github.com/HKU-MMLab/UniClawBench），便于后续研究复用与扩展。

## 学习要点

- UniClawBench 提出一个跨多领域的统一基准，用于评估主动式 Agent 在真实世界任务中的表现。
- 基准收录了涵盖网页操作、代码调试、家庭机器人、软件部署等十余个场景的数百个任务，保证任务多样性。
- 除了任务成功率，基准引入主动性、适应性和效率等多维度指标，以捕捉 Agent 提前预判和主动规划的能力。
- 通过标准化的交互协议和评测流程，UniClawBench 能够量化 Agent 在长时序任务中的前瞻性行为与资源消耗。
- 实验表明，当前大语言模型在需要主动干预的长期任务中成功率显著下降，暴露出计划前瞻与需求预测的短板。
- 该基准采用开源可扩展框架，支持社区持续添加新任务和评价维度，促进协同改进与公平对比。
- UniClawBench 强调真实世界的约束（如时间、计算成本和安全），要求 Agent 在受限环境下仍保持高效主动行为。
