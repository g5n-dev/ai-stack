## 摘要

UniClawBench 是首个面向主动 Agent 的能力驱动基准，旨在评估模型在真实动态环境中的任务完成能力。基准围绕五项核心能力构建：技能使用、探索、长上下文推理、多模态理解和跨平台协同，并基于此设计了 400 条双语真实任务。评估在活的 Docker 容器中进行，以细粒度的步骤完成检查点替代静态答案，确保评测的真实性。为防止评分信息泄漏，基准采用闭环评估策略：执行 Agent、隐藏的监督 Agent 与用户 Agent 协同模拟多轮人类反馈。作者在多种 Agent 框架下对前沿模型进行系统对比，揭示模型基础能力与框架设计共同决定实际表现。基准及代码已在 GitHub 开源（https://github.com/HKU-MMLab/UniClawBench）。
