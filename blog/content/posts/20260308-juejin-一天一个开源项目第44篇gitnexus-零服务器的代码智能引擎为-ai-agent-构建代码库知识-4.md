## 摘要

**GitNexus：零服务器代码智能引擎，为 AI Agent 构建代码库知识图谱**

**一、 项目概述**
GitNexus 是一款创新的“零服务器”代码智能引擎，旨在为 AI Agent（如 Cursor、Claude Code、Windsurf 等）提供深度代码库理解能力。它通过在浏览器端构建代码知识图谱，实现了代码分析的本地化与智能化。

**二、 核心特点**
1.  **零服务器架构**：GitNexus 完全在浏览器中运行，无需后端服务器支持，数据不上传云端，保障了本地数据的安全性与隐私。
2.  **知识图谱构建**：通过分析代码库结构，自动生成代码知识图谱，清晰展示文件、函数、类之间的依赖关系。
3.  **AI Agent 集成**：通过 MCP 协议（Model Context Protocol）与主流 AI 编程工具无缝对接，为 AI 提供结构化的代码上下文。
4.  **轻量高效**：利用浏览器本地计算能力，快速完成代码库索引与分析，响应迅速。

**三、 核心功能**
1.  **代码可视化**：以图谱形式直观展示代码库结构，帮助开发者快速理解项目架构。
2.  **智能上下文提供**：为 AI Agent 提供精准的代码上下文信息，提升 AI 辅助编程的准确性与效率。
3.  **本地化运行**：所有数据处理均在本地完成，避免云端依赖，降低使用成本。

**四、 应用场景**
1.  **AI 辅助编程增强**：通过为 Cursor、Claude Code 等工具提供深度代码上下文，显著提升 AI 代码生成与重构的质量。
2.  **代码库快速理解**：帮助新加入的开发者快速熟悉项目结构，降低学习成本。
3.  **隐私敏感项目**：适合对数据隐私要求较高的场景，确保代码数据不外泄。

**五、 技术亮点**
1.  **MCP 协议支持**：采用标准化协议与 AI Agent 通信，兼容性强，易于扩展。
2.  **浏览器原生能力**：充分利用现代浏览器的计算资源，实现高性能的本地化处理。
3.  **开源生态**：作为开源项目，GitNexus 鼓励社区参与，持续优化功能并扩展兼容性。

**支撑理由与评价**

**1. 架构范式的迁移：从云端 RAG 向端侧图谱的进化**
*   **事实陈述**：文章指出 GitNexus 采用“零服务器”架构，依赖浏览器本地算力构建代码图谱。
*   **深度分析**：这触及了当前 AI 辅助编程的核心痛点——**隐私与上下文成本的矛盾**。传统的云端 RAG（检索增强生成）需要上传代码，存在企业 IP 泄露风险，且受限于 LLM 的上下文窗口。GitNexus 将计算下沉到客户端（Edge），利用 WebAssembly 或 WASM 加速的图算法在本地处理数据，仅输出结构化的图谱数据给 AI。这是一种“**数据不动，模型动**”的逆向思维，符合当前“端侧 AI”的行业趋势。
*   **反例/边界条件**：浏览器内存堆栈限制是硬伤。当处理像 monorepo（如 Chromium 或 Android 源码）级别的超大规模代码库时，基于浏览器的 Tab 极易崩溃。此时，本地二进制程序（如基于 Rust/Go 编写的本地 Server）反而比 Web App 更具可行性。

**2. MCP 协议的生态位：打破 AI IDE 的孤岛效应**
*   **事实陈述**：文章强调通过 MCP (Model Context Protocol) 连接 Cursor、Windsurf 等 IDE。
