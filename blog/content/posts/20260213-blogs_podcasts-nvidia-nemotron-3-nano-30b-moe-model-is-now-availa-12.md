## 2. 关键技术要点

**涉及的关键技术或概念**
*   **混合专家模型：** 这是该模型的核心架构。它不是激活所有 30B 参数，而是根据输入内容动态选择相关的子网络进行计算。
*   **稀疏激活：** 在推理过程中，只有部分参数被激活。这里的“3B active parameters”是关键，意味着每次推理的计算量仅相当于一个 3B 的稠密模型。
*   **Amazon SageMaker JumpStart：** AWS 提供的机器学习中心，提供预训练模型、算法和解决方案，旨在实现“一键部署”。

**技术原理和实现方式**
*   **门控网络：** MoE 模型包含一个门控机制，负责将输入 Token 分发给最合适的“专家”子模型。
*   **计算卸载与优化：** 模型在 AWS 上的部署通常利用 NVIDIA 的优化栈（如 TensorRT-LLM 或 Triton 推理服务器），以最大化 GPU 利用率并减少显存占用。

**技术难点和解决方案**
*   **难点：** MoE 模型虽然推理计算量少了，但对显存带宽要求极高（需要加载所有 30B 参数到显存，尽管只计算 3B），且在分布式部署时存在通信开销。
*   **解决方案：** NVIDIA 和 AWS 通过高度优化的底层驱动和容器化部署，解决了 MoE 在云端 GPU 实例上的调度问题，确保了低延迟。

**技术创新点分析**
**“Nano”前缀与“30B”规格的结合**是最大的创新点。通常 Nano 指极小模型，而 30B 属于中等偏大模型。这种命名强调了其“**大模型能力，小模型成本**”的特性。
