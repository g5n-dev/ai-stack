## 2. 关键技术要点

### 涉及的关键技术或概念
1.  **纯 Python 实现的 Autograd (自动微分引擎)**：这是整个项目的灵魂。通常我们依赖 PyTorch/TensorFlow 自动计算梯度，但 `microgpt` 手写了一个基于计算图的微分级系统。
2.  **Byte-Pair Encoding (BPE) 变体**：一个极简的分词器，将文本转换为整数序列，这是模型理解语言的基础。
3.  **Transformer 架构 (GPT-2 风格)**：包含多头自注意力机制和层归一化。
4.  **反向传播**：利用链式法则手动更新神经网络参数。

### 技术原理和实现方式
- **Autograd 引擎**：通过构建一个 `Value` 类，包装标量值，并记录参与运算的子节点（构建计算图）。在反向传播时，通过拓扑排序从输出节点回溯，利用链式法则计算每个节点的梯度。
- **矩阵运算**：由于没有依赖 NumPy，项目可能使用 Python 原生列表或极其简化的矩阵类来实现线性变换，这虽然效率极低，但直观展示了矩阵乘法在神经网络中的作用。
- **训练循环**：标准的“前向传播 -> 计算损失 -> 反向传播 -> 参数更新”流程，全部在一个简单的循环中完成。

### 技术难点和解决方案
- **难点**：在无依赖库的情况下实现高效的矩阵运算和梯度计算。
- **解决方案**：作者牺牲了性能，选择了**纯标量运算**或**极度简化的列表操作**。虽然训练速度极慢，但这规避了复杂的 C++ 扩展依赖，保证了代码的便携性和可读性。

### 技术创新点分析
- **教育性工程**：这不是为了生产环境设计的代码，而是为了“人脑编译器”设计的代码。它的创新在于将复杂的数学概念映射为最直观的代码结构，使得阅读者能够像阅读伪代码一样阅读实际可运行的程序。
