## 摘要

SkillOpt 将技能视为冻结智能体的外部状态，采用类似权重空间优化的可重复训练范式，实现对技能的系统化、可控文本空间优化。系统采用独立的优化模型，将得分rollout转化为对单个技能文档的有界增/删/替换编辑，仅在验证集得分严格提升时接受编辑。为保证训练稳定，引入了文本学习率预算、被拒绝编辑缓冲区以及逐轮慢/元更新，且在部署时无需额外的模型调用。

在六项基准、七种目标模型和三种执行环境（直接聊天、Codex、Claude Code）上，SkillOpt 在全部 52 个（模型、基准、执行环境）评测单元中均取得最佳或并列最佳成绩，显著超越人类、一次性大模型、Trace2Skill、TextGrad、GEPA、EvoSkill 等对手。以 GPT‑5.5 为例，SkillOpt 在直接聊天中将平均无技能准确率提升 +23.5 分，在 Codex 代理循环中提升 +24.8 分，在 Claude Code 中提升 +19.1 分。迁移实验进一步表明，优化后的技能可在不同模型规模之间、在 Codex 与 Claude Code 环境之间以及向邻近数学基准迁移时保持效用，无需进一步优化。

评论推断，SkillOpt 的核心假设是：技能文档的局部编辑能够带来可预测的性能提升，且优化过程可收敛。这一假设在以下条件下可能失效：第一，技能文档内部存在强耦合性，有界编辑可能触发级联效应；第二，验证集与真实部署环境存在分布偏移，导致“严格提升”不等于“泛化提升”；第三，文本学习率预算的设计假设编辑粒度与性能增益呈单调关系，但实际可能存在非凸景观。

## 技术分析

#### 研究背景

SkillOpt的研究聚焦于大型语言模型（LLM）智能体的技能优化问题。传统方法通常将技能直接嵌入模型权重，这意味着每次技能更新都需要昂贵的模型微调。摘要中明确指出，SkillOpt将技能视为“冻结智能体的外部状态”，这一设计选择使得技能可以独立于基础模型进行管理和优化。从可确认的事实来看，这种“外部化”思路为技能的可复用性和跨模型迁移提供了结构基础。笔者的推断是，这一设计理念借鉴了强化学习中策略与执行器分离的思想，旨在解决企业级应用中技能库的维护难题。

#### 核心方法

SkillOpt的核心机制包含两个关键创新点。首先，它将技能文档视为可编辑的“文本权重”，采用类似神经网络权重优化的训练范式，但操作空间从数值向量转换为自然语言文本。其次，优化过程采用独立的“优化模型”，专门负责将得分rollout的结果转化为对技能文档的有界增、删、替换编辑操作。这一机制确保了编辑空间的受限性，避免了自由文本生成可能带来的质量退化。

从摘要可确认的是，系统仅在验证集得分严格提升时才接受编辑，这一“严格提升”策略有效防止了噪声扰动导致的性能波动。此外，为保证训练稳定性引入的三项机制——文本学习率预算、被拒绝编辑缓冲区以及逐轮慢/元更新——共同构成了一个多层次的稳定化框架。文本学习率预算限制了单次编辑的影响范围，被拒绝编辑缓冲区保留了有潜力但暂未被接受的编辑候选，而慢/元更新则通过延迟和嵌套更新的方式平滑优化轨迹。部署时无需额外模型调用这一特性表明，优化过程是离线完成的，最终产物是可直接使用的技能文档。

#### 理论基础

SkillOpt的理论根基可追溯至两方面的交叉领域。其一是元学习（meta-learning）中的“学习如何学习”思想，逐轮慢更新机制与MAML（Model-Agnostic Meta-Learning）的思想存在相似性，只是将参数更新替换为文本编辑。其二是程序合成领域中的有界搜索思想，有界增删替换操作等价于在有限的语法空间中枚举候选解。从推断角度看，SkillOpt的独特贡献在于将这两个领域的成熟思想首次系统性地迁移到了自然语言技能优化这一新场景。

#### 实验与结果

实验设计覆盖了六项基准、七种目标模型和三种执行环境（直接聊天、Codex、Claude Code），形成52个评测单元的完整矩阵。从摘要数据可知，SkillOpt在全部评测单元中均取得最佳或并列最佳成绩，这一全面领先的结果具有较强的说服力。GPT-5.5的具体提升数据——直接聊天+23.5分、Codex代理循环+24.8分、Claude Code +19.1分——表明优化效果在不同执行环境中具有一致性。

迁移实验结果进一步验证了技能的泛化能力：优化后的技能可在不同模型规模之间、在Codex与Claude Code环境之间以及向邻近数学基准迁移时保持效用。这一发现暗示，经过SkillOpt优化的技能可能捕捉到了任务的结构性规律，而非特定模型或环境的表面特征。

SkillOpt显著超越了人类、一次性大模型以及一系列专门方法（包括Trace2Skill、TextGrad、GEPA、EvoSkill等）的表现。从可确认的事实来看，这些对手方法涵盖了从直接提示优化到基于梯度的文本优化等多个技术路线，SkillOpt的全面胜出表明其“文本权重优化+严格验证”范式具有更强的竞争力。

#### 应用前景

SkillOpt的技术特性使其在企业智能助手自动化调优、跨平台任务执行脚本库构建、以及领域专用技能快速适配等场景具有应用潜力。特别是其“一次优化、多处部署”的迁移能力，可以显著降低技能开发成本。然而，从推断角度，这一应用前景的实现还需要解决技能文档的可解释性、版本管理以及权限控制等工程问题。

#### 研究启示与潜在局限

SkillOpt的成功揭示了一个重要洞察：将AI系统的“知识”从隐式参数空间迁移到显式文本空间，不仅可行，而且可能具有更好的可控性和可复用性。这一方向值得进一步探索。然而，从推断角度，SkillOpt的潜在失效条件包括：当任务需要高度领域专一的推理模式时，简单文本编辑可能无法捕获；当优化模型的文本生成能力成为瓶颈时，技能质量的提升将受限。可证伪的方式是设计需要复杂推理的基准，验证技能优化是否仍然有效。
