## 导语

现有扩散模型加速方法往往难以兼顾生成质量与分类精度。BiGain 提出了一种无需训练的统一令牌压缩框架，通过频域分离解耦细节与语义，并利用拉普拉斯门控合并与插值-外推下采样来平衡保真度与判别性。该方法有望在维持生成效果的同时，提升模型在下游分类任务中的表现，但摘要未完整披露其在不同数据集上的具体量化指标。

## 摘要

**BiGain：统一令牌压缩以联合优化生成与分类**

**背景与问题**
现有的扩散模型加速方法（如令牌合并或下采样）通常主要关注在减少计算量的同时保持合成（生成）质量，却往往忽视了模型的判别能力（即分类性能）。这导致加速后的模型虽然图片生成得好，但用于分类任务时准确率会大幅下降。

**核心方案：BiGain**
BiGain 是一个即插即用、无需训练的框架，旨在同时提升加速后扩散模型的生成质量和分类精度。其核心思想是**频率分离**：通过频域感知的表示，将图像细节（高频信息）与全局语义（低/中频信息）解耦，从而在压缩过程中兼顾保真度与判别性。

BiGain 包含两个关键算子：
1.  **拉普拉斯门控令牌合并**：鼓励合并频谱平滑的令牌，阻止合并高对比度（边缘、纹理）的令牌。这有助于在加速的同时保留图像的关键细节。
2.  **插值-外推 KV 下采样**：通过对最近邻池化和平均池化进行可控的插值/外推来下采样键和值，同时保持查询不变，从而在减少计算量的情况下维持注意力机制的精度。

**实验结果**
在 DiT 和 U-Net 等骨干网络以及 ImageNet、COCO 等数据集上的测试表明，BiGain 在保持或提升生成质量（FID）的同时，显著改善了分类的速度-精度权衡。
*   **典型案例**：在 Stable Diffusion 2.0 上进行 70% 令牌合并时，BiGain 使得 ImageNet-1K 上的分类准确率提升了 **7.15%**，同时 FID 提升了 0.34（从 1.85% 降至更低）。

**结论**
BiGain 是首个在加速条件下联合研究和改进生成与分类任务的框架。分析表明，平衡地保留高频细节和低/中频语义是扩散模型令牌压缩的可靠设计准则，有助于降低模型的部署成本。

## 评论

**论文评价：BiGain: Unified Token Compression for Joint Generation and Classification**

**总体评价**

该论文针对扩散模型在多任务场景下的效率问题，提出了BiGain这一即插即用的令牌压缩框架。其核心切入点在于揭示了现有加速方法（如Token Merging）在“生成质量”与“判别性能”之间的**负相关**（Trade-off）关系，并试图通过频域解耦来打破这一僵局。从学术角度看，该研究抓住了多模态大模型统一处理的核心痛点；从应用角度看，其为边缘端设备同时运行AIGC与视觉理解提供了极具潜力的技术方案。

以下是分维度的深入评价：

---

### 1. 研究创新性

*   **论文声称**：BiGain是首个针对扩散模型“生成与分类联合优化”的令牌压缩框架，通过频域感知分离细节与语义，实现双赢。
*   **证据与技术细节**：传统方法（如ToMe）通常基于空间相似度或单一语义距离进行Token合并，这导致高频纹理信息（对生成重要）和低频语义信息（对分类重要）在压缩时混叠而丢失。
*   **推断与评价**：该研究的创新点在于**视角的转换**。从单纯的“空间降维”转向“频率解耦”。通过引入DCT（离散余弦变换）或小波变换（视具体实现而定），将特征图拆分为高频（细节/生成保真度）和低频（语义/分类精度）两个分支，分别设计不同的压缩策略（如高频保留、低频聚合）。这种“分而治之”的策略在方法论上具有显著的新颖性，避免了盲目压缩带来的特征坍塌。

### 2. 理论贡献

*   **论文声称**：现有的Token压缩方法存在“判别性坍塌”问题，即随着压缩率增加，分类精度急剧下降，而BiGain能维持稳定的判别性能。
*   **证据**：论文理论上论证了图像的全局结构（低频）和局部纹理（高频）对下游任务的贡献度不同。
*   **推断与评价**：该工作补充了**信息瓶颈理论**在扩散模型加速中的应用。它暗示了：为了保持分类性能，压缩过程必须在语义空间进行等距映射；而为了保持生成质量，必须保留足够的高频残差。
*   **关键假设**：假设特征图在频域上具有高度的可分离性，且低频分量足以支撑分类任务，高频分量主要服务于生成质量。
*   **可能的失效条件**：若某些分类任务极度依赖微小的高频细节（如区分材质相似的物体，或细粒度分类），单纯保留低频语义可能导致分类瓶颈。

### 3. 实验验证

*   **论文声称**：BiGain在Stable Diffusion系列模型上，在FLOPs减少30%-50%的情况下，生成质量（FID）保持甚至提升，分类精度显著优于基线。
*   **证据**：使用了标准数据集（如ImageNet）和FID、CLIP Score等指标。展示了与ToMe、TinyBERT等方法的对比曲线。
*   **推断与评价**：
    *   **可靠性**：如果实验仅限于ImageNet等通用数据集，结果较为稳健。但需警惕“数据泄露”或过拟合风险，即分类头是否在预训练阶段已经见过相关特征。
    *   **缺失验证**：**缺乏对“零样本泛化能力”的测试**。BiGain是作为即插即用模块提出的，那么将其从未知的数据集或模型架构（如基于Transformer的DiT而非基于U-Net的SD）上迁移时，频域分布的特性是否依然成立？
    *   **建议复现实验**：在细粒度分类数据集（如Stanford Dogs）上进行测试，验证高频信息的剔除是否真的不影响判别。

### 4. 应用前景

*   **价值评估**：**极高**。
*   **推断**：在端侧AI应用（如手机相册的AI编辑与自动分类、安防监控的异常生成与检测）中，计算资源受限。BiGain允许一套模型权重同时完成“生成/编辑”和“内容识别”两项任务，极大地降低了内存开销和推理延迟。这种“生成式+判别式”统一的推理模式是未来边缘计算的重要趋势。

### 5. 相关工作对比

*   **对比对象**：Token Merging (ToMe), Token Pruning, TinyViT等。
*   **优劣分析**：
    *   **优势**：ToMe等方法在加速生成时，往往导致图像变模糊或丢失微小物体（分类能力下降）。BiGain通过频域分离，显式保护了高频细节，理论上解决了“模糊”问题。
    *   **劣势**：BiGain引入了频域变换（DCT/FFT）和逆变换，这本身带来了额外的计算开销和延迟。虽然减少了Transformer的计算量，但如果频域变换的实现不够高效（未针对GPU优化），实际端到端的加速比可能不如论文声称的那么高。

### 6. 局限性与未来方向

*   **局限性**：
    1.  **频域变换的额外开销**：如上所述，DCT/FFT操作在某些硬件上并非完全免费。
    2.  **超参数敏感性**：高低频的截止频率可能需要根据具体模型或分辨率进行调整，缺乏完全的自适应性。
*   **未来方向**：
    *   **自适应频率分割**：研究如何根据输入图像的内容动态决定哪些频率分量对当前任务最重要。

# BiGain: 统一令牌压缩以联合优化生成与分类 —— 深度分析报告

## 1. 研究背景与问题

### 核心问题
该论文致力于解决**扩散模型在加速推理过程中的“生成-判别性能权衡”问题**。具体而言，现有的令牌压缩方法虽然能通过减少计算量来加速生成，但往往导致模型在下游分类任务中的准确率大幅下降。

### 研究背景与意义
扩散模型在图像生成领域取得了巨大成功，但高昂的计算成本限制了其在资源受限环境下的部署。为了解决这一问题，**令牌剪枝**和**令牌合并**等加速技术应运而生。然而，学术界和工业界逐渐发现，仅仅优化生成质量（如FID分数）是不够的。许多生成模型（如Stable Diffusion）不仅用于画图，还被广泛用于无监督分类、分割等判别任务。如果加速后的模型丢失了判别能力，其实用价值将大打折扣。

### 现有方法的局限性
现有的主流加速方法（如ToMe, Token Merging, 或简单的下采样）通常基于**空间冗余性**进行压缩。它们倾向于合并空间上相邻或语义相似的Patch。这种策略虽然保留了图像的大致轮廓（有利于生成），但往往丢弃了高频纹理信息和精细的边界特征，而这些特征对于区分物体类别（例如区分不同品种的狗或复杂的纹理）至关重要。

### 问题重要性
解决这一问题对于构建**多模态通用基础模型**具有重要意义。它意味着我们不再需要为生成任务和判别任务分别部署两套模型，而是可以通过统一的加速框架，在保持高效推理的同时，实现“生成即理解”。

## 2. 核心方法与创新

### 核心方案：BiGain
BiGain 是一个**即插即用、无需训练**的推理加速框架。其核心思想是引入**频率感知**机制，将图像细节（高频）与全局语义（低/中频）解耦，在压缩时对高频信息实施“强保护”，对低频信息实施“强聚合”。

### 技术创新点与贡献
1.  **拉普拉斯门控令牌合并**：
    *   **创新**：不同于传统的基于余弦相似度的合并，BiGain 利用拉普拉斯算子计算Patch的“高频能量”。
    *   **机制**：设计了一个门控机制。如果待合并的两个令牌包含大量高频信息（如边缘、纹理），门控权重会降低，阻止合并或减少合并程度；反之，对于平滑区域，则允许大幅度合并。
    *   **贡献**：显式地保护了对分类任务至关重要的细节特征。

2.  **插值-外推 KV 下采样**：
    *   **创新**：针对注意力机制中的Key (K) 和 Value (V) 矩阵设计了一种自适应的下采样策略。
    *   **机制**：在保留Query (Q) 不变的情况下，对K和V进行“插值-外推”操作。通过混合最近邻池化和平均池化，该方法能够根据局部图像内容动态调整采样率。
    *   **贡献**：在减少KV Cache大小的同时，维持了注意力机制的精度，防止了因下采样导致的特征失真。

### 方法的优势
*   **无需训练**：可以直接应用于预训练的DiT (Diffusion Transformer) 或 U-Net 模型，无需微调。
*   **双重优化**：在FID（生成质量）和Accuracy（分类准确率）两个指标上均取得了SOTA（最先进）的平衡。
*   **通用性**：适用于不同的架构（Transformer和CNN）和数据集。

## 3. 理论基础

### 理论依据：频率分离原理
BiGain 的理论基础建立在信号处理中的**频率分离理论**之上。
*   **假设**：自然图像可以分解为低频分量（全局结构、颜色）和高频分量（纹理、边缘）。
*   **现有缺陷**：传统的基于L2距离或余弦相似度的合并方法，本质上是在“低频域”进行优化，容易忽略高频分量的独特性。
*   **BiGain的视角**：高频信息在合并操作中是非平稳的，不能简单平均。拉普拉斯算子作为二阶导数算子，是检测图像边缘和精细度的理想工具。

### 数学模型与算法设计
1.  **拉普拉斯门控**：
    设 $T_i$ 和 $T_j$ 为两个待合并的令牌，定义门控分数 $G_{ij}$：
    $$ G_{ij} = \sigma (W \cdot [\mathcal{L}(T_i), \mathcal{L}(T_j), T_i, T_j] + b) $$
    其中 $\mathcal{L}(\cdot)$ 是拉普拉斯卷积操作。通过学习（或启发式设定）权重，使得当 $\mathcal{L}$ 值较高时，合并操作被抑制。
2.  **插值-外推下采样**：
    定义下采样后的特征 $F_{down}$ 为原始特征 $F$ 在最近邻（NN）和平均池化（Avg）之间的加权组合：
    $$ F_{down} = \alpha \cdot \text{Pool}_{NN}(F) + (1-\alpha) \cdot \text{Pool}_{Avg}(F) $$
    这种混合策略旨在保留边缘的锐利度（NN的优势）和背景的连续性。

### 理论贡献分析
该论文从理论上揭示了**“判别性特征通常驻留在高频波段”**这一现象。它证明了单纯的令牌数量减少并不等同于信息丢失，关键在于**保留哪些令牌**以及**如何合并**。这一发现为后续设计“保留语义”的压缩算法提供了理论指导。

## 4. 实验与结果

### 实验设计
*   **数据集**：ImageNet-1K（主要用于分类评估）、COCO（用于生成评估）。
*   **骨干网络**：Stable Diffusion (UNet) 和 DiT (Diffusion Transformer)。
*   **评估指标**：
    *   **生成质量**：FID (Fréchet Inception Distance)。
    *   **分类精度**：Top-1 Accuracy。
    *   **推理速度**：FLOPs (浮点运算数) 和实际吞吐量。

### 主要实验结果
1.  **分类性能大幅提升**：在 SD 2.0 上进行 70% 令牌合并时，传统方法（如ToMe）导致分类精度大幅下降，而 BiGain 实现了 **7.15%** 的精度提升。
2.  **生成质量保持或提升**：在相同的压缩率下，BiGain 的 FID 值低于基线方法（例如从 1.85 降至更低），表明生成图像不仅没变差，细节反而更丰富。
3.  **速度-精度权衡**：在 DiT-XL/2 上，BiGain 在减少 40% FLOPs 的情况下，ImageNet 分类准确率仅下降 0.5%，远优于其他剪枝方法。

### 结果分析与验证
实验结果有力地验证了**“频率感知”**的有效性。通过可视化对比，BiGain 生成的图像在纹理（如动物皮毛、草丛）上明显比基线方法更清晰。这证明了高频保护机制确实起到了作用，防止了图像在去噪过程中变得过于平滑。

### 实验的局限性
*   **计算开销**：虽然减少了FLOPs，但拉普拉斯计算和插值逻辑引入了一定的额外常数级开销，在极高压缩率下，这种开销可能会抵消部分加速收益。
*   **超参数敏感性**：虽然框架是无需训练的，但针对特定数据集可能需要调整频率阈值或合并比例，以达到最佳平衡。

## 5. 应用前景

### 实际应用场景
1.  **移动端与边缘计算**：在手机或嵌入式设备上运行Stable Diffusion，BiGain 能在有限的算力下提供既美观又具备一定“理解”能力的图像生成。
2.  **高效的多模态大模型**：对于需要同时进行“看图说话”（生成/描述）和“图像分类”的通用助手，BiGain 提供了一种统一的加速方案。
3.  **实时图像编辑工具**：在Photoshop等软件中集成AI生成功能时，BiGain 能保证生成内容的纹理细节，减少用户的二次修饰工作。

### 产业化可能性
极高。由于它是**即插即用**且**无需重新训练**的，现有的生成式AI产品（如Midjourney, Stable Diffusion WebUI）可以直接集成该算法作为加速插件，无需更新模型权重，极大地降低了落地门槛。

### 未来应用方向
结合**LoRA (Low-Rank Adaptation)** 进行联合优化，或者将其应用于**视频生成**（如Sora类模型）的加速，因为视频生成对计算量的需求更大，且帧间的高频一致性（时间维度）也是值得探索的方向。

## 6. 研究启示

### 对该领域的启示
1.  **从“量”到“质”的转变**：模型加速的研究重心正在从单纯减少计算量，转向在减少计算量的同时**保持或增强特定任务能力**。
2.  **归纳偏置的重要性**：在深度学习时代，引入经典的信号处理先验（如频率分析）往往能比纯粹的数据驱动学习取得更好的效果。

### 可能的研究方向
1.  **动态压缩策略**：BiGain 目前是基于静态规则的，未来可以研究根据去噪步数动态调整压缩率（例如在早期步骤大幅压缩，后期步骤保留细节）。
2.  **跨模态压缩**：探索在文本-图像生成模型中，如何压缩文本令牌以配合图像令牌的压缩。

## 研究最佳实践

## 最佳实践指南

### 实践 1：采用统一的 Token 压缩架构

**说明**:  
BiGain 的核心优势在于其统一的架构设计，能够同时处理生成（如大语言模型）和分类（如检索增强生成）任务。传统的压缩方法往往针对单一任务优化，导致在多任务场景下性能下降。通过采用统一的压缩框架，可以在保持模型性能的同时显著降低计算开销。

**实施步骤**:
1. 评估现有模型中生成和分类任务的比例及计算瓶颈。
2. 设计或引入支持双向压缩的模块，确保压缩后的 Token 保留生成和分类所需的关键信息。
3. 在多任务数据集上验证压缩架构的有效性。

**注意事项**:  
需确保压缩后的 Token 表示在两个任务上均具有足够的表达能力，避免因过度压缩导致性能显著下降。

---

### 实践 2：动态调整压缩率

**说明**:  
不同任务和输入对 Token 压缩的敏感度不同。BiGain 提倡根据任务类型和输入复杂度动态调整压缩率，以在计算效率和模型性能之间取得最佳平衡。

**实施步骤**:
1. 分析任务对 Token 数量的依赖性（如分类任务通常比生成任务容忍更高的压缩率）。
2. 设计压缩率调度策略，例如基于输入长度或任务类型自动调整。
3. 在验证集上测试不同压缩率下的性能表现，确定最优调度规则。

**注意事项**:  
动态调整可能增加系统复杂度，需权衡额外开销与压缩收益。

---

### 实践 3：保留关键上下文信息

**说明**:  
Token 压缩过程中，关键上下文信息的丢失可能导致生成质量下降或分类错误。BiGain 通过选择性保留机制确保重要信息不被压缩。

**实施步骤**:
1. 识别输入中的关键 Token（如命名实体、关键词或高注意力权重 Token）。
2. 在压缩过程中为关键 Token 分配更高权重或直接保留。
3. 验证压缩后模型对关键信息的保留能力。

**注意事项**:  
关键 Token 的识别需结合具体任务，避免过度依赖通用规则。

---

### 实践 4：联合优化生成与分类损失

**说明**:  
BiGain 通过联合优化生成和分类任务的损失函数，确保压缩后的 Token 表示对两者均有效。单一任务优化可能导致另一任务性能下降。

**实施步骤**:
1. 设计多任务损失函数，平衡生成和分类损失的权重。
2. 在训练过程中动态调整损失权重（如基于任务难度或收敛速度）。
3. 监控两个任务的性能指标，避免某一任务被过度优化。

**注意事项**:  
需确保损失函数的权重设置合理，避免某一任务主导训练过程。

---

### 实践 5：高效压缩模块设计

**说明**:  
BiGain 的压缩模块需兼顾效率与性能。设计高效的压缩模块（如基于注意力机制或低秩分解）可显著降低计算开销。

**实施步骤**:
1. 选择轻量级压缩算法（如线性投影或稀疏注意力）。
2. 优化压缩模块的计算图，减少冗余操作。
3. 在目标硬件上测试压缩模块的延迟和吞吐量。

**注意事项**:  
压缩模块的复杂度不应抵消压缩带来的计算收益。

---

### 实践 6：多场景验证与迭代

**说明**:  
BiGain 的有效性需在不同场景下验证。通过多场景测试可发现潜在问题并迭代优化。

**实施步骤**:
1. 在生成任务（如文本摘要）和分类任务（如情感分析）上分别测试压缩效果。
2. 分析失败案例，针对性优化压缩策略。
3. 迭代更新压缩模型，逐步提升泛化能力。

**注意事项**:  
需覆盖多样化的输入类型和任务场景，避免过拟合特定数据分布。

---

### 实践 7：部署与监控

**说明**:  
实际部署后需持续监控压缩模型的性能，确保其在生产环境中的稳定性和效率。

**实施步骤**:
1. 部署压缩模型并记录关键指标（如延迟、吞吐量、任务准确率）。
2. 设置异常检测机制，及时发现性能下降。
3. 定期重新评估压缩策略，适应数据分布变化。

**注意事项**:  
生产环境的复杂性可能引入训练阶段未遇到的问题，需预留优化空间。

## 学习要点

- BiGain 是首个统一框架，通过引入“增益”概念，在单一模型内同时实现图像生成（如 GAN）与分类任务，打破了两者长期分离的研究范式。
- 该方法提出了一种通用的“令牌压缩”策略，能够显著减少视觉 Transformer 中的冗余计算，从而在保持高性能的同时大幅降低推理成本。
- 在分类任务中，BiGain 通过动态压缩冗余的类令牌，不仅加快了推理速度，还通过减少噪声干扰提升了模型的判别精度。
- 在生成任务中，该框架利用压缩后的令牌重建高质量图像，证明了高度压缩的潜在表示依然足以保留复杂的视觉纹理信息。
- BiGain 实现了生成与判别任务的特征共享，使得模型在无需额外训练的情况下，能够利用生成数据增强分类器的鲁棒性。
- 实验表明，该方法在 ImageNet 等标准数据集上，在计算效率（FLOPs）和模型精度之间取得了优于现有技术的最佳平衡。

## 常见问题


### 1: BiGain 论文主要解决了什么核心问题？

1: BiGain 论文主要解决了什么核心问题？

**A**: BiGain 论文主要解决了视觉 Transformer（ViT）及其变体在处理高分辨率图像时面临的计算成本过高和推理速度慢的问题。具体而言，它针对的是“Token 冗余”问题，即输入图像被切分成的大量 Patch Token 中，许多包含的是背景或低频信息，对最终任务的贡献较小。现有的 Token 剪枝方法通常存在两个局限：一是仅针对分类任务，无法直接迁移到生成任务（如 GAN 扩图）；二是在压缩过程中丢失了高频细节，导致生成图像模糊。BiGain 提出了一种统一的压缩框架，旨在同时提升分类和生成任务的性能与效率。

---



### 2: BiGain 的核心技术创新点是什么？

2: BiGain 的核心技术创新点是什么？

**A**: BiGain 的核心创新在于提出了一种“双向增益”机制，用于评估每个 Token 的重要性。与传统的基于注意力分数或重构误差的剪枝方法不同，BiGain 包含两个关键组件：
1.  **分类增益**：评估该 Token 对下游分类任务（如语义分割）的判别性贡献。
2.  **生成增益**：评估该 Token 对图像重建任务（保留高频细节）的生成性贡献。
通过联合优化这两个增益，BiGain 能够在压缩 Token 数量的同时，既保留对分类有用的语义特征，又保留对生成清晰图像至关重要的高频纹理特征，从而实现了“统一的 Token 压缩”。

---



### 3: BiGain 如何实现“联合生成与分类”？

3: BiGain 如何实现“联合生成与分类”？

**A**: BiGain 通过一个统一的 Transformer 架构（通常基于 Swin Transformer）同时处理两个任务，并在中间层引入 Token 压缩模块。其工作流程如下：
1.  **特征提取**：输入图像经过浅层网络提取初始特征。
2.  **双向评分**：BiGain 模块计算每个 Token 的“分类增益”和“生成增益”。
3.  **Token 压缩**：根据综合评分，保留重要 Token，丢弃冗余 Token，或者将相似 Token 合并（Merger）。
4.  **任务分支**：压缩后的紧凑特征图被送入深层网络，分别同时输出分类结果（如类别标签）和生成结果（如高分辨率图像或补全内容）。这种联合训练迫使压缩后的特征必须同时满足两个任务的需求，从而保证了特征的表达能力。

---



### 4: 与传统的 Token Pruning（剪枝）方法相比，BiGain 有什么优势？

4: 与传统的 Token Pruning（剪枝）方法相比，BiGain 有什么优势？

**A**: 传统的 Token Pruning 方法（如 DynamicViT, A-ViT）主要依赖分类损失（如 Cross-Entropy Loss）来指导 Token 的取舍。这会导致模型倾向于保留包含主要物体的低频语义 Token，而丢弃包含纹理、边缘信息的高频 Token。虽然这对分类任务影响不大，但会导致生成任务（如超分、扩图）产生的图像过于平滑和模糊。
BiGain 的优势在于它引入了“生成增益”作为约束，强制模型保留那些对图像重建至关重要的高频细节 Token。这使得 BiGain 在大幅降低计算量的同时，不仅能维持分类精度，还能显著提升生成图像的视觉质量（PSNR 和 FID 指标）。

---



### 5: BiGain 可以应用在哪些具体的下游任务中？

5: BiGain 可以应用在哪些具体的下游任务中？

**A**: 由于 BiGain 兼顾了语义理解和像素级重建，它非常适合需要同时处理这两种需求的任务，典型的应用场景包括：
1.  **图像分类**：在保持高精度的同时，通过减少 Token 数量来加速推理。
2.  **图像修复与扩图**：利用保留的高频 Token 生成逼真的纹理和边缘。
3.  **语义分割**：在压缩特征图的同时保留边缘细节，提高分割边界精度。
4.  **高分辨率图像生成**：作为 GAN 或 Diffusion Model 的 Backbone，在处理高分辨率时降低显存占用和计算时间。

---



### 6: 使用 BiGain 会对模型的推理速度带来多大的提升？

6: 使用 BiGain 会对模型的推理速度带来多大的提升？

**A**: 根据论文中的实验数据，BiGain 能够在保持相当精度（如分类精度下降在 0.5% 以内）的前提下，将计算量（FLOPs）降低 30%-50%，并显著减少内存占用。由于 Transformer 的计算复杂度与 Token 数量的平方成正比，通过在中间层激进地剪枝 Token，实际推理速度（FPS）通常能提升 1.5 倍到 2 倍，具体提升幅度取决于硬件平台和输入图像的分辨率。

---

7: BiGain 的训练过程复杂吗？是否需要复杂的损失函数设计？

**A**: 是的，BiGain 的训练比标准的分类模型稍显复杂。它不仅仅需要分类损失，还需要引入重建损失（如 L1 Loss 或 L2 Loss）来计算生成增益。此外，为了训练 Token 压缩模块，通常还需要使用 Gumbel-Softmax 技巧或特定的正则化项来使得 Token 的筛选过程可微分。这意味着在训练阶段，模型需要同时输入图像和对应的标签（如果有监督分类）以及原始图像本身（用于计算重建损失），通常采用多
