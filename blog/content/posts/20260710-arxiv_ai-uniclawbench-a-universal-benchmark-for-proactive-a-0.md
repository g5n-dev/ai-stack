## 摘要

UniClawBench 是首个以能力驱动的基准，旨在评估大模型及多模态大模型在动态真实场景中的主动智能体表现。基准围绕五项核心能力构建：
#### 基础能力
- **技能使用**（Skill Usage）：智能体能够快速定位并正确调用所需 API 或工具。
- **探索**（Exploration）：在不确定环境下进行主动搜索与信息收集。
- **长上下文推理**（Long‑Context Reasoning）：在长对话或多轮交互中保持状态和推理连贯性。
- **多模态理解**（Multimodal Understanding）：融合文本、图像、音频等多种输入完成复杂任务。
- **跨平台协同**（Cross‑Platform Coordination）：跨多个系统或服务进行任务编排与信息传递。

#### 任务设计
基于上述能力设计了 **400 条双语（中文‑英文）真实任务**，覆盖日程管理、信息检索、自动化脚本生成、视觉问答、跨应用工作流等场景，任务难度从单步指令到多轮协同递进。

#### 评估方式
- **实时容器**：在 Docker 环境中执行任务，使用细粒度、逐步骤完成的检查点进行评判，避免依赖预录答案。
- **闭环反馈**：由执行智能体、隐藏督导智能体和用户模拟智能体构成，分别负责任务执行、进度监控与自然语言反馈，模拟真实多轮交互且不泄露评分标准。

#### 实验与发现
对多款前沿模型在不同 Agent 框架（如 ReAct、Plan‑and‑Execute、AutoGPT 等）下进行对比，揭示 **模型本身能力** 与 **框架设计** 对整体性能的不同贡献。结果显示，仅靠模型规模不足以保证跨平台协同和长上下文任务的高效完成，框架对任务分解与错误恢复的调度至关重要。

#### 资源开放
基准代码、任务集、评估脚本均已在 GitHub（https://github.com/HKU-MMLab/UniClawBench）公开，供研究者复现和进一步扩展。

UniClawBench 通过能力分解、真实环境执行与闭环反馈，为评估和提升主动智能体的综合表现提供了系统性、可比性的平台。

## 技术分析

主动智能体（Proactive Agent）代表了人工智能从被动响应向主动规划的重大范式转变。随着大语言模型和多模态大模型的快速发展，智能体具备了更强的推理和决策能力，能够在真实动态环境中主动探索和完成任务。然而，现有基准测试普遍存在场景静态化、评估依赖预录答案、缺乏多模态融合能力考察等问题，难以真实反映智能体在复杂真实场景中的表现。UniClawBench的出现正是为了填补这一空白，通过能力驱动的视角重新定义智能体评估标准。

评估机制采用实时容器与闭环反馈相结合的设计。在Docker环境中执行任务，使用细粒度逐步骤完成的检查点进行评判，避免依赖预录答案。执行智能体、隐藏督导智能体和用户模拟智能体三方协作，模拟真实多轮交互且不泄露评分标准，保证了评估的动态性和公平性。

根据摘要信息，实验对比了多款前沿模型在不同Agent框架（ReAct、Plan-and-Execute、AutoGPT等）下的表现。结果表明，模型规模并非决定性因素，仅靠增大模型参数不足以保证跨平台协同和长上下文任务的高效完成。框架设计对任务分解与错误恢复的调度至关重要，框架与模型能力之间存在复杂的交互关系。这一发现具有重要的实践指导意义，提示研究者在优化智能体系统时需要同时关注模型能力和框架设计的协同优化。
