3.  **LLM 隔离**：元数据通常位于消息对象的顶层属性中，而不是 `content` 字符串内部，因此它们默认不会被包含在发送给 LLM 的提示词中。除非你手动在后端将元数据拼接到 Prompt 中，否则模型是“看”不到这些数据的。
