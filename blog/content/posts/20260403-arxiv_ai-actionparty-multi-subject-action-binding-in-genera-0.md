## 摘要

近期，视频扩散模型在构建可交互的“世界模型”方面取得进展，但大多数仅限于单一智能体，难以同时控制场景中多个主体。本文提出 ActionParty，一种动作可控的多主体世界模型，用于生成式电子游戏。核心是引入主体状态 token——一种持久捕捉每个主体状态的潜在变量。通过在视频潜在空间与状态 token 联合建模，并引入空间偏置机制，实现全局画面渲染与个体动作驱动的状态更新解耦。在 Melting Pot 基准上评估，首次实现可同时控制七名玩家、跨越46种不同环境的世界模型。实验表明，ActionParty 在动作跟随准确率和身份一致性方面显著提升，并能通过自回归方式稳健追踪主体在复杂交互中的轨迹。

#### 论文声称与证据
作者声明 ActionParty 通过主体状态 token 与空间偏置机制，实现视频潜在空间中全局渲染与多主体动作更新的解耦，从而在 Melting Pot 基准上首次完成七名玩家、46 种环境的同步控制。实验提供了动作跟随准确率和身份一致性的量化提升，这构成其声称的直接证据。然而，评测局限于单一基准，未展示跨任务或跨模型的迁移数据，证据的覆盖范围仍显有限。

#### 关键假设与潜在失效
1. **Token 能持久捕获状态**：假设状态 token 在长时间自回归生成中保持低噪声且信息不衰减。若 token 受累积误差或梯度消失影响，身份一致性会快速退化。
2. **空间偏置的解耦有效性**：该机制假设空间偏置能够在潜在空间精准区分各主体运动。若场景中出现高度遮挡或运动交叉，解耦可能失效，导致动作混淆。
3. **多主体交互的可建模性**：认为所有交互行为均可在视频扩散模型的潜在空间内表示。若实际游戏中出现高频碰撞、瞬时状态突变（如死亡/重生），模型可能出现不可恢复的生成错误。
**验证方式**：可在不同游戏引擎（如 Unity、Unreal）上搭建相同任务，或在更大规模的多智能体环境（e.g., StarCraft II）上测试，观察 token 稳定性和动作跟随误差的收敛情况。

#### 推断与应用前景
基于现有实验，ActionParty 在受控基准上展示了可行的多主体世界模型框架。若上述假设得到进一步验证，可预期其在生成式游戏、自动驾驶仿真以及多机器人协同训练等场景中产生实际价值。建议后续工作重点提升 token 的长期记忆能力，并引入对抗性扰动测试，以评估模型在极端交互下的鲁棒性。总体而言，该研究为多主体生成模型提供新思路，但距离通用、实时的世界模型仍有待更大规模的实验验证。

## 技术分析

#### 研究背景
- **已知事实**（摘要）：视频扩散模型已能构建可交互的“世界模型”，但大多数系统仅支持单一智能体，难以在多主体场景中实现同步控制。
- **推断**：游戏行业对可实时响应多玩家动作的生成式模型有强烈需求；现有模型缺乏对多个主体状态的统一表示，导致交互时出现身份混淆或动作漂移。

#### 核心方法
##### 主体状态 token
- **抽象层**：引入一种潜在变量（主体状态 token），在视频潜在空间中持久捕获每个主体的姿态、位置等关键属性。
- **实现**：token 与视频潜在码联合建模；通过交叉注意力机制让每帧的生成过程查询对应主体的 token，实现状态传播。

##### 空间偏置机制
- **设计**：在自注意力层加入空间偏置，使 token 对局部区域（主体所在位置）产生强约束，其他区域弱约束，从而实现全局渲染与个体动作更新的解耦。
- **效果**：保持画面整体连贯的同时，确保每个主体的动作能够独立驱动其 token 更新。

##### 训练与推理
- **训练**：在大规模电子游戏录像上进行条件扩散模型训练，条件包括动作标签和主体状态 token。
- **推理**：自回归生成；每生成一帧后，更新对应主体的 token，作为下一帧的条件。

#### 理论基础
- **潜在变量模型**：token 视为离散潜在变量，捕捉主体状态的时间一致性。
- **条件扩散**：在视频潜在空间进行去噪，条件信息由 token 与动作向量共同提供，实现动作驱动的生成。
- **假设**：
  1. 主体状态能在低维 token 中完整表达；
  2. 空间偏置能够有效分离主体间的注意力；
  3. 训练数据覆盖足够多样的多主体交互。

#### 实验与结果
- **基准**：Melting Pot，提供46种多智能体环境，最多支持七名玩家。
- **指标**：动作跟随准确率、身份一致性（ID preservation）。
- **结论**：相较于基线（单一主体模型），ActionParty 在所有指标上显著提升；自回归生成能够稳健追踪复杂交互轨迹。
- **推断**：实验规模说明模型具备一定的可扩展性，但仅在 Melting Pot 环境中验证，跨域泛化能力仍待检验。

- **多主体状态表示**：持久 token 为多智能体生成模型提供统一的状态抽象，可视为对“角色图谱”的潜在空间编码。
- **空间约束与解耦**：在注意力机制中引入显式空间偏置，是解决多主体渲染冲突的有效手段。
- **自回归驱动的时序一致性**：通过 token 更新实现跨帧状态传播，可提升长序列生成的稳定性。

#### 关键假设与潜在失效条件
- **假设**：token 能完整捕获主体状态，且在长序列中不发生信息衰减。
- **失效条件**：
  1. **交互密度过高**：当主体间碰撞或遮挡频繁时，token 可能被错误更新，导致身份混淆。
  2. **未见过的角色或环境**：模型对训练集外的主体外观或行为模式缺乏泛化，token 表示失效。
  3. **长序列漂移**：自回归更新累计误差会逐渐削弱 token 的判别能力。

- **身份混淆实验**：人为制造高密度交互场景，检测 token 是否保持正确对应关系。
- **长序列评估**：生成 100+ 帧连续动作，观察 ID preservation 指标衰减趋势，验证自回归误差控制的有效性。

ActionParty 通过主体状态 token 与空间偏置机制，首次在多主体生成式游戏场景中实现同步控制，并在 Melting Pot 基准上取得显著提升。其实验结果表明持久 token 能够有效捕捉个体状态，空间约束有助于解耦全局渲染与局部动作。然而，模型的泛化能力、对高密度交互的鲁棒性以及长序列误差累计仍是后续研究需要验证的关键方向。
