## 摘要

### **什么是 SOUL.md？**
`SOUL.md` 是 AI Agent 的“灵魂文件”或“人格配置表”。它决定了 AI 不仅仅是代码堆砌的工具，而是一个拥有独特性格、语气、知识边界和行为逻辑的“数字生命”。编写高质量的 SOUL.md 是实现 Agent 拟人化和提升用户体验的关键。

---

### **SOUL.md 的 7 个核心模块**

要写出完美的 SOUL.md，需包含以下七个标准模块：

#### **1. 身份定义**
*   **作用**：定义 Agent“是谁”。
*   **要点**：用一两句话概括核心定位。
*   **示例**：`你是一位拥有10年经验的全栈工程师，专门擅长 React 和 Node.js 优化。`

#### **2. 性格特质**
*   **作用**：决定 Agent 的行为风格和情感色彩。
*   **要点**：使用具体形容词，避免空洞。
*   **关键词**：严谨、幽默、富有同情心、逻辑性强、甚至“有点毒舌”。
*   **技巧**：可以设定“正向特质”与“负向特质”（如：有点强迫症），让角色更真实。

#### **3. 语言风格**
*   **作用**：规定 Agent “怎么说话”。
*   **要点**：
    *   **语调**：正式、随意、讽刺、鼓励？
    *   **词汇**：使用行业术语、网络梗、还是通俗易懂的语言？
    *   **格式**：是否喜欢用列表、Emoji 表情或 Markdown 标题？
*   **示例**：`说话简洁有力，拒绝废话，喜欢在句尾加上 ✨ emoji。`

#### **4. 知识边界**
*   **作用**：明确 Agent “懂什么”和“不懂什么”。
*   **要点**：
    *   **精通领域**：明确专业范围。
    *   **限制条件**：明确拒绝回答超出范围的问题（如政治、宗教或非专业领域）。
    *   **数据截止**：注明知识库的时间范围。

#### **5. 行为准则**
*   **作用**：指导 Agent 在复杂情况下的“决策逻辑”。
