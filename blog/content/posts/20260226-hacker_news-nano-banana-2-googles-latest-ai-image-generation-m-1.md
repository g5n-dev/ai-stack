```python
# 示例1：使用Nano Banana 2生成图像
import requests
import json

def generate_image(prompt, api_key):
    """
    使用Nano Banana 2 API生成图像
    :param prompt: 图像描述文本
    :param api_key: Google Cloud API密钥
    :return: 生成的图像URL
    """
    url = "https://generativelanguage.googleapis.com/v1beta/models/nano-banana-2:generateImage"
    headers = {"Authorization": f"Bearer {api_key}"}
    data = {"prompt": prompt, "size": "1024x1024"}
    
    response = requests.post(url, headers=headers, json=data)
    result = response.json()
    
    return result.get("image_url")

# 使用示例
image_url = generate_image("一只戴着墨镜的香蕉在海滩上", "YOUR_API_KEY")
print(f"生成的图像链接: {image_url}")
```

```python
import os
import requests

def batch_generate_images(prompts, output_dir="generated_images"):
    """
    批量生成图像并保存到本地
    :param prompts: 图像描述列表
    :param output_dir: 保存目录
    """
    os.makedirs(output_dir, exist_ok=True)
    
    for i, prompt in enumerate(prompts):
        # 调用生成函数（示例1中的函数）
        image_url = generate_image(prompt, "YOUR_API_KEY")
        
        # 下载图像
        img_data = requests.get(image_url).content
        with open(f"{output_dir}/image_{i+1}.png", "wb") as f:
            f.write(img_data)
        
        print(f"已保存: image_{i+1}.png")

# 使用示例
prompts = [
    "赛博朋克风格的香蕉城市",
    "梵高风格的香蕉静物画",
    "香蕉宇航员在火星"
]
batch_generate_images(prompts)
```

```python
import numpy as np
from PIL import Image
import requests
from io import BytesIO

def evaluate_image_quality(image_url):
    """
    评估生成图像的基本质量指标
    :param image_url: 图像URL
    :return: 包含质量指标的字典
    """
    # 下载图像
    response = requests.get(image_url)
    img = Image.open(BytesIO(response.content))
    img_array = np.array(img)
    
    # 计算基本指标
    metrics = {
        "分辨率": img.size,
        "色彩丰富度": len(np.unique(img_array.reshape(-1, 3), axis=0)),
        "亮度均值": np.mean(img_array),
        "对比度": np.std(img_array)
    }
    
    return metrics

# 使用示例
metrics = evaluate_image_quality("https://example.com/generated_image.png")
print("图像质量评估结果:")
for k, v in metrics.items():
    print(f"{k}: {v}")
```

## 最佳实践指南

### 实践 1：构建结构化且具体的提示词

**说明**：Nano Banana 2 作为 Google 最新的图像生成模型，在处理包含丰富细节、明确风格和清晰构图指令的提示词时表现最佳。模糊或过于简单的描述往往导致结果不可预测。通过结构化输入，可以显著提升生成图像与预期的一致性。

**实施步骤**：
1. 采用主体 + 风格 + 环境 + 灯光 + 技术参数（如宽高比、渲染风格）的公式构建提示词。
2. 避免使用笼统的词汇（如“一只狗”），转而使用具体描述（如“一只赛博朋克风格的机械柯基，霓虹灯下的雨夜街道”）。
3. 利用括号或权重语法（如果支持）来强调关键视觉元素。

**注意事项**：避免提示词过长导致模型注意力分散，应专注于对视觉画面影响最大的描述词。

---

### 实践 2：利用风格迁移与艺术参考

**说明**：该模型在理解特定艺术流派、摄影风格和材质质感方面进行了深度优化。明确指定艺术风格或参考特定艺术家/作品的特征，可以生成更具审美价值和视觉冲击力的图像。

**实施步骤**：
1. 在提示词中明确定义媒介，例如“油画”、“3D 渲染”、“矢量插画”或“胶片摄影”。
2. 添加风格修饰词，如“虚幻引擎 5 渲染”、“吉卜力工作室风格”或“极简主义平面设计”。
3. 结合材质描述，如“玻璃质感”、“水彩纹理”或“金属光泽”。

**注意事项**：混合过多冲突的风格（如同时要求“写实照片”和“抽象像素画”）可能会导致画面不协调，应保持风格的一致性。

---

### 实践 3：精确控制构图与镜头语言

**说明**：为了获得理想的画面布局，需要在提示词中包含专业的摄影和电影术语。Nano Banana 2 能够理解复杂的空间关系和镜头设置，这有助于控制视角和景深。

**实施步骤**：
1. 指定拍摄角度，如“鸟瞰图”、“特写”、“低角度拍摄”或“过肩镜头”。
2. 定义景深效果，使用“浅景深”、“背景虚化”或“f/1.8 光圈”等术语。
3. 描述主体在画面中的位置，例如“居中构图”或“遵循三分法”。

**注意事项**：复杂的构图描述可能需要多次迭代尝试，以找到最符合模型逻辑的表达方式。

---

### 实践 4：掌握迭代式优化与负向提示

**说明**：首次生成的结果很少是完美的。通过分析初始输出并调整提示词，结合负向提示词来排除不需要的元素，是获取高质量图像的关键环节。

**实施步骤**：
1. 生成第一版图像，识别出不符合预期的细节（如多余的手指、错误的颜色）。
2. 在提示词中增加正向强化词，修正细节。
3. 使用负向提示词功能，明确列出需要排除的内容，例如“模糊、低质量、扭曲、水印、多余的肢体”。

**注意事项**：负向提示词应谨慎使用，避免过度排除导致画面主体缺失或过度平滑。

---

### 实践 5：合理设置分辨率与宽高比

**说明**：根据最终用途（如社交媒体帖子、演示文稿或打印素材）正确设置图像尺寸至关重要。Nano Banana 2 支持多种生成分辨率，合理的设置能避免画面拉伸或裁剪。

**实施步骤**：
1. 根据输出平台选择参数，例如 Instagram 故事选择 9:16，桌面壁纸选择 16:9。
2. 在提示词或设置面板中明确指定分辨率（如 4k, 1080p）或宽高比参数。
3. 对于需要高细节放大的场景，先生成高分辨率原图，再进行超分辨率处理。

**注意事项**：极端的宽高比可能会导致主体变形，建议在常用比例范围内进行创作。

---

### 实践 6：遵循伦理规范与版权合规

**说明**：作为 Google 的 AI 模型，使用 Nano Banana 2 时必须遵守安全准则和版权法律。生成内容不应包含有害、仇恨、色情或侵犯他人版权的素材。

**实施步骤**：
1. 避免输入涉及公众人物受权保护的肖像，或直接复制受版权保护的艺术作品风格用于商业用途。
2. 检查生成内容是否符合社区标准，避免生成暴力、血腥或歧视性内容。
3. 在发布 AI 生成内容时，根据平台要求进行适当标注。

**注意事项**：模型通常内置了安全过滤器，试图绕过这些过滤器可能导致账户受限或封禁。
