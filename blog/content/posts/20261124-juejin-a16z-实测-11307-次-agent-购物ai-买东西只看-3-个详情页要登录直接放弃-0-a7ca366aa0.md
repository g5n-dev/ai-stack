## 核心结论

a16z 与 The Prompting Company 在 1270 条购物和软件选型提示词上，让 Grok Bot、Muse、Instinct、Dots 完整执行了 11307 次个人智能体流程，并以 ChatGPT、Gemini、Perplexity 的 2619 次结果作对照。结果显示，智能体并不会广泛浏览商品：Muse 每次最多从自家目录拉取 50 个商品，即使触发浏览器搜索，平均也只打开 3 个详情页。

四个智能体的选择具有较高趋同度：一个智能体选中某商品后，至少另一个选中它的概率为 73%；近四分之一的测试中，四个模型选出了相同第一名。对商家而言，进入候选列表、获得详情页访问权以及允许直接结账，可能比影响最终用户偏好更关键。

## 能力机制

智能体主要依据可结构化读取的信息进行筛选。商品页需要清楚呈现功能、价格以及接口或自动化限制；软件页若公开 API、官方 MCP 集成和可运行示例，更容易被纳入选型。来源中的案例显示，Dots 查询 Midjourney 时发现其缺少通用 API 且条款限制自动化调用，随后转向 Ideogram。

比较商品时，智能体关注包含运费、订阅周期、退换货和保修的总成本。同价情况下，提供免费退货、更长退货期或原路退款的商家，在 86% 的测试中胜出。275 次真实商店比价中，智能体有 72% 的时候选择价格较高但信任度更高的授权经销商。折扣也并非越大越有效：低于 10% 的折扣未改变选择；10% 至 50% 的折扣仅让 24% 的转向低价非权威卖家；超过 50% 后，部分智能体因怀疑商品真实性而避开。

不同模型的信息权重并不一致。Muse 仅在 10% 的推荐中引用用户评价，其他三者为 30% 至 41%；Instinct 在 26 次平局决胜中只有 4 次选择评分更高者，更重视退货与取消条款。来源给出的解释是，智能体倾向把功能、成本、条款、接口可用性和购买链路作为整体判断，而不是只追随最低标价。

## 快速开始

以下是基于来源事实整理的接入自查流程，属于工程建议，不代表来源报告已经提供部署方案：

1. 列出核心商品或软件的参数、价格、计费周期、退货、保修、取消和授权信息，避免关键规则只存在于图片或模糊描述中。
2. 单独说明产品能完成的任务、适合的具体场景及不适用条件。测试中，细软或染烫发质等具体需求可改变吹风机选择结果；明确“团队模板”或“专业级输出”也会改变设计软件选型。
3. 对软件产品公开可确认的 API、MCP 集成、调用条款和限制说明；若不支持自动化，应明确写出。来源没有提供可核验的安装或运行命令，因此这里不列出命令。
4. 区分普通人类访问路径与无需登录的访客结账路径，检查页面是否能在不索取账号密码的情况下展示商品、价格和最终付款入口。
5. 使用不同品牌、不同细分场景以及不同措辞进行重复测试，分别记录候选排名、详情页访问、总成本判断、引用来源和结账中止位置。

## 适用边界

11307 次实验由 a16z 与为品牌提供智能体优化服务的 The Prompting Company 联合完成，各子实验样本量并不相同。用于交叉验证消费流向的 YipitData 面板截至 11 月 11 日，排除了 Amazon，也没有区分 Muse 与 Instinct，因此不能据此比较不同模型。

消费样本还受到品类结构影响。旅游聚合平台和交易市场在智能体促成的消费中占比较高；在前 50 个商家中，近三分之一流向聚合平台或交易市场，计入自带第三方市场的零售商后为 46%，再计入传统多品牌零售商后达到 55%。这不能直接外推到所有消费品类。

此外，走到结账表单不等于完成自动扣款。来源称，多数消费者仍不愿把最终付款完全交给 AI；反爬机制和买错货的责任归属也尚未解决。Amazon 结账测试中，Grok Bot 均能进入购物车，Muse、Instinct 和 Dots 则被反爬策略拦截。

## 核验清单

- 核对实验规模：1270 条提示词、11307 次完整个人智能体流程，以及 2619 次对照运行。
- 核对浏览深度：Muse 单次最多拉取 50 个商品，触发浏览器搜索后平均查看 3 个详情页。
- 核对选择趋同：至少两个智能体选择同一商品的概率为 73%，近四分之一测试出现相同第一名。
- 核对成本与信任：86% 的同价测试偏向退货政策更好的商家；72% 的商店比价偏向授权经销商。
- 核对折扣阈值：低于 10% 无明显影响，10% 至 50% 的转向概率为 24%，超过 50% 后可能触发真实性疑虑。
- 核对结账门槛：支持免登录访客结账时，81% 的运行到达结账表单末尾；要求登录的商店测试均提前中止。
- 核对证据来源：分别记录评价引用比例、条款偏好、站点链接分布及失败环节，不把单个模型的结果推广到全部智能体。
- 区分本地保存与外部调用：来源只支持对配置和自动化访问条件的分析，不能据此断言推理数据或用户信息一定留在本机。
