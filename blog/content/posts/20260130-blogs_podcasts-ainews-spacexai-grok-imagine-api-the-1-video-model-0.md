**说明**：Grok Imagine API 作为顶级视频模型，对自然语言理解能力极强。通过结构化、细节丰富的提示词工程，可以显著提升生成视频的准确性和艺术表现力，避免模型产生歧义或生成不符合预期的内容。

**实施步骤**：
1. 采用“主体 + 动作 + 环境 + 风格 + 运镜方式”的五维结构编写提示词。

3. 避免使用否定句式（如“不要有人”），改用正向描述（如“空旷的街道”）。

**注意事项**: 保持提示词简洁但信息密度高，过长的描述可能会导致处理延迟增加。
