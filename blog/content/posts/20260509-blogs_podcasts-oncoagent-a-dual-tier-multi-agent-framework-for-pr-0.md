#### 核心观点

OncoAgent的核心命题在于解决肿瘤临床决策中数据隐私与智能辅助之间的矛盾。传统AI系统在医疗场景面临严格的数据合规要求，而单纯的联邦学习或差分隐私方案往往难以满足临床决策的实时性与准确性需求。该框架创新性地采用双层多智能体架构，将隐私计算与决策生成进行功能解耦，实现“数据不出域、推理可共享”的新型协作范式。这种设计在保证患者隐私安全的前提下，为基层医疗机构提供了与顶级肿瘤中心同等水平的决策支持能力。

#### 关键技术点

##### 双层多智能体架构设计

系统采用本地层与协作层的双层结构。本地层部署于各医疗机构内部，由多个专科智能体组成，负责病历解析、检查结果解读、患者既往史关联等基础任务。协作层作为跨机构协调中心，汇聚多个本地层的决策建议，通过知识融合与投票机制生成综合诊疗方案。双层架构的优势在于将敏感数据处理限制在本地层，仅交换经过脱敏处理的特征向量或决策置信度，有效降低数据泄露风险。

##### 隐私保护技术实现

框架集成三类隐私增强技术：同态加密确保协作层可在密文状态下完成模型推理；安全多方计算实现多机构联合建模而无需共享原始数据；本地差分隐私在特征提取阶段注入可控噪声，防止模型逆向攻击。技术选型上，同态加密用于计算密集型任务如影像特征聚合，安全多方计算处理结构化临床数据的联合查询，而差分隐私作为最后一道防护层应用于向外部系统的数据输出。
