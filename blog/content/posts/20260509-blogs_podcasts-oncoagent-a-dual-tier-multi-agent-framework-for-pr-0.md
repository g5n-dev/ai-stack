## 导语

OncoAgent 是一个面向肿瘤临床决策的双层多智能体框架，通过在本地节点与中心服务器之间划分计算，实现诊疗建议的生成而无需直接暴露患者敏感数据。框架结合联邦学习与差分隐私，在保障数据安全的前提下聚合多源医学信息，提高模型泛化能力。本文将详细介绍系统架构、关键算法实现及在真实病例数据集上的验证效果，帮助研究者和临床团队快速评估并部署该方案。

#### 核心观点

#### 关键技术点
##### 双层架构
- **本地层（Edge Agent）**：负责患者数据清洗、特征工程、局部模型微调，采用联邦学习与本地差分隐私（DP‑SGD）实现噪声注入。
- **中心层（Cloud Agent）**：聚合本地模型的梯度或参数更新，进行全局模型训练、知识库融合以及全局决策推荐。

##### 多智能体协作机制
- **任务分解**：将临床决策拆分为病例检索、方案生成、风险评估、解释生成等子任务，各子任务对应专属智能体。
- **消息协议**：基于安全的 RPC 或 gRPC 消息总线，使用加密通道传输；通过统一的意图协议（Intent‑Protocol）实现跨代理意图识别与响应。
- **冲突消解**：采用基于权重的投票或基于置信度的优先级排序，确保最终建议的一致性与可信度。

- **安全多方计算（MPC）**：用于跨机构模型的参数聚合，避免单点泄露。
- **同态加密（HE）**：在极端隐私需求场景下，对加密模型输出进行解密后再生成解释。
