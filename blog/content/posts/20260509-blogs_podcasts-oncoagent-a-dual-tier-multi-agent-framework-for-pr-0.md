#### 核心观点
##### 中心命题
OncoAgent 旨在通过双层多智能体协作，在不暴露原始患者数据的前提下，为肿瘤临床决策提供实时、精准的辅助。

##### 支撑理由
1. **隐私保护是跨机构数据共享的前提**：采用联邦学习、差分隐私等技术，实现模型在本地更新，仅共享梯度或噪声扰动后的参数。
2. **多智能体协同提升决策覆盖**：影像、基因组、临床文本分别由专属代理处理，融合层再统一生成综合建议，避免单点信息盲区。
3. **双层架构兼顾效率与安全**：边缘层（本地）完成快速过滤和特征抽取，云层（中心）负责全局模型聚合与深度推理，降低带宽消耗并提升响应速度。

- 当数据分布极度不均衡时，局部模型可能产生偏差，导致云层聚合后整体性能下降。

- 差分隐私的噪声注入可能掩盖罕见突变特征，影响精准医学关键决策。

- **安全多方计算（MPC）**：云端聚合时采用秘密共享，防止单点泄露。
