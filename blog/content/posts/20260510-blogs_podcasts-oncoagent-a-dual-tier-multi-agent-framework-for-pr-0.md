##### 支撑理由
1. **双层结构**：边缘层完成实时推理，云层负责全局模型聚合，避免原始数据外泄。
2. **多智能体分工**：数据获取、特征抽取、模型训练、推理解释等职责分离，提高系统的可维护性与可扩展性。
3. **隐私技术**：联邦学习、差分隐私、同态加密等多管齐下，保证在协同训练时每位患者的信息不可逆。

#### 关键技术点

##### 双层多智能体架构
- **边缘层智能体**：负责本地数据清洗、特征抽取和快速推理，延迟<1 s；典型实现为轻量化深度模型（MobileNet、EfficientNet）或基于规则的专家系统。
- **云层智能体**：收集边缘模型的梯度或参数更新，执行联邦聚合，生成全局模型并下发；采用安全聚合协议防止中间梯度泄露。

##### 隐私保护技术
- **联邦学习（FL）**：在本地训练，仅共享模型参数或梯度。
- **差分隐私（DP）**：在梯度更新时加入高斯噪声，限制单个样本影响。
- **同态加密（HE）**：对加密梯度进行聚合，进一步防止服务器侧数据泄漏。

##### 领域知识融合
- **肿瘤知识图谱**：整合分期、基因变异、药物相互作用等实体关系，支持路径推理与解释生成。
- **可解释性模块**：使用注意力图、规则抽取等方法，将模型输出映射到知识图谱中的关键节点，提升临床可接受度。

##### 可解释决策生成
- **自然语言解释**：基于模板或生成模型，将推理链路转化为医师易读的报告（如“基于KRAS突变和PD‑L1表达，推荐使用免疫检查点抑制剂”）。
