> 一、什么是Claude Code Skills？
> 在介绍具体Skills之前，我们先快速理解一下Claude Code Skills的概念。
> 一句话解释
> ：Skills是一种可复用的能力模块，你可以把它理解成给Claude Code安装的“插件”或“技能包”。
> 每个Skill包含一个特定的提示词模板、工具调用逻辑和输出格式，让Claude Code在遇到特定任务时能够“知道”该怎么专业地处理。
> 通俗理解
> ：就像一个新人入职后，你给他一套标准操作流程（SOP）——遇到A情况怎么做，遇到B情况用什么工具。Skills就是给Claude Code的“SOP”。

> Skill 1：Code Review
> 它是代码审查，自动化的“代码质检员”。
