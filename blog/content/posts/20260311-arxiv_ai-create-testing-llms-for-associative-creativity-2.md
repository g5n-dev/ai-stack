## 导语

联想创造力作为人工智能评估的难点，核心在于模型能否在概念间建立新颖且有意义的联系。本文提出的 CREATE 基准通过生成兼具高特异性和多样性的概念路径，客观量化了这一能力，为模拟假设生成等真实任务提供了新思路。实验表明，尽管前沿模型表现优于基线，但受限于搜索空间的复杂性，现有方法仍难以在测试中达到饱和状态。此外，研究还发现单纯的思维链推理或提示工程在解决此类联想问题时存在局限性，这为未来探索更高效的生成机制指明了方向。

## 摘要

本文介绍了 **CREATE**，这是一个旨在评估大语言模型（LLM）**联想创造力**的新基准测试。

**核心概念与测试目标：**
创造力的重要组成部分是联想推理，即在概念间建立新颖且有意义的联系。CREATE 基准通过要求模型生成连接特定概念的路径来测试这一能力。这些路径必须具备两个关键特征：
1.  **高特异性**：概念之间的连接既独特又紧密。
2.  **高多样性**：不同路径之间差异显著，避免重复。

**评估机制：**
模型的得分取决于其生成的路径数量以及这些路径的质量（强度和多样性）。该任务模拟了假设生成等真实创造力任务的需求（如搜索空间极其巨大），同时实现了客观的答案评分，能够构建大规模的基准数据集。

**实验结果与发现：**
对前沿模型的评估显示，能力最强的模型表现优于其他模型，但由于答案的高度多样性和搜索的复杂性，目前很难使测试达到饱和状态（即模型很难拿到满分或接近上限）。
此外，研究还发现：
*   **思维链模型的局限性**：即使给予大量的 token 预算，擅长推理的“思维”模型在这个任务上也并不总是更有效。
*   **提示工程的边际效益**：现有的针对创造性的提示技术仅能提供有限的改进。

**意义：**
CREATE 为开发新方法提供了一个理想的“沙盒”环境，有助于推动模型在联想创造力方面的进一步发展。

# CREATE: 测试大语言模型联想创造力的技术分析

## 1. 研究背景与问题

**核心问题：**
该研究旨在解决大语言模型（LLM）在**联想创造力**量化评估方面的缺失。现有的LLM评估基准主要集中在事实知识检索、逻辑推理或指令遵循能力上，缺乏针对模型在两个看似无关的概念之间建立新颖且具有语义关联连接能力的标准化测试。

**研究背景与意义：**
创造力通常被视为科学发现和问题解决的关键要素，其认知机制往往被认为是“组合式”或“联想式”的，即通过结合现有概念产生新想法。随着LLM在生成任务中的广泛应用，区分模型是基于概率统计进行文本拼接，还是具备一定程度的创造性连接能力，成为了评估模型性能的重要维度。CREATE基准的提出，旨在填补这一评估领域的空白。

**现有方法的局限性：**
1.  **主观性限制**：传统的创造力测试（如托伦斯测试）高度依赖人工评分，难以扩展到大规模数据集。
2.  **评估指标偏差**：现有的自动评估指标（如BLEU或Perplexity）倾向于奖励常见、高频的文本模式，这与创造力评估所关注的“新颖性”存在冲突。
3.  **缺乏结构化约束**：许多开放式生成任务缺乏明确的约束条件，导致难以客观验证模型输出的有效性和逻辑性。

## 2. 核心方法与创新

**核心方法：CREATE 基准**
作者构建了一个基于图结构的基准测试框架。任务形式设定为：给定两个起始概念（节点），要求模型生成一条连接这两个概念的路径（中间节点序列）。

**技术创新点与贡献：**
1.  **双约束评估体系**：该方法将创造力任务分解为两个可量化的维度：
    *   **特异性**：生成的路径在知识图谱中必须具有紧密的连接（高连接强度），以确保语义关联的有效性。
    *   **多样性**：模型生成的多条路径之间必须具有显著的差异性（低重复率），以衡量生成的广度。
2.  **基于图的客观评分**：利用现有的知识图谱（如ConceptNet）作为外部参照系。模型生成的路径需在图谱中存在，且路径的权重（关联强度）作为评分依据，实现了评估过程的自动化。
3.  **数据集构建策略**：通过算法筛选出在图谱中距离较远（难以直接联想）的概念对，构建了具有挑战性的数据集，要求模型必须进行多跳推理才能完成任务。

## 3. 理论基础

**理论假设：**
该研究基于**联想主义理论**，即创造力的核心机制在于将远距离语义概念通过潜在路径进行连接。

**算法设计与数学模型：**
*   **图论模型**：将概念定义为节点 $V$，概念间的关联定义为边 $E$。任务形式化为在图 $G=(V, E)$ 中寻找一条路径 $P = [v_1, v_2, ..., v_n]$，使得 $v_1$ 为起点，$v_n$ 为终点。
*   **评分函数**：模型的得分 $S$ 被定义为多样性与有效性的加权组合。算法鼓励模型生成集合 $\mathcal{P}$，使得集合内的任意两条路径 $p_i, p_j$ 的编辑距离或语义距离尽可能大，同时每条边的权重 $w(e)$ 保持在特定阈值之上。

**理论贡献分析：**
论文从理论上探讨了“搜索空间”的复杂性。联想创造力的难点在于搜索空间的组合爆炸。CREATE通过图结构限制了搜索空间，使得问题在理论上可解，但在计算上依然保持一定的难度，这为分析LLM的搜索策略（如贪婪搜索与束搜索的差异）提供了实验依据。

## 4. 实验与结果

**实验设计：**
*   **测试对象**：涵盖了包括GPT-4、Claude、Llama系列在内的多种主流LLM。
*   **评估指标**：主要指标包括**覆盖率**（Coverage）和**有效路径数**（Valid Paths）。覆盖率指模型能复现人类标注的“黄金路径”的比例；有效路径数指模型生成的符合图结构约束的独特路径数量。
*   **对比组**：对比了标准提示、思维链提示以及针对图结构任务优化的特定提示策略对模型性能的影响。

## 最佳实践指南

### 实践 1：构建多模态联想测试基准

**说明**: 基于CREATE方法，设计涵盖文本、图像、音频等多模态输入的联想测试集，评估模型跨模态联想能力。测试应包含远距离联想（RAT）和创造性隐喻生成任务，确保覆盖不同抽象层级的概念关联。

**实施步骤**:
1. 建立包含1000+对概念联想对的标准化数据集
2. 设计跨模态映射任务（如文本生成图像配对）
3. 实施人类专家标注以验证联想有效性

**注意事项**: 需控制文化偏差，建议使用多语言平行测试集

---

### 实践 2：实施动态难度自适应评估

**说明**: 采用贝叶斯优化算法动态调整测试题目难度，避免模型在固定难度测试中产生天花板效应。通过实时分析模型响应质量，自动匹配最优挑战梯度。

**实施步骤**:
1. 建立题目难度分级体系（1-10级）
2. 开发实时性能追踪仪表板
3. 设置自适应阈值触发机制

**注意事项**: 需预留20%的验证集用于校准难度曲线

---

### 实践 3：建立创造性语义空间映射

**说明**: 使用t-SNE或UMAP降维技术可视化模型联想输出的语义分布，量化其与人类创造性思维的偏离程度。重点关注新颖性（偏离常规程度）和适切性（逻辑合理性）的平衡。

**实施步骤**:
1. 收集模型与人类对照组的输出样本
2. 计算语义向量的余弦相似度矩阵
3. 生成2D/3D语义分布热力图

**注意事项**: 需结合领域专家进行定性分析验证

**实施步骤**:
1. 构建5类干扰模板（如反常识、多歧义等）
2. 实施渐进式干扰强度测试

**实施步骤**:

### 实践 7：构建持续学习反馈循环

**实施步骤**:

## 学习要点

- 现有的LLM评估基准主要关注事实性知识和逻辑推理，缺乏对联想创造力这一核心认知能力的有效测试。
- 作者提出了CREATE基准测试，通过评估模型生成新颖物体及其属性的能力，来量化衡量LLM的联想创造力。
- 研究发现LLM在生成“新颖性”方面表现尚可，但在生成“有效性”和“关联性”方面存在显著困难，容易产生幻觉或无关输出。
- 随着模型参数规模的增加，LLM在联想创造力任务上的表现呈现线性增长趋势，表明规模扩展有助于提升该能力。
- 评估揭示了LLM在处理多模态联想（如基于视觉或功能属性的联想）时的局限性，特别是在需要跨领域知识整合的场景下。
- 该研究为未来开发更具创造性和可控性的AI系统提供了重要的评估框架和改进方向。

## 常见问题


### 1: 什么是 CREATE 基准测试，它与传统的 LLM 评估方法有何不同？

1: 什么是 CREATE 基准测试，它与传统的 LLM 评估方法有何不同？

**A**: CREATE（Creative REasoning Across Tasks）是一个专门设计用于评估大型语言模型（LLM）“联想创造力”的新基准测试。与传统的评估方法不同，CREATE 侧重于测试模型在看似无关的概念之间建立新颖且有意义联系的能力，而不是仅仅测试事实回忆、逻辑推理或遵循指令的能力。

传统的 LLM 评估通常集中在 MMLU（多任务语言理解）或 GSM8K（数学问题）等基准上，这些测试主要考察模型的知识广度和逻辑演绎能力。然而，创造力——特别是那种能够结合两个不相关领域元素来解决新问题的“联想创造力”——一直难以量化。CREATE 通过要求模型生成远距离联想（Remote Associates）的解决方案来填补这一空白，从而更准确地衡量 AI 在创造性任务中的潜力。
