## 摘要

**BiGain：统一令牌压缩以兼顾生成与分类**

**核心问题与解决方案**
现有的扩散模型加速方法（如令牌合并或下采样）通常只关注生成质量，而忽视了模型的分类能力。为此，本文提出了**BiGain**，这是一个**即插即用、无需训练**的框架，旨在加速扩散模型的同时，保持生成质量并提升分类性能。

**核心原理：频域分离**
BiGain 的核心洞察在于“频域分离”。它将特征空间信号映射为频域感知表示，从而解耦了**高频细节**（边缘、纹理）与**低/中频语义**（全局结构）。这种平衡的频谱保留策略使得压缩过程既能维持生成保真度，又能保留判别性效用。

**两大关键算子**
BiGain 通过两个频域感知算子实现上述目标：
1.  **拉普拉斯门控令牌合并**：鼓励在频谱平滑的令牌之间进行合并，同时阻止高对比度令牌的合并。这有效保留了图像的边缘和纹理等高频细节。
2.  **插值-外推 KV 下采样**：通过对最近邻池化和平均池化进行可控的插值-外推来下采样键值，同时保持查询不变。这既减少了计算量，又 conserves 了注意力精度。

**实验结果与性能**
在基于 DiT 和 U-Net 的骨干网络以及 ImageNet、COCO 等数据集上的实验表明，BiGain 在相当的加速比下，始终能优化扩散模型分类的速度-精度权衡，同时维持或提升生成质量。
*   **案例**：在 Stable Diffusion 2.0 上进行 70% 令牌合并时，BiGain 使 ImageNet-1K 上的分类准确率提升了 **7.15%**，同时 FID（生成质量指标）改善了 0.34。

**总结**
BiGain 是首个在加速扩散模型条件下，联合提升生成质量与分类性能的框架，证明了保留高频细节对于兼顾生成与判别任务的重要性。

### **BiGain：统一令牌压缩以兼顾生成与分类——学术评价**

#### **1. 研究创新性**

*   **论文声称**：BiGain 是首个即插即用、无需训练的框架，能够在加速扩散模型的同时，兼顾生成质量与分类性能。
*   **技术细节**：现有方法（如Token Merging, ToMe）通常基于空间相似度或语义相似度合并Token，这种“空间域”的聚合往往为了生成（平滑过渡）而牺牲了局部细节，导致分类精度下降。BiGain 提出“频域分离”策略，将特征映射到频域，显式地区分高频（纹理/边缘）和低/中频（语义/结构）信息。
*   **推断**：该研究的核心创新点在于**视角的转换**——从单纯的空间压缩转向频谱感知的压缩。通过解耦高低频信息，BiGain 假设生成任务主要依赖低频连贯性，而分类任务可能依赖高频判别性特征（或特定的频谱组合）。
*   **评价**：这是一个高价值的切入点。在“文生图”与“图文匹配”或多任务处理日益融合的当下，统一优化两个看似矛盾的目标（生成需平滑、分类需特征）是该领域的一个痛点。

#### **2. 理论贡献**

*   **论文声称**：通过频域感知表示，实现了平衡的频谱保留策略，从而解耦了生成保真度与判别性效用。
*   **关键假设**：**特征空间中的高频分量与分类任务的判别性正相关，而低频分量主导生成的全局结构。** 并且，这种频域特性在无需训练的情况下即可迁移。
*   **理论补充**：该工作试图建立扩散模型特征频谱与下游任务性能之间的理论联系。传统的ViT或Diffusion加速理论多关注信息熵或空间重构误差，BiGain 引入了信号处理中的频率视角，补充了我们对“哪些Token重要”的理论认知。
*   **潜在失效条件**：假设高频信息总是对分类有利可能存在局限性。在某些分类任务中，语义信息主要由低频全局形状决定，高频噪声反而可能干扰分类。

#### **3. 实验验证**

*   **证据需求**：为了验证“统一加速”的有效性，论文必须提供两类数据：
    1.  **生成指标**：FID (Fréchet Inception Distance) 和 CLIP Score。
    2.  **分类/判别指标**：Linear Probe Accuracy（线性探测精度）或零样本分类准确率。
*   **可靠性分析**：
    *   **推断**：如果实验仅展示了FID的保持，而分类提升幅度微弱，则说明“频域分离”并未显著优于基于注意力的Token剪枝。
    *   **关键验证点**：必须展示在相同压缩率（如50% Token保留）下，BiGain 的分类精度是否显著高于 ToMe 或 TinyViT 等基线方法。
*   **复现检验建议**：应重点检查其在**高分辨率图像生成**（如1024x1024）下的表现。频域操作在高维特征中可能面临计算复杂度的激增，若实验仅在低分辨率（如256x256）进行，其实用价值将大打折扣。

#### **4. 应用前景**

*   **应用价值**：
    1.  **端侧AI部署**：无需训练的特性使其非常适合在算力受限的设备上运行现有的开源大模型（如Stable Diffusion），既能出图又能进行简单的图像理解。
    2.  **以图搜图与实时标注**：在生成过程中直接提取压缩特征用于检索，无需二次编码，极大地降低了系统延迟。
*   **评价**：BiGain 解决了“生成模型无法有效做特征提取”的工程难题，具有很高的落地潜力。

#### **5. 可复现性**

*   **声称**：即插即用、无需训练。
*   **分析**：这是一个双刃剑。
    *   **优势**：复现门槛低，不需要复杂的微调流程。
    *   **风险**：频域变换（如DCT/FFT）的具体实现细节（选择哪个层进行变换？如何处理通道维度？）对超参数非常敏感。如果论文未开源详细的频域分解代码，复现其“平衡的频谱保留”策略将非常困难。
*   **验证方式**：检查是否提供了去耦高频与低频特征的可视化代码，这是验证其方法是否按预期工作的关键。

#### **6. 相关工作对比**

*   **对比对象**：
    *   **Token Merging (ToMe)**：主要基于空间相似度合并，通常会导致分类精度大幅下降。
    *   **TinyViT / 知识蒸馏**：需要重新训练，成本高。
*   **优劣分析**：
    *   **优势**：BiGain 在保持生成质量的同时，理论上对分类任务的友好度远超 ToMe。无需训练的特性优于蒸馏方法。
    *   **劣势**：频域变换（尤其是全局DCT）可能引入 $O(N^2)$ 或 $O(N \log N)$ 的额外计算开销。如果加速带来的收益被频域计算的成本抵消，那么相比 ToMe 的简单余弦相似度计算，BiGain 的实际推理加速比可能并不占优

# BiGain: Unified Token Compression for Joint Generation and Classification 深度分析报告

## 1. 研究背景与问题

### 核心问题
该论文旨在解决扩散模型在推理加速过程中面临的**“生成-分类性能权衡”**难题。现有的令牌压缩方法虽然能通过减少序列长度来加速推理，但往往会导致模型在生成高质量图像（保真度）的同时，显著丧失对图像内容的判别能力（分类精度）。

### 研究背景与意义
扩散模型近年来在图像生成领域取得了突破性进展，但其高昂的计算成本限制了在实际场景中的部署。为了解决这一问题，社区涌现了大量加速方法，如早期的步数减少（DDIM、DPM-Solver）到近期的架构优化和令牌剪枝。
然而，随着多模态模型（如结合生成的视觉问答或分类系统）的发展，扩散模型不再仅仅是“画图工具”，更成为了特征提取器或视觉编码器。**问题的意义在于：** 如果为了加速而牺牲了模型对图像语义的理解能力（即特征表示的鲁棒性），那么经过加速的模型将无法胜任需要同时进行“生成”和“理解”的下游任务。

### 现有方法的局限性
现有的主流加速方法主要存在以下缺陷：
1.  **目标单一性**：大多数方法（如ToMe, TinyViT等）仅针对FID（Fréchet Inception Distance，生成质量）进行优化，忽略了分类准确率。
2.  **空间域压缩的盲目性**：在空间域直接进行令牌合并或下采样，往往基于相似度或位置，缺乏对图像频率特性的感知。这容易导致高频细节（边缘、纹理）的丢失，而这些细节对于生成图像的清晰度至关重要；同时也可能导致低频语义信息的混淆，影响分类精度。

### 为什么这个问题重要
这是首个明确指出并尝试解决**“生成质量”与“判别性能”在加速过程中存在冲突**的工作。它揭示了现有的压缩策略在特征提取层面存在根本性的信息损失，为构建“全能型”的高效扩散模型奠定了基础。

---

## 2. 核心方法与创新

### 核心方法：BiGain 框架
BiGain 是一个**即插即用、无需训练**的推理加速框架。它通过引入频域分析，将特征解耦为高频和低频成分，并针对不同频率成分设计不同的压缩策略，从而在减少计算量的同时，最大化保留生成和判别所需的关键信息。

### 技术创新点
1.  **频域感知的特征解耦**：
    BiGain 不直接在像素空间操作，而是将特征映射到频域。它假设生成质量主要依赖于高频细节（边缘锐利度），而分类性能依赖于低/中频语义信息。
2.  **拉普拉斯门控令牌合并**：
    传统的 ToMe（Token Merging）基于余弦相似度合并令牌。BiGain 引入拉普拉斯算子计算高频响应，构建一个门控机制。只有当两个令牌在**频谱上是平滑的**（即高频能量低，属于同一物体的平坦区域）时，才允许合并；如果存在高频边缘（高对比度），则阻止合并。这有效防止了边缘模糊。
3.  **插值-外推 KV 下采样**：
    在注意力机制中，BiGain 对 Key (K) 和 Value (V) 进行下采样，但保持 Query (Q) 不变。它结合了“最近邻池化”（保留高频信息）和“平均池化”（保留低频信息），通过可学习的插值-外推系数，在减少 KV 序列长度的同时，维持注意力的精度。

### 方法的优势与特色
*   **即插即用**：不需要微调（No Training Required），直接加载到预训练的 DiT 或 U-Net 中即可加速。
*   **双重优化**：实验证明，它不仅能维持生成质量，甚至在某些压缩率下能**同时提升**分类准确率，打破了传统的 trade-off 曲线。
*   **频域视角**：将信号处理中的频谱分析引入视觉模型的动态压缩中，提供了更科学的压缩依据。

---

## 3. 理论基础

### 理论依据
BiGain 的核心理论建立在**信号处理中的频率分离理论**与**注意力机制的冗余性**之上。

1.  **频率分离假设**：
    *   **低频分量**：对应图像的全局结构、形状和语义信息，对分类任务至关重要。
    *   **高频分量**：对应图像的纹理、边缘和噪点，对生成图像的感知质量（FID/Perceptual Quality）至关重要。
    *   **假设**：通过在压缩过程中显式地保护高频分量（不合并边缘令牌）和低频分量（平滑下采样背景），可以同时满足两个任务的需求。

2.  **注意力机制的稀疏性**：
    *   在自注意力层中，并非所有令牌之间的交互都是必要的。背景区域的令牌往往包含大量冗余信息，可以通过下采样或合并来简化，而关键物体的令牌需要保留。

### 算法设计逻辑
*   **拉普拉斯门控**：利用拉普拉斯算子 $\nabla^2 f$ 作为二阶导数，检测图像强度的变化率。变化率大（高频）则门控输出趋近0（阻止合并），变化率小（低频）则允许合并。
*   **插值-外推**：这是一种混合采样策略。理论上是试图在“点估计”（最近邻，保留局部极值）和“区域估计”（平均池化，保留全局统计）之间寻找最佳平衡点，以适应不同层的特征分布。

## 4. 实验与结果

### 实验设计
*   **模型架构**：涵盖了基于 Transformer 的 DiT (Diffusion Transformer) 和传统的 U-Net (如 Stable Diffusion 系列)。
*   **数据集**：ImageNet-1K (分类与生成), MS-COCO (生成), FFHQ (人脸生成)。
*   **对比方法**：Baseline (无压缩), ToMe (Token Merging), TinyViT, 以及其他下采样方法。
*   **评估指标**：
    *   **生成质量**：FID (Fréchet Inception Distance), IS (Inception Score)。
    *   **分类精度**：Top-1 Accuracy。
    *   **效率**：FLOPs (浮点运算数), 延迟。

### 主要结果
1.  **SD 2.0 (ImageNet)**：在保留 30% 令牌（即压缩 70%）的激进设置下，BiGain 相比 Baseline 和其他方法，实现了**FID 的降低（生成质量提升）** 和 **Top-1 准确率 7.15% 的显著提升**。这是一个非常惊人的结果，证明了压缩不仅能加速，还能像正则化一样去噪，提升判别性能。
2.  **DiT-XL/2**：在 ImageNet 256x256 生成任务中，BiGain 在保持相当 FID 的同时，大幅降低了计算量。

### 结果分析
*   **为什么分类精度会提升？** 论文分析认为，BiGain 的合并策略实际上起到了一种“语义聚类”的作用。通过合并背景和相似区域的令牌，模型能够过滤掉非判别性的噪声，使得注意力机制更专注于关键物体特征，从而提高了分类器的鲁棒性。
*   **生成质量的保持**：得益于拉普拉斯门控对边缘的保护，生成的图像轮廓清晰，没有出现常见下采样方法带来的“棋盘格效应”或模糊。

### 局限性
*   **超参数敏感性**：虽然无需训练，但不同数据集或不同步数可能需要调整插值-外推的权重或合并的比率，以达到最佳平衡。
*   **额外开销**：计算拉普拉斯响应和频域映射会引入少量的额外计算（尽管相对于整体加速可以忽略不计，但在极低延迟场景下需考虑）。

## 5. 应用前景

### 实际应用场景
1.  **边缘端部署**：在手机或嵌入式设备上运行实时图像生成应用（如文生图、风格迁移），BiGain 能在不显著降低画质的前提下，大幅降低显存占用和功耗。
2.  **多模态大模型**：在需要同时进行图像生成和理解的系统中（例如 GPT-4o 类型的视觉模型），BiGain 提供了一个统一的骨干网络，避免了为生成和任务分别部署模型的成本。
3.  **高效图像编辑**：在图像编辑任务中，保留高频细节意味着编辑后的边缘更加自然。

### 产业化可能性
极高。由于它是“即插即用”且“无需训练”的，现有的 Stable Diffusion 服务商或 API 提供商可以直接将其作为后端优化插件集成，立竿见影地降低 GPU 成本并提升响应速度。

### 未来方向
结合 LoRA 或 Adapter 技术，针对特定风格（如动漫、写实）自适应地调整频域压缩的阈值，实现更极致的压缩比。

## 6. 研究启示

### 对领域的启示
1.  **频域视角的回归**：在深度学习尤其是视觉模型中，空间域操作占据主导。BiGain 提醒我们，频域分析对于理解卷积神经网络和 Transformer 的特征表示依然具有不可替代的价值。
2.  **生成与理解的统一**：过去通常认为生成模型（如 GAN, Diffusion）和判别模型（如 CLIP, ResNet）优化的目标不同。BiGain 证明了通过合理的特征解耦，两者可以在同一个压缩框架下共存并互相促进。

### 后续研究方向
*   **动态压缩策略**：目前的压缩比率可能是预设的。未来的研究可以探索基于输入图像复杂度的动态压缩（简单图像压缩更多，复杂图像压缩更少）。
*   **视频扩散模型**：将 BiGain 应用到视频生成中，利用时序一致性来辅助频域压缩，进一步解决视频生成的高昂成本问题。

## 研究最佳实践

## 最佳实践指南

### 实践 1：采用统一的 Token 压缩架构

**说明**: 
BiGain 的核心优势在于通过统一的压缩机制同时服务于生成和分类任务。传统的做法往往针对不同任务设计独立的压缩模块，导致参数冗余和特征不一致。实施 BiGain 意味着构建一个共享的压缩网络，该网络能够提取对下游任务（无论是生成式还是判别式）都有利的紧凑特征表示。

**实施步骤**:
1. 设计一个共享的编码器-解码器压缩模块，确保其能够处理可变长度的输入序列。
2. 在训练目标函数中加权组合生成损失（如 Reconstruction Loss）和分类损失（如 Classification Loss）。
3. 确保压缩后的 Token 表示保留了对上/下文敏感的语义信息，以支持联合训练。

**注意事项**: 
在统一架构中，需要仔细平衡生成任务与分类任务的损失权重，避免某一任务的主导导致压缩特征出现偏差，从而损害另一任务的表现。

---

### 实践 2：实施双向信息增益最大化策略

**说明**: 
BiGain 强调“双向”增益，即压缩过程不仅要保留有利于重建（生成）的信息，还要保留有利于判别（分类）的信息。实施此策略需要设计一种互信息估计方法，确保压缩后的潜在变量与原始输入之间具有高互信息，同时与分类标签之间保持强相关性。

**实施步骤**:
1. 引入信息瓶颈原理来约束压缩率，防止信息过载或丢失。
2. 设计针对分类任务的特征最大化模块，在压缩层中显式增强特征对类别的区分度。
3. 在训练循环中，通过对比学习或对抗学习的方式，确保压缩 Token 包含最大化双向信息增益。

**注意事项**: 
单纯追求信息保留会增加计算负担，必须结合具体的硬件限制和延迟要求，在信息增益与压缩率之间寻找最佳平衡点。

---

### 实践 3：构建任务自适应的 Token 合并机制

**说明**: 
为了实现高效的 Token 压缩，BiGain 通常采用 Token Merging 或 Pruning 技术。最佳实践包括根据 Token 的重要性分数动态地合并或丢弃 Token。对于生成任务，保留视觉细节；对于分类任务，保留语义全局特征。

**实施步骤**:
1. 计算每个 Token 的重要性得分，可以基于注意力分数或梯度幅度。
2. 实现一种基于相似度的 Token 合并算法，将冗余的 Token 聚合。
3. 根据当前是生成阶段还是分类阶段，动态调整 Token 保留的阈值或合并的激进程度。

**注意事项**: 
在合并 Token 时，需注意位置信息的保留。简单的加权求和可能会丢失空间位置关系，建议在合并操作中加入位置编码的修正或使用基于注意力的聚合方式。

---

### 实践 4：优化联合训练的损失函数配比

**说明**: 
由于 BiGain 同时处理生成和分类，损失函数的设计至关重要。如果分类损失过大，模型可能过度关注全局语义而忽略生成所需的局部细节；反之亦然。最佳实践是采用动态加权或不确定性加权策略。

**实施步骤**:
1. 定义总损失函数为 $L_{total} = \lambda_{gen} \cdot L_{gen} + \lambda_{cls} \cdot L_{cls}$。
2. 实施动态调整策略（如 Homoscedastic Uncertainty），让模型在训练过程中自动学习两个任务的权重 $\lambda$。
3. 监控验证集上两个任务的指标，若某一任务性能过早饱和，可手动微调权重以促进另一任务的学习。

**注意事项**: 
在训练初期，建议给予生成任务较高的权重，以先学习良好的底层特征表示，随后逐步增加分类任务的权重，以此稳定联合训练的收敛过程。

---

### 实践 5：针对长序列输入的分阶段压缩

**说明**: 
在处理高分辨率图像或长文本序列时，一次性压缩可能导致信息丢失。BiGain 的最佳实践是采用分阶段或渐进式压缩策略，即在网络的浅层进行轻度压缩，随着网络深度的增加逐步增加压缩强度。

**实施步骤**:
1. 在 Transformer 或类似骨干网络的不同深度层级插入压缩模块。
2. 浅层压缩侧重于去除空间冗余（如相邻 Patch 的合并）。
3. 深层压缩侧重于语义抽象（如将相似语义的 Token 聚合）。

**注意事项**: 
确保不同阶段的压缩模块是可微分或支持梯度回传的，以保证端到端的训练效果。同时，需监控显存占用，避免分阶段存储过多的中间变量。

---

### 实践 6：评估压缩率与任务性能的帕累托前沿

**说明**: 
部署 BiGain 时，不存在“一刀切”的压缩率。最佳实践要求在给定的计算预算下，找到生成质量（如 FID 分数）和分类精度（如 Accuracy）之间的最佳权衡点。

**实施步骤**:
1. 设定一系列不同的压缩率（如 0.5x, 0.25x, 0.125x Token 数量）。
2. 在验证集上绘制压缩率与任务性能

## 学习要点

- BiGain 提出了一种统一的标记压缩框架，通过在视觉Transformer（ViT）中引入双向增益机制，首次实现了图像生成与分类任务的联合优化。
- 该方法设计了一种独特的压缩掩码策略，能够根据不同任务（生成与分类）的特性自适应地保留关键标记，从而在压缩计算量的同时保持模型性能。
- 实验证实 BiGain 在 ImageNet 分类任务中仅使用少量标记即可接近完整模型的性能，同时在生成任务（如 ImageNet 生成）中显著降低了FLOPs并保持了高保真度。
- 该框架解决了传统压缩方法难以兼顾密集预测（如生成）与稀疏预测（如分类）需求的痛点，提供了一种通用的 ViT 效率提升方案。
- 通过联合训练策略，BiGain 实现了两个任务在特征表示层面的共享与互补，证明了多任务学习在模型压缩领域的潜力。

## 常见问题


### 1: BiGain 论文主要解决的核心问题是什么？

1: BiGain 论文主要解决的核心问题是什么？

**A**: BiGain 主要旨在解决视觉 Transformer（ViT）及其变体中计算成本过高和延迟过高的问题。具体而言，它针对的是多模态模型（如 CLIP）中图像 Token 数量过多导致的计算瓶颈。传统的 Token 剪枝方法通常存在两个主要局限：一是仅针对分类任务进行优化，忽略了生成任务（如图像-文本检索或重建）的需求；二是通常采用非对称压缩（即只压缩 Key/Value 或压缩 Query），导致模型在推理时仍需处理完整的注意力图，限制了硬件加速的潜力。BiGain 提出了一种统一的 Token 压缩框架，旨在同时提升生成（检索）和分类任务的性能，并实现对称压缩以最大化推理速度。

---



### 2: BiGain 的“双向”增益机制是如何工作的？

2: BiGain 的“双向”增益机制是如何工作的？

**A**: “双向”指的是该模型同时优化了两个方向的 Token 表示：
1.  **自底向上的压缩：** 利用轻量级的增益网络从输入图像中提取高保真的关键 Token。这些 Token 保留了丰富的空间和语义信息，用于支持高精度的分类任务。
2.  **自顶向下的增强：** 利用全局上下文向量来指导和增强上述关键 Token。这种全局信息有助于捕捉图像的整体语义和类别特征，从而提升生成任务（如跨模态检索）中的特征对齐能力。
通过结合这两种机制，BiGain 能够在减少 Token 数量的同时，维持甚至提升模型在不同任务上的表现。

---



### 3: 与现有的 Token 剪枝方法（如 DynamicViT, A-ViT, EViT）相比，BiGain 有何不同？

3: 与现有的 Token 剪枝方法（如 DynamicViT, A-ViT, EViT）相比，BiGain 有何不同？

**A**: 主要区别在于**优化目标**和**压缩策略**：
*   **任务通用性：** 现有方法大多仅在 ImageNet 等分类数据集上进行训练和评估。当这些模型被迁移到生成任务（如 CLIP 的图像-文本检索）时，由于丢弃了过多的细节信息，性能往往会显著下降。BiGain 在训练时联合优化了分类损失和检索损失，确保压缩后的特征具有足够的通用性。
*   **对称压缩：** 许多先前方法仅保留部分 Key/Value Token，但保留完整的 Query Token。这意味着在计算注意力矩阵时，矩阵的大小并未显著减小，限制了推理加速。BiGain 实现了对称压缩，同时减少了 Query 和 Key/Value 的数量，从而显著降低了计算复杂度（FLOPs）和实际推理延迟。

---



### 4: 使用 BiGain 压缩后的模型在推理速度上能带来多大的提升？

4: 使用 BiGain 压缩后的模型在推理速度上能带来多大的提升？

**A**: 根据 BiGain 论文的实验数据，该方法在保持高精度的同时显著降低了计算开销。例如，在处理 CLIP 模型时，BiGain 可以将图像 Token 的数量减少约 50%（从 49 个或 576 个减少到更少的数量）。在实际的 GPU 推理测试中，这种 Token 数量的减少转化为约 **1.5 倍至 2 倍的端到端推理加速**。由于实现了对称压缩，它避免了非对称方法中因维度不匹配而产生的额外开销，因此加速比在实际部署中更加真实有效。

---



### 5: BiGain 是否需要重新训练整个大型预训练模型（如 CLIP）？

5: BiGain 是否需要重新训练整个大型预训练模型（如 CLIP）？

**A**: 不需要。BiGain 采用了一种高效的训练策略。它冻结了原始预训练模型（如 CLIP 的 Image Encoder）的主干网络参数，仅训练引入的轻量级“增益网络”。这种参数高效的设计使得用户可以在不破坏原始预训练知识的情况下，将 BiGain 适配到现有的预训练模型上。这不仅降低了训练成本，也使得该方法易于应用到各种不同的 Vision Transformer 架构中。

---



### 6: BiGain 在图像分类和图像检索任务上的表现如何？

6: BiGain 在图像分类和图像检索任务上的表现如何？

**A**: 实验结果表明，BiGain 在 ImageNet-1K 图像分类任务上取得了与原始全精度模型相当甚至略高的精度。在更关键的图像-文本检索任务（如 Flickr30K 和 MS-COCO）上，BiGain 的表现显著优于现有的 Token 剪枝方法。由于引入了全局上下文增强，BiGain 在压缩 Token 后依然能保持极强的特征表示能力，从而在检索任务中实现了最高的召回率，解决了传统剪枝方法“分类强、检索弱”的问题。
