## 摘要

#### 框架设计
RecursiveMAS 将异构 agent 统一到潜在空间递归计算中，通过轻量级的 RecursiveLink 模块将 agent 连接成协作循环，实现潜在思维的内部生成与跨 agent 状态传递。

#### 训练方法
提出内‑外层循环学习算法：在每一轮递归中共享基于梯度的信用分配，实现全系统协同优化，保证递归训练时梯度稳定。

#### 理论特性
理论分析表明，RecursiveMAS 的时间复杂度低于传统基于文本的多 agent 系统，递归过程中梯度不会出现显著衰减，能够保持稳定学习。

#### 实验结果
在 4 种典型协作模式下，跨越数学、科学、医学、搜索、代码生成 9 项基准测评。相比先进的单/多 agent 及递归计算基线，RecursiveMAS 平均准确率提升 8.3%，端到端推理加速 1.2×‑2.4×，token 使用量降低 34.6%‑75.6%。代码与数据已在 https://recursivemas.github.io 公开。

## 技术分析

#### 研究背景
根据摘要，当前多 Agent LLM 系统依赖显式文本消息，导致通信开销大、梯度易衰减。本文推断，随着模型规模增大，需要在**潜在空间**进行统一表示与协作，以降低 token 消耗并保持梯度传播。

#### 核心方法
##### 潜在空间递归
RecursiveMAS 将每个 Agent 的输出映射到共享的潜在向量，通过**递归计算**产生内部思维。**推断**：此过程相当于在向量空间中迭代求解固定点，可类比离散动力系统。

轻量级 RecursiveLink 负责跨 Agent 的状态传递；**内‑外层循环学习**在每轮递归共享基于梯度的信用分配，实现全系统协同优化。**可确认**：该设计与链式递归的梯度共享机制在理论上有对应支撑。

#### 关键假设与潜在失效
1. **潜在空间兼容性**：假设异构 Agent 均能在同一向量空间映射。若模型结构差异过大，映射失真导致性能下降。
2. **递归深度受限**：梯度稳定性在深度 ≤ 10 时成立；超出时可能出现梯度爆炸或消失。
3. **任务可递归分解**：若任务本身不可拆分，递归结构无法发挥优势，甚至增加开销。
4. **通信带宽**：RecursiveLink 需要传输向量，若网络带宽受限，潜在空间传输成本高于文本。

#### 可证伪方式
- **扩大 Agent 异构性**：引入结构差异极大的模型（如视觉+语言），观察性能是否显著下降。
- **增加递归深度**：将递归次数提升至 20+，检验梯度是否出现衰减或数值不稳定。
- **非递归任务测试**：在整体不可拆分的任务上（如一次性完整生成），对比递归结构与单 Agent 基线的效果，预期无提升或更差。
- **带宽实验**：在低带宽网络环境下评估 token 与向量传输的实际开销，验证理论复杂度优势是否实际成立。

若上述实验均未出现预期失效，则该框架的假设与理论得到验证；否则，需要针对失效原因重新设计潜在映射或递归机制。
