# 示例1：计算量子纠缠态的保真度
def entanglement_fidelity(state1, state2):
    """
    计算两个量子态之间的保真度
    参数:
        state1: 第一个量子态的复数向量
        state2: 第二个量子态的复数向量
    返回:
        两个态之间的保真度值(0-1之间)
    """
    import numpy as np
    
    # 将输入转换为numpy数组
    psi1 = np.array(state1, dtype=complex)
    psi2 = np.array(state2, dtype=complex)
    
    # 计算内积
    inner_product = np.vdot(psi1, psi2)
    
    # 保真度是内积模的平方
    fidelity = np.abs(inner_product)**2
    return fidelity

# 测试用例
state_a = [1/np.sqrt(2), 1/np.sqrt(2)]  # |+⟩ 态
state_b = [1, 0]  # |0⟩ 态
print(f"保真度: {entanglement_fidelity(state_a, state_b):.4f}")
```

# 示例2：模拟黑洞霍金辐射的温度
def hawking_temperature(mass, solar_mass=1.989e30):
    """
    计算黑洞的霍金辐射温度
    参数:
        mass: 黑洞质量(kg)
        solar_mass: 太阳质量(kg)
    返回:
        霍金温度(Kelvin)
    """
    import numpy as np
    
    # 物理常数
    hbar = 1.0545718e-34  # 约化普朗克常数
    c = 299792458  # 光速
    G = 6.67430e-11  # 万有引力常数
    k_B = 1.380649e-23  # 玻尔兹曼常数
    
    # 计算霍金温度
    T = (hbar * c**3) / (8 * np.pi * G * mass * k_B)
    return T

# 计算不同质量黑洞的温度
masses = [1e12, 1e20, solar_mass, 1e6*solar_mass]
for m in masses:
    print(f"质量 {m:.2e} kg 的黑洞温度: {hawking_temperature(m):.4e} K")
```

### 2: AI 是如何辅助发现新的物理公式或结果的？

2: AI 是如何辅助发现新的物理公式或结果的？

**A**: AI 在理论物理中的应用通常基于**数据驱动**的方法，常见的技术是**符号回归**。

其工作流程通常如下：
1.  **数据输入**：将实验观测到的数据（如天体运行轨迹、粒子散射数据）输入 AI 系统。
2.  **模式识别**：AI 尝试用各种基础的数学运算（加、减、乘、除、三角函数等）去拟合这些数据。
3.  **筛选与优化**：AI 搜索既能精确匹配数据，又遵循“奥卡姆剃刀”原则（即公式越简洁越好）的数学表达式。
4.  **结果输出**：AI 输出一个人类可读的数学公式，该公式可能对应一个新的物理假设或对已知定律的修正。

### 3: AI 生成的结果可靠吗？是否经过了验证？

3: AI 生成的结果可靠吗？是否经过了验证？

**A**: AI 生成的结果在被视为科学事实之前，必须经过严格的**人类验证**。

AI 擅长寻找数学上的相关性，但它并不理解物理意义（如因果关系、守恒定律或量纲分析）。AI 可能会找到一个在数学上完美拟合数据，但在物理上缺乏解释性的公式。因此，这些“新结果”目前主要被视为**候选假设**，需要物理学家通过进一步的实验和理论推导来确认其有效性。
