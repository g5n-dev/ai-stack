## 摘要

本文提出了一种名为**黎曼流匹配与雅可比正则化**的新方法，旨在解决标准扩散transformer在表征编码器的特征空间中无法收敛的问题。

**主要发现与问题定义：**
现有的研究表明，利用表征编码器进行生成建模具有高效和高保真的潜力。然而，标准的扩散transformer（DiT）无法直接在这些表征上收敛。近期研究将此归因为模型“容量瓶颈”，并建议通过增加模型宽度来解决，但这会导致计算成本高昂。本文通过实验证明，这一失败的根源其实是**几何性的**，而非容量不足。作者将其核心原因识别为**几何干扰**：即标准的欧几里得流匹配强迫概率路径穿过超球形特征空间（表征编码器的输出空间）内部的低密度区域，而不是沿着流形表面进行。

**解决方案（RJF）：**
为了解决这个问题，作者提出了RJF方法。该方法通过将生成过程限制在流形测地线上，并校正由曲率引起的误差传播，从而解决了几何干扰问题。这使得标准Diffusion Transformer架构无需增加宽度即可实现收敛。

**实验结果：**
实验表明，RJF方法使得标准的DiT-B架构（参数量1.31亿）能够有效收敛，达到了3.37的FID分数，而此前的标准方法在同样条件下无法收敛。

### 实践 1：利用预训练表征编码器替代原生 Patch Embedding

**说明**:
标准 Diffusion Transformer (DiT) 架构通常采用基于卷积的 Patch Embedding 层将图像像素映射为潜在 Token。本指南的核心创新在于解耦这一过程，利用在大规模视觉数据集（如 CLIP 或 VAE）上预训练好的表征编码器来替代随机初始化的 Patch Embedding。这能让模型直接在高质量的语义流形上进行初始化，从而加速收敛并提升生成质量。

**实施步骤**:
1. 选择一个与生成任务对齐的预训练模型（例如用于图像生成的 VAE Encoder 或用于语义对齐的 CLIP Vision Encoder）。
2. 移除标准 DiT 模型中的 `PatchEmbed` 模块。
3. 将预训练编码器的输出维度通过适配层映射到 DiT 输入所需的维度。
4. 冻结预训练编码器的权重，仅训练适配层和 DiT 的 Transformer Block。

**注意事项**:
确保预训练模型的输出空间分辨率与 DiT 的输入要求匹配，可能需要引入池化或插值操作来对齐 Token 数量。

### 实践 2：流形空间的解耦训练策略

**说明**:
该方法强调“在流形上学习”，即生成模型不应从像素噪声中重建图像，而应在预训练编码器定义的潜在流形空间内进行去噪。实施时，需要构建一个两阶段的训练流程，先学习流形映射，再在流形空间内学习扩散过程，以避免模型在训练初期陷入高频像素噪声的陷阱。

**实施步骤**:
1. **阶段一（流形对齐）**：训练一个轻量级的适配器，将随机噪声映射到预训练编码器的潜在空间分布。
2. **阶段二（扩散训练）**：冻结预训练编码器，仅在潜在空间中对 DiT 模型进行标准的扩散训练（预测噪声或速度）。
3. 联合微调：在上述两阶段稳定后，对整体网络进行低学习率的端到端微调。

**注意事项**:
在阶段一中，需监控 KL 散度或重建损失，以确保生成的潜在向量分布在预训练模型的有效支持域内，避免流形漂移。

### 实践 3：引入自适应层归一化

**说明**:
为了使预训练的表征编码器（通常具有固定的特征分布）与动态变化的扩散过程（时间步 $t$ 和类别条件 $c$）有效融合，必须在 Transformer Block 中引入自适应机制。这不仅仅是简单的拼接，而是通过调制特征统计量来实现条件注入。

**实施步骤**:
1. 在 DiT 的每个 Transformer Block 中，将时间步嵌入和类别嵌入投影为缩放因子和偏置参数。
2. 用自适应层归一化替换标准的 Layer Normalization。
3. 确保调制参数作用于从表征编码器传入的 Token，而非仅作用于自注意力层的输出。

**注意事项**:
计算 AdaLN 参数时应避免维度爆炸，通常使用两层 MLP (SiLU 激活) 将时间/条件向量映射为所需的缩放/偏置参数。

### 实践 4：多尺度特征融合

**说明**:
单一尺度的预训练特征可能丢失细节信息。最佳实践包括利用编码器的中间层特征（多尺度特征），将这些不同分辨率的特征图展平并拼接，作为 DiT 的输入。这相当于为 Transformer 提供了多尺度的上下文信息。

**实施步骤**:
1. 提取预训练编码器不同深度的特征图（例如 1/4, 1/8, 1/16 分辨率）。
2. 将这些特征图分别展平为 Token 序列。
3. 通过线性投影层统一不同 Token 的维度，并将它们拼接成一个长序列输入给 DiT。
4. 在 DiT 内部添加位置编码以区分不同来源的 Token。

**注意事项**:
Token 序列的长度的增加会显著增加注意力机制的二次方计算复杂度。如果序列过长，建议在 DiT 内部使用 Flash Attention 或类似的注意力优化技术。

### 实践 5：零样本/少样本迁移配置

**说明**:
利用强大的预训练表征编码器，可以实现模型在不同领域间的快速迁移。例如，使用在自然图像上训练的编码器来指导医学图像或特定艺术风格的生成，而无需从头训练整个扩散模型。

**实施步骤**:
1. 锁定在源数据集上训练好的表征编码器。
2. 替换或微调 DiT 的 Adapter 层以适应目标域的图像分布。
3. 使用极少的目标域数据对 DiT 主干进行微调（LoRA 或全参数微调）。

**注意事项**:
评估源域和目标域在预训练编码器空间中的语义距离。如果距离过远，可能需要重新训练编码器或使用域适应技术。
