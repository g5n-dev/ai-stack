## Key Features

  * Multi-mode gallery browsing (normal, favorites, subscriptions, watched, popular)
  * Advanced search with filters (category, rating, uploader, tags)

  * Tag system with translation support (10+ languages)

### Gallery Management

  * Cloud-synced favorites (10 categories)
  * Local favorites for offline access
  * Reading history with timestamps
  * Quick search templates for frequent queries

  * Multi-threaded parallel downloads with configurable worker count
  * Two-tier storage: temporary cache (40-640MB) and persistent storage
  * Download queue with pause/resume/retry support

  * Label-based organization and filtering

  * Multiple reading modes (left-to-right, right-to-left, vertical)

  * Custom hosts database
  * Domain fronting capability
  * Proxy configuration support

  * 10 supported languages: Chinese (Simplified/Traditional/Hong Kong), Japanese, Korean, English, German, Thai, French, Spanish

# 1. 技术架构深度剖析 🏗️

### 技术栈与架构模式
*   **混合编程范式**：
    *   **上层 (UI/Logic)**：采用 **Java + Kotlin** 混合开发。从文件名 `UpdateDialog.kt` 可以看出，项目正在逐步向 Kotlin 迁移，利用其现代化的语言特性（如 Coroutines 协程、扩展函数）处理异步任务和 UI 逻辑。
    *   **底层 (Core/Engine)**：核心图片处理和编解码逻辑使用 **C/C++ (JNI)**。`app/src/main/cpp` 目录下的 CMakeLists.txt 证明了这一点。这种架构模式通常称为 **"分层架构"** 或 **"菱形架构"**，即 UI 层与底层高性能引擎通过 JNI 桥接。
*   **构建系统**：使用 **Gradle** 进行构建管理，配合 **CMake** 管理原生 C++ 代码。这是 Android NDK 开发的标准配置。

### 核心模块与关键设计
*   **图片引擎**：这是该项目的灵魂。不同于大多数 Android App 直接使用 `Glide` 或 `Picasso`，EhViewer 系列通常自研或深度定制图片加载器。`UnikeryDrawable.java` 和 `ImageBitmapHelper.java` 表明其拥有自定义的 Drawable 系统和 Bitmap 管理机制，旨在解决大图（如长条漫画）加载时的 OOM（内存溢出）问题。
*   **应用生命周期管理**：`EhApplication.java` 暗示了全局状态的管理，包括崩溃处理、内存监控和全局配置初始化。

### 技术亮点与创新点
*   **极致的内存管理**：通过 JNI 将图片解码逻辑下沉到 C++ 层，直接操作 Native 堆内存，绕过 Java 堆的 Bitmap 分配限制（尤其是在 Android 旧版本上），并利用内存映射（mmap）技术高效读取大文件。
*   **自定义渲染管线**：不依赖系统的 ImageView，而是通过自绘或高度定制的 View 来实现图片的分块加载、缩放和滤镜效果。

# 2. 核心功能详细解读 🎯

### 主要功能与场景
*   **Gallery 浏览**：针对 E-Hentai 和 ExHentai 网站的专门优化阅读器。
*   **高性能图片解码**：支持 JPEG、PNG、GIF 以及 WebP 等格式，特别是针对压缩包内的图片进行直接读取（无需解压到磁盘）。
*   **标签与元数据管理**：复杂的本地数据库存储标签、评分和收藏状态。

### 解决的关键问题
