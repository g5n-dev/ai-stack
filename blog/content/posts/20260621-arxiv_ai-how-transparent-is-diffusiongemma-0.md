## 摘要

#### 变量透明性
DiffusionGemma 在连续潜空间中进行大量计算，表面上其不透明串行深度（inter‑state 计算量）比自回归的 Gemma 4 高约 28.6 倍。通过在去噪步骤之间引入可解释的 token 瓶颈，将信息流向映射为可读状态，可在不损失下游性能的前提下将不透明深度降至 1.1 倍，接近自回归模型的水平。

#### 算法透明性
在扩散模型中，所有 token 在每一步去噪都可能改变，使其具备实现复杂分布式算法的能力，这导致算法层面的透明性比自回归模型更难获取。为缩小差距，作者进行了一系列可解释性案例研究，发现了非时序推理、token 与序列的“涂抹”（smearing）以及中间上下文推理等扩散特有的现象。

#### 可监测性
可监测性是透明度的重要应用，评估模型输出对下游任务的可用性。实验表明，DiffusionGemma 与 Gemma 4 在可监测性上表现相当，说明其推理过程虽在潜空间展开，但仍能提供有效的监督信号。

#### 小结
尽管 DiffusionGemma 的变量透明度起初看似远低于自回归模型，但通过 token 瓶颈的可解释映射即可大幅提升；而在算法层面，扩散模型展现出独特的推理模式，给可解释性带来新挑战。整体上，DiffusionGemma 在可监测性上与 Gemma 4 持平，为后续更深入的透明性研究奠定了基础。

## 技术分析

#### 研究背景
- 大语言模型（LLM）正从自回归（AR）向扩散（diffusion）架构迁移，以实现更高的生成并行度。
- 扩散模型在连续潜空间中进行多步去噪，导致“变量透明性”和“算法透明性”难以评估。
- 本文聚焦 **DiffusionGemma**，首次系统度量其在变量、算法及可监测三个维度的透明度。

##### 核心方法与理论
- **变量透明性**：定义“不透明串行深度”（opaque serial depth）为模型在去噪步骤间的累计计算量。
- **Token Bottleneck**：在每两个去噪步骤之间插入可解释的 token 映射，将潜状态投影到人类可读的 token 空间，从而压缩不透明深度。
- **理论依据**：若信息流可被有限 token 捕获，则模型的计算等价于在 token 维度上的线性组合，理论上可将深度降至接近 AR 水平。

##### 实验与结果
- 基准对比：DiffusionGemma（无 bottleneck）的不透明深度约为 AR Gemma 4 的 **28.6 倍**。
- 引入 token bottleneck 后，不透明深度降至 **1.1 倍**，性能保持不变。
- **案例研究**揭示：
  1. **非时序推理**：模型在去噪早期即可预测远距离依赖。
  2. **Token 与序列的涂抹（smearing）**：同一 token 在多步间出现模糊分布。
  3. **中间上下文推理**：在去噪中段出现对前文信息的跨步聚合。
- **可监测性**：下游任务（问答、摘要）上，DiffusionGemma 与 Gemma 4 的监控指标相当，说明潜空间仍提供有效监督信号。

##### 应用前景
- **可解释调试**：通过 token bottleneck 可直接检查每步激活的语义单元，便于定位错误生成。
- **安全与合规**：透明度的提升有助于在监管环境中提供模型决策的可追溯性。
- **跨模态生成**：扩散架构天然适合图像-文本联合生成，透明度工具可迁移至多模态模型。

##### 研究启示
- **变量透明性**可通过结构化瓶颈快速提升，说明其核心瓶颈在于信息的表示方式而非计算量。
- **算法透明性**仍是难点，扩散模型的全局交互特性导致传统注意力可视化不足以解释其推理过程，需要新的概念化工具。
- **可监测性**结果表明，即使在潜空间运行，模型仍能保持对下游任务的适用性，为进一步的理论分析提供了实验依据。

##### 关键假设、潜在失效与可证伪方式
- **假设**：token bottleneck 能捕获所有关键信息，且不引入额外偏差。
  - **失效条件**：若模型在特定语言现象（如长程依赖）上依赖潜空间非线性组合，bottleneck 可能丢失关键信号。
- **假设**：不透明串行深度是衡量透明度的有效代理。
  - **失效条件**：若模型通过并行计算实现等价语义，深度度量会低估实际复杂度。
- **可证伪方式**：
  1. 移除 bottleneck，对比下游任务性能；若性能显著下降，则说明 bottleneck 捕获了必要信息。
  2. 使用概念探测（concept probing）检查 token 表征是否对应人类可解释的语义；不匹配则暗示信息未被完整映射。
  3. 通过干预实验（如强制某步去噪固定）验证推理路径的可解释性，若结果与预期不符，则透明度评估需重新定义。
