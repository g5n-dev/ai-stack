## 核心结论

量化是将大模型的浮点参数转换为低位整数存储的技术手段。FP16 权重经过量化后可以转为 INT8 或 INT4 表示，显著降低显存占用和计算量。以 INT4 为例，精度从 16 位压缩到 4 位，存储空间降至原来的四分之一，但会产生不可避免的精度损失。量化过程需要计算 scale 参数来完成浮点与整数之间的双向转换。

## 能力机制

量化的核心是将连续的浮点数值映射到离散的整数编码。以一组范围在 [-0.2, 0.2] 的浮点数为例，需要映射到 [-2, -1, 0, 1, 2] 这五个整数刻度。具体做法是先确定浮点数的区间范围，然后在每个刻度位置标记对应的整数标签。映射时每个浮点数会找到离自己最近的刻度并贴上该刻度的整数标签。

对称 INT4 量化采用更规范的映射流程。假设权重范围为 [-0.2, 0.2]，INT4 有符号整数用二进制补码表示，编码范围是 [-8, 7]。零偏移设为 0，这体现了「对称」特性——0 轴两侧的编码范围完全对称。

计算 scale 的行业标准公式为 s = A / 7，其中 A 是原始权重极值的最大绝对值。公式中使用 7 而非 8 作为分母，是为了确保最大的正权重 A 能够精确对应到 q=7 这个正数侧的最大编码，避免正向溢出导致权重失真。选择 s = A / 8 虽然负数侧更宽松，但会导致正数侧编码不足。

浮点转整数量化公式为 w_int = clip(round(w_float / scale), Qmin, Qmax)，包含三个步骤：除以 scale 得到相对位置、四舍五入取最近整数、截断到合法范围 [-8, 7]。以 w=0.1 为例，除以 scale 得到 3.5，四舍五入后为 4。以 w=-0.18 为例，除以 scale 得到约 -6.3，四舍五入后为 -6。

反量化使用重建公式 ŵ = q × s 将整数编码还原为浮点数近似值。q=4 对应 ŵ=4×scale，q=-6 对应 ŵ=-6×scale。由于整数档位有限，原始值与还原值之间必然存在误差。

## 快速开始

对称量化实施需要按顺序完成以下步骤。

第一步，统计原始权重的最大值 w_max 和最小值 w_min，确定参数的实际取值范围。第二步，计算最大绝对值 A = max(|w_max|, |w_min|)。第三步，计算 scale 参数 s = A / 7，其中 7 是 INT4 正数侧的最大编码值。第四步，使用公式 w_int = clip(round(w_float / s), -8, 7) 将每个浮点权重转换为对应的整数编码。第五步，推理时通过 ŵ = q × s 将整数编码还原为浮点数进行计算。

## 适用边界

对称量化存在两个主要局限。

当权重分布偏离零点时会产生编码浪费。如果权重全是正值如 [0, 0.2]，负数侧的编码档位完全无法利用。这种情况下需要改用非对称量化方案，允许存在零点偏移以充分利用编码空间。

极端离群值会破坏全局精度。如果权重中混入了 0.8 这样的极端值，为了容纳它而放大全局 scale，会导致 0.1 附近的正常权重全部被压缩到同一档位。解决思路是采用分组量化，将权重分成多个小组各自计算 scale，将极端值的影响限定在局部范围内。

## 核验清单

评估量化方案时需确认以下要素。

scale 计算是否正确使用了 A/7 而非 A/8，确保正数侧编码空间被充分利用。量化公式是否包含除法、四舍五入、截断三个完整步骤。截断范围是否为 [-8, 7] 的合法 INT4 区间。反量化重建公式是否为 ŵ = q × s。是否考虑了权重分布的对称性，必要时采用分组量化或非对称量化处理离群值。
