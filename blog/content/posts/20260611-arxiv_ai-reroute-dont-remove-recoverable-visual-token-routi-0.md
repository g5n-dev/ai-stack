## 摘要

#### 背景
视觉语言模型（VLM）把图像映射为成百上千个视觉 token，导致解码器的注意力计算和 KV‑cache 存储开销巨大。现有 token 压缩方法大多采用“先打分、后永久删除”的“筛选‑去除”模式。

#### 问题
删除操作不可逆，但 token 的重要性会随解码层深度变化，尤其在需要细粒度定位（grounding）的查询中，低层分数低的 token 可能在后层重新变得关键，导致信息丢失。

#### 方法——Reroute
Reroute 是一种无需训练的即插即用方案，将不可逆的删除替换为可恢复的路由。
- **路由阶段**：对视觉 token 打分后，部分 token 进入解码块处理，另一部分 token 被“延迟”，绕过本层并重新进入下一路由决策的候选池。
- **复用已有规则**：Reroute 直接利用已有的注意力分数排序规则和分层调度，保持原剪枝方法的理论 TFLOPs 与 KV‑cache 预算类别不变。

#### 实验结果
在 LLaVA‑1.5 和 Qwen 两种骨干网络上，对 FastV、PDrop、Nüwa 等变体进行测试：
- 在激进的 token 删减比例下，Reroute 显著提升了细粒度定位任务的准确率。
- 同时保持通用视觉问答（VQA）性能不下降。

#### 结论
VLM token 压缩不应仅被视为一次性剪枝，而应视为可恢复的路由问题。Reroute 通过延迟而非删除，实现了更灵活、更高效的资源利用。代码已开源：https://github.com/elmma/mllm-reroute/
