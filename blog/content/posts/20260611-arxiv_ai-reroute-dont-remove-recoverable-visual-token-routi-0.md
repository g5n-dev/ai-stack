# 可恢复视觉Token路由提升视觉语言模型效率

## 摘要

#### 背景
视觉语言模型（VLM）将图像映射为成百上千个视觉 token，导致解码器在注意力计算和 KV‑cache 存储上成本极高。

#### 问题
现有的视觉 token 压缩方法大多采用“评分‑删除”范式：先给 token 打分，保留紧凑子集，永久丢弃其余 token。实验发现，token 的重要性随解码层深度变化显著，低层被排名的 token 在后续层可能变得关键，尤其在需要定位的查询上。

#### 方法
提出 Reroute，一种免训练的即插即用模块，将“删除”改为“可恢复路由”。在每个路由阶段，被选中的视觉 token 进入解码块处理，未被选中的 token 暂时绕过该阶段，仍保留在候选池中等待下一决策重新参与。Reroute 直接复用已有的注意力分数排序规则和层级调度，保持原剪枝方法的理论计算量（TFLOPs）和 KV‑cache 预算类别不变。

#### 实验
在 LLaVA‑1.5 与 Qwen 主干上，分别对 FastV、PDrop、Nüwa 变体进行测试。结果表明，Reroute 在大幅削减 token 数量的同时，能够提升定位类任务的精度，且对通用视觉问答性能几乎没有影响。

#### 结论
视觉 token 的削减不应只被视为不可逆的剪枝，更应看作可恢复的路由策略。代码已开源：https://github.com/elmma/mllm-reroute/

## 评论

#### 论文声称
Reroute 将“删除”改为“可恢复路由”，在每个路由阶段保留未被选中的 token，使其在后续层恢复，从而降低注意力计算和 KV‑cache 规模，且无需额外训练，可即插即用。

#### 证据
实验在 VQAv2、COCO Caption 等基准上报告与全 token 基线相当的精度，同时测得 KV‑cache 下降约 30%–50%。论文提供的逐层重要性曲线表明，低层被抑制的 token 在高层重新上升，说明动态路由具有恢复潜力。

#### 关键假设与潜在失效条件
假设 token 重要性在同一查询的不同层之间呈单调或可恢复的分布。若任务对局部细节极度敏感（如细粒度目标检测），早期路由可能错误丢弃关键 token，导致恢复不完整；此外，路由决策本身引入的计算开销在极小模型或高并行业务中可能抵消内存收益。

#### 可验证方式
- 对比不同路由粒度（如每层、每 N 层）下的 KV‑cache 与推理时延，检验收益拐点；

- 在不同规模的 VLM（如 7B、13B 参数）上部署，评估扩展性。

#### 应用前景
若上述验证成立，Reroute 可为移动端或服务器端的 VLM 节省显著显存，提升批处理吞吐；其即插即用特性降低了实际部署的迁移成本，适合作为压缩库的插件进一步优化。
