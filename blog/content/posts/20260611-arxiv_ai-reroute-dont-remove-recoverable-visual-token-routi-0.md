## 摘要

#### 背景

视觉-语言模型（VLM）将图像映射为成百上千的视觉 token，导致解码器在注意力计算和 KV‑cache 存储上都非常昂贵。

#### 现有方法的问题

当前的 token 削减大多采用“排序后去除”策略：先对 token 打分，仅保留分数最高的部分，永久丢弃其余 token。然而 token 的重要性随解码层深度变化，早期被低分的 token 在后续层可能重新变得关键，尤其在需要定位（grounding）的查询中。

#### Reroute 方法

提出 Reroute，一种免训练的即插即用模块，将不可逆的删除改为可恢复的路由。每一层路由阶段，选中的 token 进入解码块，未被选中的 token 被暂时跳过（Bypass），但不丢弃，而是重新进入下一阶段的候选池。Reroute 直接复用已有的注意力分数排名规则和层级调度，保持原有剪枝方法的理论 TFLOPs 与 KV‑cache 预算类别不变。

#### 实验结果

在 LLaVA‑1.5 与 Qwen 主干上，对 FastV、PDrop、Nüwa 等不同 token 削减方案进行实验。结果显示，Reroute 在激进 token 削减下显著提升了定位任务的准确率，同时保持通用视觉问答（VQA）性能不掉。

#### 结论

研究表明，视觉 token 削减不应仅视为不可逆的剪枝，而应视作可恢复的路由问题。代码已开源：https://github.com/elmma/mllm-reroute/

## 技术分析

#### 研究背景与问题

视觉-语言模型（VLM）将输入图像转换为成百上千个视觉token，这种设计虽然保留了细粒度视觉信息，却导致解码器在注意力计算和KV-cache存储上承受巨大的计算负担。当前主流的token削减方法普遍采用“排序后去除”策略：先对所有token根据重要性打分，仅保留分数最高的部分，其余token被永久丢弃。这种不可逆的删除机制在推理效率和视觉信息保留之间形成了固有的矛盾。

现有方法存在两个核心问题。其一，token的重要性并非静态不变，而是随解码层深度动态变化。早期被低分标记的token在后续层可能重新变得关键，尤其是在需要视觉定位（grounding）的查询中。其二，永久性删除导致信息损失无法恢复，限制了模型在需要综合多层次视觉特征任务上的表现。

#### 核心方法：Reroute机制

Reroute提出了一种免训练的即插即用模块，将不可逆的token删除转化为可恢复的路由问题。其核心创新在于引入"Bypass"机制：未被当前层选中的token不会直接丢弃，而是暂时跳过该层的解码块，重新进入下一路由阶段的候选池。这种设计允许token在后续层重新获得被处理的机会，从而实现信息的动态恢复。

从实现细节来看，Reroute直接复用已有的注意力分数排名规则和层级调度策略。每层的路由阶段首先对候选池中的token进行重要性评估和排序，选中的token进入解码块进行处理，未选中的token则通过Bypass路径保留到下一阶段。该方法保持了原有剪枝方法的理论TFLOPs与KV-cache预算类别不变，意味着不会引入额外的计算开销。

#### 理论基础与分析

Reroute的有效性建立在视觉特征层级抽象的理论假设上。深层网络倾向于提取更抽象、更任务相关的特征，而浅层特征往往更加通用。早期被低分标记的token可能在后续层获得更高的相关性评分，因为后续层的注意力机制能够根据任务上下文重新评估token的价值。

这一设计符合条件计算（conditional computation）的基本思想，即根据输入动态决定计算路径。与完全跳过token的方法不同，Reroute保留了所有token的参与机会，只是改变了它们的参与时机，从而在效率和完整性之间取得平衡。

#### 实验结果与性能分析

根据摘要信息，实验在LLaVA-1.5与Qwen两个主流VLM主干上进行，测试对象包括FastV、PDrop、Nüwa等不同token削减方案。结果显示，Reroute在激进token削减条件下显著提升了定位任务的准确率，同时保持通用视觉问答（VQA）性能基本不变。这一发现验证了可恢复路由策略的实际价值，特别是在需要细粒度视觉定位的任务中效果更为明显。

#### 应用前景与局限

Reroute的即插即用特性使其具有广泛的部署潜力。它可以与现有token削减方案无缝集成，无需额外训练即可获得性能提升。对于资源受限的部署场景，该方法能够在保持较低计算成本的同时减少信息损失。

然而，方法的有效性依赖于几个关键假设。首先，它假设token重要性确实随层深变化且后续层评分具有参考价值。其次，Bypass机制假设未被处理的token在后续层能够获得足够的关注机会。如果模型架构本身对token的层级顺序敏感，或者某些token在首次未选中后难以重新获得关注，Reroute的效果可能受限。

#### 研究启示

这项工作的核心贡献在于重新定义视觉token削减问题：从不可逆的剪枝转变为可恢复的路由。这一视角转变启发后续研究关注token的动态参与模式，而非仅追求静态的token数量减少。Reroute证明了在VLM效率优化中，保留信息流通的灵活性可能比单纯降低计算量更为重要。
