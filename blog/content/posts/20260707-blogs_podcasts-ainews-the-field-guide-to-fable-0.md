## 学习要点

- Fable 是将 F# 代码编译为 JavaScript 的工具，使开发者可以在 Web 前端使用强类型函数式编程。
- 通过 Fable，开发者能够直接调用 npm 包和 JavaScript 生态系统的丰富库，同时保持类型安全。
- Fable 支持 React、Elmish 等前端框架，提供声明式 UI 编写方式，提升代码可维护性。
- 在 F# 与 TypeScript/JavaScript 之间可以共享类型定义，减少重复代码并提升 IDE 的智能提示。
- 生成的 JavaScript 支持源码映射，使开发者能够在浏览器中直接调试 F# 源码。
- Fable 通过 tree‑shaking 与代码分割帮助生成更小、更快的 Web 应用。
