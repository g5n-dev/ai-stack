## 摘要

**STAMP：一种基于选择性任务感知机制的文本隐私保护框架**

**1. 核心概念与目标**
STAMP（Selective Task-Aware Mechanism for Text Privacy）是一种新型的文本隐私保护框架，旨在解决差分隐私中隐私保护与数据效用难以兼顾的难题。其核心思想是实现“任务感知”的文本私有化，即在保护敏感信息的同时，尽可能保留对下游任务有用的数据特征。

**2. 关键技术机制**
STAMP 的创新性主要体现在以下两个方面：

*   **选择性预算分配（Token级分区）：**
    STAMP 摒弃了传统方法对文本统一加噪的做法，而是从“Token级”粒度进行精细化控制。它会综合评估两个维度：
    1.  **任务重要性：** 该词对下游任务的贡献程度（通过任务特定的表示来衡量）。
    2.  **隐私敏感度：** 该词包含的敏感信息量（如人名、日期、ID等）。
    基于此，STAMP 能够在不同部分分配不同的隐私预算，对高敏感度且对任务无用的信息加强保护，对关键任务信息减少扰动。

*   **极坐标扰动机制：**
    为了对词嵌入进行私有化，STAMP 引入了“极坐标机制”。与传统在各向同性的空间中添加随机噪声不同，该机制仅在**单位球上扰动嵌入向量的方向**，而保持其模长不变。
    *   **解码优势：** 解码过程采用余弦最近邻搜索，这与扰动的几何特性完美契合。
    *   **语义保持：** 该机制能更好地维持嵌入空间中的语义邻域关系，避免因加噪破坏词与词之间的语义距离。

**3. 实验结果与效果**
在 SQuAD、Yelp 和 AG News 等标准数据集上的实验表明，结合了归一化极坐标机制的 STAMP 框架，在面对不同的 Token 隐私预算设置时，均能取得优于现有方法的“隐私-效用”权衡。

*   **论文声称**：STAMP 提出了一种“选择性任务感知”机制，打破了差分隐私（DP）在文本处理中“统一加噪”的传统范式，实现了隐私保护与数据效用的更好平衡。

    *   **细粒度控制的突破**：将隐私预算分配下沉到 Token 级是极具挑战性的，因为必须严格遵循组合定理。如果 STAMP 成功实现了这一点，这标志着文本隐私技术从“粗粒度文本脱敏”向“语义级隐私保护”的迈进。

#### **2. 理论贡献**

*   **论文声称**：构建了一个基于“任务感知”的文本私有化框架，旨在解决差分隐私中保护与效用难以兼顾的难题。

    *   **理论挑战**：在差分隐私中，对单个 Token 进行独立的隐私预算分配极易导致隐私预算的线性累积，使得总隐私预算迅速耗尽（$\epsilon$ 值爆炸）。

# 深入分析报告：STAMP 文本隐私保护框架

## 1. 研究背景与问题

### 核心问题
该论文致力于解决自然语言处理（NLP）领域中一个经典的博弈难题：**如何在严格保护文本隐私（满足差分隐私，DP）的前提下，最大程度地保留数据对下游任务的效用**。

### 背景与意义
随着 GDPR 等数据隐私法规的实施，医疗、金融等领域的敏感文本数据（如电子病历、评论记录）的共享与利用面临巨大挑战。差分隐私作为目前最严格的隐私保护标准，通过向数据中注入数学噪声来掩盖个体贡献。然而，文本数据具有高维、稀疏和语义依赖性强的特点。传统的 DP 方法（如对整个文本或词向量统一加噪）往往会导致“过保护”或“欠保护”——即为了保护无关紧要的词而破坏了整句句法的完整性，或者为了保留语义而泄露了隐私。

### 现有方法的局限性
1.  **统一加噪：** 现有方法通常对文本中的所有 Token 分配相同的隐私预算，或者对整个嵌入向量添加高斯噪声。这导致对任务至关重要的关键词被过度扰动，而无用的停用词却消耗了宝贵的预算。
2.  **语义空间破坏：** 在欧几里得空间中添加各向同性的高斯噪声，容易改变词向量的模长，从而破坏嵌入空间中的语义邻域结构，导致下游任务（如分类、QA）性能急剧下降。

### 重要性
STAMP 的提出标志着文本隐私保护从“粗粒度、盲目加噪”向“细粒度、任务感知”的范式转变。它不仅提升了隐私保护的效率，更使得在高度敏感的文本数据上进行深度学习成为可能。

---

## 2. 核心方法与创新

### 核心方法
STAMP 框架包含两个核心组件，形成了一套“感知-分配-扰动”的闭环流程：

1.  **选择性预算分配机制：**
    *   **任务感知：** 利用下游任务模型（如 BERT）的注意力权重或梯度信息，计算每个 Token 对最终预测结果的贡献度。
    *   **隐私敏感度：** 利用预定义的规则或命名实体识别（NER）模型，评估 Token 包含的隐私信息量（如人名、地点）。
    *   **动态分配：** 根据上述两个维度，构建优化目标。对“高敏感度且低任务贡献”的 Token 分配极小的隐私预算（加重噪），对“低敏感度且高任务贡献”的 Token 分配较大预算（加轻噪）。

2.  **极坐标扰动机制：**
    *   **几何变换：** 将词嵌入向量的扰动空间从笛卡尔坐标系转换到极坐标系。
    *   **方向扰动：** 仅在单位球面上对向量的**方向（角度）**添加噪声，严格保持向量的**模长**不变。
    *   **解码重构：** 在解码阶段，通过余弦相似度（Cosine Similarity）在私有词表中查找最接近的向量进行替换。

### 技术创新点
*   **Token 级差分隐私：** 将隐私预算的粒度从句子级细化到 Token 级，实现了隐私保护的空间局部化。
*   **模长保持假设：** 首次在文本 DP 中系统性利用“词义由方向决定，模长代表频率/领域特性”的几何性质，通过极坐标扰动规避了模长噪声对语义距离的破坏。

## 3. 理论基础

### 理论依据
1.  **局部差分隐私：**
    STAMP 遵循严格的 LDP 定义。对于每个 Token $x$，其扰动后的输出 $y$ 满足 $\frac{P(y|x)}{P(y|x')} \leq e^{\epsilon}$。论文通过串行组合定理，证明了整个句子的隐私损耗由所有 Token 隐私预算之和的上界决定。

2.  **向量空间几何学：**
    *   **假设：** 在预训练词嵌入空间（如 Word2Vec, GloVe, BERT 嵌入）中，语义相似度主要由向量夹角决定。
    *   **机制：** 极坐标机制利用 von Mises-Fisher 分布或球面上的高斯分布对方向进行采样。从信息论角度看，这种方法去除了对语义分类无用甚至有害的“模长信息”噪声。

3.  **隐私-效用权衡优化：**
    SBA 机制本质上是一个优化问题。在总隐私预算 $\epsilon_{total}$ 固定的约束下，寻找最优的预算分配向量 $\{\epsilon_1, \epsilon_2, ..., \epsilon_T\}$，以最大化下游任务的期望效用。

### 理论贡献
论文从理论上证明了在单位球面上进行方向扰动相比于欧氏空间扰动，在保留语义邻域结构方面具有更小的期望误差上界。

## 4. 实验与结果

### 实验设计
*   **数据集：** 涵盖了三种典型任务——**SQuAD**（阅读理解/抽取式）、**Yelp**（情感分析/分类）、**AG News**（主题分类/短文本）。
*   **对比基准：** 与传统的局部差分隐私方法（如 dX-X, DP-SGD）以及针对文本优化的方法（如 PrivBERT）进行对比。
*   **评估指标：** 下游任务的准确率/ F1分数 vs. 隐私预算 ($\epsilon$)。

### 结果分析
1.  **显著的效用提升：** 在相同的隐私预算（特别是低预算 $\epsilon < 2$）下，STAMP 在所有数据集上的表现均显著优于基线方法。
2.  **极坐标机制的优势：** 消融实验证明，使用“极坐标扰动 + 余弦解码”的组合明显优于“高斯扰动 + 欧氏距离解码”。这验证了保持模长对于维持嵌入空间几何结构的重要性。
3.  **预算分配的有效性：** 可视化结果显示，STAMP 成功地将更多预算分配给了实义词（如名词、动词），而将极少的预算分配给停用词或敏感实体。

### 局限性
*   **计算开销：** SBA 机制需要计算梯度或注意力权重来评估任务重要性，这增加了预处理阶段的计算成本。
*   **解码偏差：** 由于必须从预定义的词表中选择最近邻，这可能导致生成的私有化文本出现“OOV（Out-of-Vocabulary）”问题或无法处理生僻词。

## 5. 应用前景

### 实际应用场景
1.  **医疗病历共享：** 医院可以发布经过 STAMP 处理的电子病历文本，供研究机构训练疾病预测模型，既保护了患者姓名和ID，又保留了症状描述的关键特征。
2.  **智能客服与质检：** 企业可以利用 STAMP 对用户对话记录进行脱敏，然后交给第三方进行模型训练或人工质检，避免泄露用户隐私。
3.  **金融风控：** 对贷款申请中的文本说明进行隐私化处理，用于反欺诈模型训练。

### 产业化可能性
*   **优势：** 框架模块化，可插入现有的 BERT/Transformer 流程中。
*   **挑战：** 需要针对特定领域微调“任务重要性”评估模块，否则预算分配可能不准确。

### 未来方向
结合大语言模型（LLM）的生成能力，利用 STAMP 的思想指导 LLM 生成满足差分隐私的合成文本，而非简单的词替换。

## 6. 研究启示

### 对领域的启示
*   **从“保护数据”到“保护语义”：** 未来的文本隐私保护不应仅仅关注数据点的匿名化，更应关注语义空间的流形结构保护。
*   **任务驱动的隐私：** 隐私保护不应是脱离应用的，必须与具体的下游任务紧密耦合。

### 后续研究方向
1.  **上下文感知的扰动：** STAMP 目前主要针对单个 Token，未来可研究如何对词组或短语进行联合扰动，以保持局部句法连贯性。
2.  **自适应预算分配：** 利用强化学习动态调整预算分配策略，以适应数据分布的变化。
