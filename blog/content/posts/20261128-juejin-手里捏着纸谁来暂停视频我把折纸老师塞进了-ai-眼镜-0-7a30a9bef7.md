## 核心结论

《折纸》是一款面向 Rokid AI 眼镜的亲子折纸智能体，已在 AIUI Studio 开发并形成上架版本。其核心不是让模型识别用户手中的纸，而是把课程、几何动画、语音命令和模型理解拆开处理：动画负责展示“这一折”，本地程序负责切换、重播与放慢，模型只在选款、歧义理解和当前步骤答疑时介入。

这种分工确保步骤编号、动画和课程说明使用同一份页面状态。用户未说“下一步”前，当前折叠会持续循环；只有明确确认后，程序才进入下一步或完成页。

## 能力机制

课程数据把每一步拆成固定纸片、移动纸片、折后形状、折线、提示和动作类型。固定纸与移动纸分开表示，因此动画能够明确区分哪些区域不动、哪些区域翻转，而不是只播放一张模糊的结果图。

折叠计算以二维投影为基础：先求点在线段上的垂足，再围绕该垂足旋转。绘图层继续处理抬起高度、纸层遮挡、前后关系和层序，支持翻面、展开及四角向中心折等动作。屏幕尺寸变化时，课程使用归一化坐标，再换算到画布位置。

每个动作按“起点停留、折叠移动、结果停留”循环。不同课程可配置不同动作时长；“慢一点”只把移动段拉长至 1.55 倍，起点和结果仍保留停留时间。重播会重置动画起点，但不会改变步骤编号。

语音最终结果才会触发操作，并通过集合去重。明确命令包括“确认”“下一步”“上一步”“再看一遍”“慢一点”和“返回首页”。镜腿按键也进入同一处理入口，其中方向键映射为上一步和下一步，重复事件在 180 毫秒内会被忽略。

课程名称和常见简称先与本地目录匹配。遇到否定、多个候选或超出固定表达时，才交给 `LanguageModel`。模型上下文包含课程目录、页面阶段、当前作品和当前步骤，返回类型限定为 `select`、`help`、`unsupported`；程序还会校验课程是否存在、回复是否为空及长度。模型可以解释步骤或选择已有课程，但不能生成一套新教程或改写动画。

## 快速开始

在 AIUI Studio 新建智能体后，先通过“对话创建”搭起工程，再进入代码页。来源中的工程约定包括：首页选择作品、查看成品与纸张要求、语音确认、循环演示当前折叠，以及支持上一步、重播、慢一点和返回首页。

主要文件划分为：

```text
app.json                 页面与权限
app.js                   生命周期
lib/fold.js              课程、命令、模型
lib/draw.js              几何与绘制
pages/index/index.ink    状态与事件
```

页面配置可按来源保留为：

```json
{
  "name": "折纸",
  "permissions": ["RECORD_AUDIO"],
  "pages": ["pages/index/index"],
  "window": { "navigationBarTitleText": "折纸" }
}
```

运行后可使用这些已实现的语音命令：

```text
确认
下一步
上一步
再看一遍
慢一点
返回首页
```

工程建议：继续沿用“课程数据、绘制逻辑、页面状态”分离的结构。新增课程时，应同时补齐纸张要求、每一步说明、折线与移动区域、动作时长及完成页所需信息，避免只增加文字而没有可播放动画。

## 适用边界

该版本不拍摄用户手中的纸，也不判断纸是否已经折对。早期通过拍照判断纸形的方案，在尖角翻到背面后出现连续误判，因此完成确认改由用户控制。模型只能依据课程内容解释“这一折往哪里折”，不能核验实体纸张的完成状态。

课程目录目前包含纸飞机、东南西北、弹跳青蛙、会说话的小狗、纸杯、纸响炮、页角书签、小鱼和小帆船。页角书签、小鱼和小帆船被设计为五步课程；不同作品对 A4 长方形纸或正方形纸的要求不同，选课阶段必须先提示。

模型调用等待上限为 30 秒，超时或失败时保留当前步骤；用户在此期间发出明确命令，可取消旧任务并执行新操作。模拟器可以提交语音识别文字，但真实佩戴、收音效果和亲子跟折体验仍需分别测试。

## 核验清单

1. 从选款进入预览，确认作品名称、纸张要求与步骤数一致。
2. 预览阶段说“确认”，检查是否从第一步开始，而不是直接播放后续动画。
3. 跟随演示完成一折后停止操作，确认动画仍循环且步骤编号不变。
4. 分别执行“下一步”“上一步”“再看一遍”“慢一点”“正常”“返回首页”，核对索引、动画起点和速度状态。
5. 在同一课程中提问，确认模型只解释当前步骤，不把问题误判为选款或完成。
6. 使用“不要纸飞机”“纸飞机还是小鱼”等表达，检查系统是否先澄清而不是直接跳转。
7. 对模型回复执行格式与课程 ID 校验，确认无效选择、空回复或超长回复不会进入页面状态。
8. 等待模型时发送明确命令，确认旧请求被取消，当前课程和步骤不被异步结果覆盖。
9. 切换课程或离开页面，确认动画、语音识别、语音播放和模型会话均被清理。
10. 在模拟器完成流程后，再分别验证眼镜端真实收音、按键操作和实际跟折效果。
