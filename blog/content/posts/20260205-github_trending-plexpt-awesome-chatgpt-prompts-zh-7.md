## 代码示例



```python
# 示例1：批量处理ChatGPT提示词
def process_prompts(prompt_list):
    """
    处理ChatGPT提示词列表，添加通用前缀和后缀
    :param prompt_list: 原始提示词列表
    :return: 处理后的提示词列表
    """
    processed = []
    for prompt in prompt_list:
        # 添加角色设定
        processed.append(f"作为一个专业的AI助手，请{prompt}。请确保回答准确且有帮助。")
    return processed

# 测试用例
raw_prompts = ["解释量子纠缠", "推荐几本Python书籍", "写一首关于春天的诗"]
print(process_prompts(raw_prompts))
```


此代码实现了一个基础的提示词质量评估工具，能够自动检测提示词的完整性并提供改进建议，帮助用户优化ChatGPT提示词设计。

```python
# 示例2：提示词效果评估工具
def evaluate_prompt_quality(prompt):
    """
    评估提示词质量的简单工具
    :param prompt: 待评估的提示词
    :return: 评分(0-10)和改进建议
    """
    score = 10
    suggestions = []
    
    # 检查提示词长度
    if len(prompt) < 10:
        score -= 3
        suggestions.append("提示词过短，建议增加更多细节")
    
    # 检查是否包含具体要求
    if "请" not in prompt and "要求" not in prompt:
        score -= 2
        suggestions.append("建议添加明确的请求或要求")
    
    if "格式" not in prompt and "输出" not in prompt:
        score -= 1
        suggestions.append("建议指定输出格式")
    
    return score, suggestions

# 测试用例
test_prompt = "写一篇关于AI的文章"
print(evaluate_prompt_quality(test_prompt))
```

## 最佳实践

## 最佳实践指南

### 实践 1：明确角色设定

**说明**: 通过为 ChatGPT 分配具体的角色或身份（如"资深程序员"、"专业翻译"、"面试官"等），可以显著提升回答的专业性和针对性。角色设定有助于 AI 调整其语气、用词和思考角度。

**实施步骤**:
1. 在提示词开头使用 "Act as a..." 或 "你扮演..." 的句式
2. 详细描述角色的专业背景、性格特点和职责范围
3. 结合具体任务场景补充角色的上下文信息

**注意事项**: 避免使用模糊不清的角色定义，确保角色与任务需求高度匹配

---

### 实践 2：采用分步思维链

**说明**: 对于复杂的逻辑推理、数学计算或编程问题，要求 AI 展示中间思考步骤可以大幅提高结果的准确性。这种方法迫使模型在给出最终答案前进行更深入的推理。

**实施步骤**:
1. 在提示词中明确要求 "Let's think step by step" 或 "请一步步思考"
2. 要求 AI 列出关键推导过程或计算步骤
3. 对复杂任务可要求先给出解题思路再执行

**注意事项**: 确保步骤之间的逻辑连贯性，必要时可要求验证中间结果

---

### 实践 3：提供少样本示例

**说明**: 通过在提示词中提供 2-3 个理想的输入-输出示例，可以更精确地引导 AI 理解预期的格式、风格和质量标准。这比单纯的语言描述更有效。

**实施步骤**:
1. 准备 2-3 个具有代表性的高质量示例
2. 使用清晰的分隔符区分示例和实际任务
3. 确保示例覆盖任务的主要变化维度

**注意事项**: 示例必须准确反映期望的输出标准，避免提供矛盾或低质量的示例

---

### 实践 4：设置输出约束

**说明**: 明确规定回答的格式、长度、结构等约束条件，可以获得更规范、更易处理的输出结果。特别适用于需要批量处理或结构化数据的场景。

**实施步骤**:
1. 明确指定输出格式（如 JSON、Markdown 表格、列表等）
2. 设置合理的长度限制（字数或段落数）
3. 定义必须包含或排除的内容要素

**注意事项**: 约束条件应合理且可执行，过度限制可能影响回答质量

---

### 实践 5：建立迭代优化机制

**说明**: 将复杂任务分解为多轮交互，通过逐步细化要求、纠正偏差来获得最佳结果。这种方法特别适用于创意写作、代码开发等需要持续改进的任务。

**实施步骤**:
1. 首先获取初步方案或草稿
2. 针对具体问题提出修改建议
3. 要求 AI 解释关键决策或提供替代方案
4. 逐步完善直到满足要求

**注意事项**: 保持修改建议的具体性和可操作性，避免模糊的反馈

---

### 实践 6：利用上下文参考

**说明**: 通过提供相关背景材料、数据集或文档片段，可以让 AI 生成更贴合具体场景的回答。这种方法能显著减少幻觉现象，提高事实准确性。

**实施步骤**:
1. 使用三引号或代码块分隔参考材料
2. 明确说明材料的使用方式（如"基于以下内容..."）
3. 对长文档可采用分块引用+摘要的方式

**注意事项**: 确保提供的参考材料准确可靠，避免包含矛盾信息

---

### 实践 7：应用思维框架

**说明**: 引入专业的思维模型或分析框架（如 SWOT、5W1H、金字塔原理等）可以提升回答的结构性和深度。这种方法特别适用于商业分析、问题诊断等场景。

**实施步骤**:
1. 在提示词中指定使用的思维框架
2. 简要说明框架的应用规则
3. 要求输出严格遵循框架结构

**注意事项**: 确保选择的框架与任务性质匹配，避免过度复杂化简单问题

2: 如何使用这些提示词？
