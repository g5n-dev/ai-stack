## 摘要

ActionParty是一种可控制多主体动作的视频扩散世界模型，旨在解决现有模型在多智能体场景下的动作绑定难题。它引入主体状态token——持续捕获每个主体状态的潜在变量——并通过空间偏置机制将状态token与视频潜在表示联合建模，实现全局画面渲染与各主体动作控制的解耦。在Melting Pot基准上评估，ActionParty首次实现同时控制最多七名玩家的视频世界模型，覆盖46种多样化环境。实验结果显示，该模型在动作跟随准确性和身份一致性上显著提升，并能够在复杂交互中保持鲁棒的自主回归跟踪。

## 技术分析

#### 研究背景
##### 问题定义
多主体视频生成是生成式游戏世界的核心挑战：模型不仅要合成高保真画面，还必须把每个玩家的动作精准绑定到对应角色上，实现同步控制。现有基于扩散的视频生成模型（如 Denoising Diffusion Probabilistic Models）在单主体或少量主体时表现尚可，但在多智能体、长时间序列的交互场景中，动作绑定（action binding）易出现身份混淆、动作漂移等问题（摘要）。

##### 现有方法局限
- **缺乏显式状态抽象**：大多数模型直接在像素空间或潜空间进行动作调节，缺乏对每个主体内部状态的独立捕获。
- **空间/时序耦合**：传统交叉注意力或条件注入难以在全局渲染与局部动作之间实现解耦，导致对多主体的控制不够精细（推断）。
- **规模受限**：多数基准仅覆盖 2–3 名玩家，难以验证模型在更高并发度下的鲁棒性（摘要）。

#### 核心方法
##### 主体状态 token
ActionParty 为每个玩家引入 **主体状态 token**（subject state token），该 token 在每个时间步持续编码对应玩家的姿态、意图及交互上下文。通过在扩散过程的前向噪声注入阶段对 token 进行条件化，实现对单主体状态的持续捕获（摘要）。

##### 空间偏置机制
利用 **空间偏置（spatial bias）** 将主体状态 token 与视频潜在表示进行空间对齐。具体做法是将 token 与对应的空间位置特征进行加权交互，使每个 token 的影响范围限定在对应角色的像素区域，从而在全局渲染时保留局部控制（摘要）。

##### 联合建模与解耦
模型将全局画面生成任务与多主体动作控制任务进行 **联合训练**：
- 全局分支负责整体场景布局、光照等；
- 主体分支通过状态 token 与空间偏置实现细粒度动作绑定。
两者共享底层扩散骨干，实现信息共享与解耦（推断）。

#### 理论基础
##### 视频扩散模型
采用 Latent Diffusion Model（LDM）框架，先将视频压缩至低维潜在空间，再在潜在空间执行扩散-去噪过程。主体状态 token 通过 cross‑attention 注入，使去噪网络能够在生成过程中感知每个玩家的动作约束（摘要）。

##### 状态表示学习
主体状态 token 通过自监督或动作标签监督学习得到，保持对姿态、意图等高层语义的捕获。空间偏置通过位置编码实现，使 token 与特定空间区域产生对应关系，理论上保证每个玩家的动作仅影响其对应区域（推断）。

#### 实验与结果
##### 评估基准与指标
在 **Melting Pot** 基准（包含 46 种多样化交互环境）上实验，使用两项关键指标：
- **动作跟随准确率**（Action Following Accuracy）：衡量生成动作与输入动作的一致性；
- **身份一致性**（Identity Consistency）：衡量同一玩家在不同帧中外观与身份的保持程度（摘要）。

- 在长时间自回归生成（>30 步）中仍保持低漂移率，验证了其鲁棒的自回归跟踪能力（摘要）。

##### 极限与鲁棒性
- 随着玩家数量增加（>7）或交互密度提升，性能下降趋势平缓，表明模型对多主体规模具备一定可扩展性（推断）。

##### 关键假设
1. **状态 token 足以完整表征玩家状态**：假设 token 能够捕获姿态、意图、交互历史等全部关键信息。
2. **空间偏置能够在所有场景下准确定位角色**：假设角色在不同帧的视觉定位误差不影响 token 的空间对应关系。

##### 失效条件
- **遮挡严重或快速运动**：空间偏置可能失效，导致动作误绑定到相邻角色。
