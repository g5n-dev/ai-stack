## 导语

针对智能体强化学习常因依赖稀疏结果奖励而忽视中间推理质量的问题，本文提出了 Agent-RRM（智能体推理奖励模型）。该模型通过提供包含显式推理链、纠错指导及过程评分的结构化反馈，设计了三种训练策略以细化奖励信号。实验显示，统一反馈策略显著提升了智能体在复杂推理基准上的表现，不过模型对计算资源的具体需求尚无法从摘要确认。这一工作为优化智能体推理过程提供了新的奖励建模思路。

## 摘要

本文针对智能体强化学习主要依赖**稀疏结果奖励**（仅关注最终对错）而忽略中间推理质量的问题，提出了**Agent-RRM（智能体推理奖励模型）**。该模型提供包含**显式推理链、针对性纠错指导及过程评分**的结构化反馈。基于此，作者设计了Reagent-C、Reagent-R和Reagent-U三种训练策略。实验表明，统一反馈策略（Reagent-U）效果最佳，在GAIA和WebWalkerQA基准上分别达到43.7%和46.2%的性能，验证了细化推理奖励能显著提升智能体的复杂推理能力。

## 评论

**论文评价：Exploring Reasoning Reward Model for Agents**

**总体评价**

本文针对当前基于大语言模型（LLM）的智能体在强化学习（RL）训练中面临的“奖励稀疏”与“过程黑箱”问题，提出了**Agent-RRM（智能体推理奖励模型）**。该工作试图通过显式建模中间推理步骤的质量来替代传统的仅关注最终结果的二元奖励，是连接大模型“过程监督”与“智能体决策”的一次重要尝试。

以下从七个维度进行深入剖析：

### 1. 研究创新性

*   **Claim（声称）**：现有的Agent RL训练主要依赖Outcome Reward Models（ORM），即只看最终结果对错，忽略了推理路径的质量。本文提出的Agent-RRM能够提供包含显式推理链、纠错指导和过程评分的结构化反馈。
*   **Evidence（证据）**：作者设计了三种训练策略：Reagent-C（基于ORM的对比学习）、Reagent-R（基于RRM的推理重构）和Reagent-U（统一反馈）。实验显示，Reagent-U在GAIA基准上达到43.7%，显著优于基线。
*   **Inference（推断）**：该研究的核心创新在于将“过程奖励模型（PRM）”的思想系统性地迁移到复杂的Agent任务中。
    *   **新发现**：单纯的“纠错”并不总是带来性能提升（Reagent-R表现不如Reagent-U），说明Agent需要的是**任务完成导向**的统一反馈，而非单纯的逻辑修正。
    *   **方法论**：Agent-RRM不仅仅是打分，还生成“纠错指导”，这实际上是一种**基于批评的生成**，将奖励模型从判别器升级为生成式导师。

### 2. 理论贡献

*   **Claim（声称）**：细化推理奖励能显著提升智能体的复杂推理能力。
*   **Evidence（证据）**：通过引入中间步骤的监督信号，模型在长链条任务（如WebWalkerQA）上的表现提升明显。
*   **Inference（推断）**：
    *   **理论补充**：本文在理论上补充了Agent训练中的**信用分配**问题。在多步推理中，ORM无法区分“虽然错了但推理方向正确”和“虽然对了但推理错误（幻觉）”的情况。Agent-RRM通过提供细粒度的Step-wise Score，理论上能更准确地指导策略梯度更新。
    *   **假设与风险**：该方法隐含了一个关键假设——**“推理步骤的局部线性可加性”**。即假设每一步的高分推理必然导致最终的高质量结果。然而，在复杂规划中，局部最优的推理步骤可能导致全局死胡同。
    *   **验证方式**：建议进行**Reward Correlation Analysis**，计算累积的Step-wise Reward与最终Outcome Reward之间的Spearman相关系数，以验证局部奖励是否真的能指导全局最优。

### 3. 实验验证

*   **Claim（声称）**：Reagent-U统一反馈策略效果最佳；在GAIA和WebWalkerQA上达到SOTA水平。
*   **Evidence（证据）**：
    1.  **主实验**：在GAIA（Val set）上达到43.7%，在WebWalkerQA上达到46.2%。
    2.  **消融实验**：对比了不同反馈策略（Reward-only vs. Unified）。
*   **Inference（推断）与质疑**：
    *   **基线选择**：论文主要对比了ReAct/Reflection等基线。但未与同样关注过程监督的**Math-Shepherd**、**PRM**类方法在Agent场景下的直接移植进行充分对比，难以区分是架构优势还是数据规模优势。
    *   **数据泄露风险**：Agent-RRM的训练数据构造细节未完全公开。如果训练数据中包含了与测试集高度相似的推理路径，模型可能只是在模仿推理而非学会推理。
    *   **验证方式**：建议进行**Out-of-Distribution (OOD) Generalization Test**，在训练未见过的全新工具或全新领域（如从知识问答切换到代码执行）中测试Agent-RRM的泛化能力。

### 4. 应用前景

*   **应用价值**：
    1.  **可解释性调试**：Agent-RRM提供的“纠错指导”不仅能训练模型，还能直接展示给人类用户，解释Agent为何失败，这对于构建可信AI至关重要。
    2.  **自进化系统**：该框架可以用于构建“Agent Arena”，让Agent不断自我博弈，RRM作为裁判，实现无需人类标注的迭代优化。
*   **局限**：RRM本身是一个较大的模型，推理阶段引入RRM进行打分会显著增加**延迟**和**计算成本**。在实时性要求高的应用（如对话机器人）中，可能需要将RRM的知识蒸馏到策略模型中才能落地。

### 5. 可复现性

*   **Claim（声称）**：基于GAIA和WebWalkerQA数据集。
*   **Evidence（证据）**：论文给出了RRM训练的Prompt模板和策略架构。
*   **Inference（推断）**：
    *   **模糊点**：RRM的训练数据来源语焉不详。是人工标注的？还是用强模型（如GPT-4）合成的？如果是合成数据，合成质量对最终效果的影响极大。
    *   **复现难点**：复现Agent实验通常涉及复杂的API调用（搜索、数据库查询），环境配置的一致性难以保证。

# 《Exploring Reasoning Reward Model for Agents》深度分析报告

## 1. 研究背景与问题

### 核心问题
本文旨在解决智能体在复杂任务中面临的**“过程监督缺失”**问题。具体而言，现有的基于强化学习（RL）训练的智能体，大多依赖于**稀疏结果奖励**，即只在任务最终完成时给出一个简单的对错判断。这种训练模式忽略了任务执行过程中的中间推理步骤，导致智能体难以在长链路、多步骤的复杂任务中进行有效的学习和自我修正。

### 研究背景与意义
随着大语言模型（LLM）的发展，AI智能体在处理复杂任务（如网页导航、多跳问答、工具调用）时展现出了巨大潜力。然而，这些任务通常需要严密的逻辑推理和精准的执行步骤。
- **意义**：如果仅依靠最终结果来指导学习，智能体就像一个“只看分数的学生”，无法理解自己在哪一步推理出了错。引入**推理奖励模型**能够提供细粒度的反馈，帮助智能体区分“正确的推理”与“错误的结果”，从而提升其在复杂环境中的泛化能力和鲁棒性。这是迈向具备逻辑推理和自我纠错能力的通用人工智能（AGI）的关键一步。

### 现有方法的局限性
1.  **稀疏奖励的困境**：在长链路任务中，奖励信号极度延迟。如果任务在第10步失败，仅告诉智能体“失败”了，它很难知道是第1步的规划错了，还是第5步的工具调用错了。
2.  **Outcome Supervision（结果监督）的不足**：现有的许多工作（如基于Outcome Reward Model, ORM）只关注最终输出。研究表明，过程监督在解决复杂推理问题时比结果监督更有效，但在智能体领域尚未得到充分探索。
3.  **缺乏可解释性**：单纯的数值奖励无法告诉智能体*为什么*错了，也无法提供修正建议。

### 为什么这个问题重要
在现实应用中，智能体处理的任务往往是高风险或高成本的（如自动化运维、金融交易辅助）。仅仅“做对”是不够的，智能体必须展示出可靠的、可追溯的推理过程。解决这一问题能显著提升智能体的**可信度**和**可控性**。

---

## 2. 核心方法与创新

### 核心方法：Agent-RRM
作者提出了**Agent-RRM（Agent Reasoning Reward Model）**，这是一个专门为智能体设计的推理奖励模型。与传统的ORM不同，Agent-RRM不仅仅输出一个标量奖励值，而是提供包含以下三个维度的**结构化反馈**：
1.  **显式推理链**：分析智能体的行动轨迹，构建每一步的推理上下文。
2.  **针对性纠错指导**：当检测到错误步骤时，提供具体的修正建议（例如：“搜索关键词不准确，应使用X而非Y”）。
3.  **过程评分**：对中间步骤进行打分，而不仅仅是最终结果。

### 训练策略：Reagent 系列
基于Agent-RRM，作者设计了三种强化学习训练策略，探索不同反馈组合的效果：
1.  **Reagent-C（Correction-based）**：仅使用Agent-RRM生成的**纠错文本**作为反馈，通过监督学习（SFT）的方式让智能体学会修正自己的错误轨迹。
2.  **Reagent-R（Reward-based）**：仅使用Agent-RRM生成的**过程奖励分数**，结合PPO（近端策略优化）等RL算法进行训练。
3.  **Reagent-U（Unified）**：**统一反馈策略**。结合了上述两者，既利用RL优化策略（利用分数），又利用SFT吸收修正知识（利用文本）。这是本文效果最好的方法。

### 技术创新点与优势
- **从“判卷”到“批改”**：传统的Reward Model只做判卷人，Agent-RRM充当了导师的角色，不仅打分还提供解题思路。
- **统一反馈框架**：Reagent-U证明了将强化学习的探索能力与监督学习的模仿能力结合，能产生协同效应。
- **数据效率**：通过显式的纠错信号，模型能更高效地从失败样本中学习，减少了在稀疏奖励环境中的盲目探索。

## 3. 理论基础

### 理论依据
1.  **过程偏好假设**：论文基于一个核心假设，即“正确的最终结果通常源于正确的推理过程”。虽然也存在“幸存者偏差”（即过程错但结果对），但优化过程能提高模型在未见任务上的成功率和鲁棒性。
2.  **奖励塑造**：在强化学习中，Reward Shaping是一种在不改变最优策略的前提下，通过修改奖励函数来加速收敛的技术。Agent-RRM本质上是一种高级的、基于知识的Reward Shaping，它引入了中间状态的先验知识（即LLM生成的纠错）。
3.  **反馈机制**：结合了**Actor-Critic架构**（利用Critic评估价值）和**行为克隆**（利用专家数据修正行为）。

### 算法设计
算法的核心在于构建Agent-RRM的训练数据：
- **输入**：智能体的轨迹 $(s_0, a_0, s_1, a_1, ...)$ 和最终结果。
- **标注生成**：利用更强的教师模型（如GPT-4）分析轨迹，识别错误步骤 $a_i$，生成修正建议 $c_i$，并计算过程奖励 $r_i$。
- **训练目标**：
    - 对于RRM：学习预测 $(r_i, c_i)$。
    - 对于Agent：最大化 $\sum r_i$（RL分支）并最小化生成轨迹与修正后轨迹的KL散度（SFT分支）。

## 4. 实验与结果

### 实验设计
- **基准测试**：选择了两个极具挑战性的智能体基准：
    - **GAIA**：需要多模态推理、工具使用和背景知识的复杂任务。
    - **WebWalkerQA**：模拟真实网页浏览和问答。
- **基线模型**：包括标准的SFT模型、ReAct prompting、以及使用传统ORM进行RL训练的模型。

### 主要结果
- **性能提升**：Reagent-U在GAIA上达到了**43.7%**的得分，在WebWalkerQA上达到了**46.2%**。相比基线模型（如ReAct或仅使用结果奖励的RL模型）有显著提升。
- **策略对比**：
    - Reagent-C（仅纠错）表现优于基线，说明显式的修正文本非常有价值。
    - Reagent-R（仅分数）表现一般，可能是因为单纯的分数在复杂空间中提供的梯度信息依然有限。
    - **Reagent-U（统一）**表现最佳，验证了“分数+文本”互补的假设。

### 结果分析与局限性
- **分析**：实验证明了细粒度的过程监督能有效缓解长链路任务中的“迷失”问题。Agent-RRM提供的纠错文本充当了“思维链”的脚手架。
- **局限性**：
    1.  **计算开销**：构建Agent-RRM需要依赖昂贵的教师模型（如GPT-4）进行数据标注，训练成本较高。
    2.  **错误传播**：如果RRM本身给出了错误的纠错建议，可能会误导智能体。
    3.  **泛化性**：实验主要集中在网页浏览和知识问答，在物理交互或更开放的沙盒环境中效果尚待验证。

## 5. 应用前景

### 实际应用场景
1.  **智能客服与售后**：Agent-RRM可以训练出能够处理复杂用户问题的智能体，即使解决问题失败，也能生成清晰的错误报告供人工参考，或自动尝试修正方案。
2.  **自动化运维与调试**：在复杂的IT系统中，智能体需要执行一系列操作来排查故障。过程奖励模型能确保每一步操作的合规性和逻辑性，防止误操作。
3.  **教育与辅导**：作为AI导师，不仅告诉学生答案错了，还能指出推理逻辑中的漏洞并提供修正步骤，这完全符合教育心理学的原则。

### 产业化可能性
- **高**。随着企业对AI Agent落地需求的增加，如何保证Agent的“可控性”和“可解释性”是商业化落地的关键。Agent-RRM提供了一种提升可控性的有效路径。
- **挑战**：在于降低标注成本。未来可能需要研究如何利用较小的模型来充当RRM，或者通过自动化合成数据来替代昂贵的人工/大模型标注。

## 6. 研究启示

### 对领域的启示
- **范式转移**：该研究进一步证实了AI Agent训练从“结果导向”向“过程导向”转移的必要性。未来的Agent训练将不仅仅是强化学习，而是“强化学习+监督学习+反馈学习”的混合体。
- **模型即裁判**：引入专门的Judge模型（RRM）来指导Actor模型（Agent）的训练，将成为构建复杂系统的标准架构。

### 未来方向
1.  **动态RRM**：目前的RRM可能是静态的，未来可以研究随着Agent能力提升而动态进化的RRM。
2.  **多模态反馈**：目前的反馈主要是文本，对于视觉或听觉为主的任务，需要研究多模态的反馈机制。
3.  **自我博弈**：利用Agent-RRM进行AlphaZero式的自我对弈，通过不断的自我博弈和纠错来激发更强的推理能力。

## 8. 相关工作对比

### 与同类研究的对比
- **vs. Outcome Reward Model (ORM)**：
    - **ORM**（如WebGPT、训练中的HHH）只看最终结果。
    - **Agent-RRM**看过程。在复杂任务中，RRM能提供更密集的学习信号，ORM容易导致“奖励黑客”或学习效率低下。
- **vs. Process Reward Model (PRM)**：
    - **PRM**（如Math-Shepherd）主要用于数学推理，通常是对思维链中的每一步打分。
    - **Agent-RRM**是PRM在Agent领域的扩展，但它增加了**“纠错文本生成”**这一维度，且处理的是包含环境交互的轨迹，而非纯文本链。
- **vs. Reflexion**：
    - **Reflexion**是一种通过自我反思来改进的Prompt策略。
    - **Agent-RRM**则是将这种“反思”显式

## 研究最佳实践

## 最佳实践指南

### 实践 1：构建过程监督型奖励模型

**说明**:
传统的结果监督仅根据最终输出给予奖励，这在复杂推理任务中往往无法有效指导智能体优化。最佳实践是采用过程监督，即对推理链中的每一个中间步骤进行评估和打分。这有助于模型识别错误的推理路径，防止“正确结论但错误推导”的情况，从而提高智能体在复杂任务中的可靠性和逻辑一致性。

**实施步骤**:
1. 构建包含逐步推理标注的训练数据集，而不仅仅是最终答案。
2. 设计奖励模型架构，使其能够接收并评估中间的推理状态。
3. 训练模型为每个推理步骤分配奖励分数，而不仅仅是针对最终结果。

**注意事项**:
- 确保标注数据的质量，错误的步骤标注会误导模型。
- 平衡过程奖励与结果奖励的权重，避免模型过度关注细节而忽略了整体目标。

---

### 实践 2：利用结果回溯合成训练数据

**说明**:
高质量的过程监督数据通常难以直接获取。最佳实践是利用现有的结果级数据，通过让模型回溯生成推理链来合成过程监督数据。具体而言，可以使用一个强大的推理模型（如GPT-4）生成到达已知结果的推理步骤，或者使用“反向推理”技术，从结果倒推合理的中间过程，从而低成本地构建大规模训练集。

**实施步骤**:
1. 收集仅有最终答案标注的任务数据集。
2. 使用高性能的大语言模型生成从问题到答案的详细推理路径。
3. 将生成的推理路径视为“基本真值”，用于训练过程奖励模型。

**注意事项**:
- 验证合成数据的逻辑性，过滤掉幻觉或逻辑跳跃的合成路径。
- 这种方法依赖于生成模型的质量，可能存在噪声，需配合数据清洗策略。

---

### 实践 3：实施结果与过程的混合奖励机制

**说明**:
纯粹的过程奖励可能会导致计算开销过大或推理发散，而纯粹的结果奖励则缺乏指导性。最佳实践是结合两者，设计混合目标函数。在推理的早期和中间阶段主要依赖过程奖励进行纠偏，在推理结束时引入结果奖励进行最终验证。这种机制能够平衡推理的准确性与效率。

**实施步骤**:
1. 分别训练或调整过程奖励模型（PRM）和结果奖励模型（ORM）。
2. 在智能体的搜索算法（如蒙特卡洛树搜索或束搜索）中，将过程奖励作为节点评估的启发式指标。
3. 将结果奖励作为终止条件或最终路径选择的主要依据。

**注意事项**:
- 需要通过实验确定过程奖励与结果奖励在总损失函数中的最佳比例。
- 确保两个奖励模型的评分尺度大致一致，避免某一个模型主导训练过程。

---

### 实践 4：采用拒绝采样优化推理路径

**说明**:
在强化学习或微调阶段，利用奖励模型对多个候选输出进行排序至关重要。最佳实践是使用拒绝采样策略，即让模型生成多个不同的推理路径，利用训练好的推理奖励模型对这些路径进行打分，仅保留得分最高的路径用于后续的微调。这种方法能够显著提升模型对高质量推理模式的模仿能力。

**实施步骤**:
1. 对于同一个输入提示，让策略模型生成 K 个不同的推理轨迹。
2. 使用推理奖励模型对所有轨迹进行评分。
3. 根据分数筛选出最优样本，构建微调数据集进行迭代更新。

**注意事项**:
- 采样数量 K 需要根据计算资源进行调整，通常在 4 到 16 之间。
- 避免样本多样性不足，导致模型陷入局部最优。

---

### 实践 5：关注思维链的隐性知识提取

**说明**:
在探索推理奖励模型时，不仅要关注显式的文本推理步骤，还应关注模型内部状态的隐性知识。最佳实践包括利用模型的隐藏层状态或注意力图来辅助判断推理质量，或者训练奖励模型使其能够理解非文本形式的中间表征（如代码解释器的中间状态、工具调用的返回结果）。

**实施步骤**:
1. 分析智能体在多步推理中的中间激活值或工具调用日志。
2. 将这些隐性特征与显式的文本推理链结合，作为奖励模型的输入。
3. 训练奖励模型识别复杂的逻辑跳跃和工具使用效率。

**注意事项**:
- 隐性特征通常难以解释，需确保其与任务目标的相关性。
- 增加了模型架构的复杂性，可能影响推理速度。

---

### 实践 6：迭代式在线学习与自我进化

**说明**:
静态数据集训练的奖励模型容易遇到性能天花板。最佳实践是采用迭代式的在线学习流程，让智能体在与环境的交互中不断产生新的数据，利用当前的奖励模型筛选数据，进而更新奖励模型本身。这种“自我进化”的循环能帮助智能体探索训练集中未覆盖的长尾推理问题。

**实施步骤**:
1. 部署当前的智能体系统解决新的、未见过的问题。
2. 收集成功解决或部分解决的案例及其推理轨迹。
3. 使用这些新数据（可能结合人工反馈）来微调奖励

---
## 学习要点

- 推理奖励模型（RRM）通过直接对齐人类对推理过程的偏好，显著提升了智能体在复杂任务中的规划与决策能力。
- 相比于仅依赖最终结果的反馈，RRM 能够更有效地识别并强化中间推理步骤中的逻辑正确性，从而优化思维链质量。
- 该方法解决了传统奖励模型在多步推理任务中存在的稀疏奖励和信用分配难题，使智能体能更精准地定位错误来源。
- 引入推理过程监督不仅提高了智能体在数学和逻辑等领域的表现，还增强了模型面对未见任务时的泛化性与鲁棒性。
- 研究表明，高质量的推理过程数据对于训练此类模型至关重要，其效果往往优于单纯增加最终结果数据的规模。
- RRM 为构建更可靠的自主智能体提供了一种通用的可扩展范式，能够减少模型在复杂交互中产生的幻觉现象。

## 常见问题


### 1: 什么是“推理奖励模型”，它与传统的奖励模型有何不同？

1: 什么是“推理奖励模型”，它与传统的奖励模型有何不同？

**A**: 推理奖励模型是一种专门用于评估和增强智能体推理过程质量的模型。与传统的奖励模型主要关注最终输出的正确性不同，RRM 侧重于评估“中间推理步骤”的质量。它通过分析智能体在解决问题时的思维链或行动轨迹，来判断其推理逻辑是否严密、步骤是否合理，从而在训练过程中给予更精细的反馈信号，帮助智能体不仅得到正确答案，还能学会正确的思考方法。

---



### 2: 为什么现有的奖励模型难以有效评估智能体的推理能力？

2: 为什么现有的奖励模型难以有效评估智能体的推理能力？

**A**: 现有的奖励模型通常基于结果监督，即只根据最终结果给予奖励。然而，在复杂的推理任务中，即使最终答案是错误的，智能体的推理过程可能包含有价值的逻辑步骤；反之，正确的答案也可能是由错误的逻辑（如“幻觉”或猜测）推导得出的。现有模型难以区分这些细微差别，导致它们无法有效地指导智能体改进其内部推理过程，限制了智能体在需要多步规划任务中的表现。

---



### 3: 该研究提出的RRM是如何构建和训练的？

3: 该研究提出的RRM是如何构建和训练的？

**A**: 根据论文内容，RRM 的构建通常包含以下步骤：首先，收集包含推理轨迹（如思维链或工具调用记录）的数据集。其次，利用更强大的模型（如 GPT-4）或人工标注，对推理过程中的每一步或整体轨迹进行质量评估和打分，生成训练标签。最后，使用这些数据训练一个奖励模型，使其能够输入一个推理轨迹，输出一个反映该推理质量高低的标量分数。这个分数随后被用作强化学习（如 PPO）或拒绝采样优化中的奖励信号。

---



### 4: RRM 如何提升 Agent 的任务解决能力？

4: RRM 如何提升 Agent 的任务解决能力？

**A**: RRM 通过提供过程级的反馈来提升 Agent 的能力。在强化学习训练阶段，RRM 实时评估 Agent 生成的推理路径。如果 Agent 采取了正确的逻辑步骤，即使任务尚未完成，RRM 也会给予正向奖励，强化这种行为；反之则给予惩罚。这种机制鼓励 Agent 探索更合理的解题路径，减少盲目尝试，从而显著提高其在复杂任务（如数学推理、代码生成、工具使用）中的成功率和泛化能力。

---



### 5: 该研究使用了哪些数据集或基准测试来验证 RRM 的有效性？

5: 该研究使用了哪些数据集或基准测试来验证 RRM 的有效性？

**A**: 该类研究通常在需要复杂推理的基准测试上进行验证，例如 GSM8K 或 MATH（数学推理）、HumanEval（代码生成）、以及 ALFWorld 或 WebShop（具身智能和网页交互任务）。通过在这些数据集上对比使用 RRM 训练的 Agent 与使用标准 Outcome Reward Model 训练的 Agent，可以证明 RRM 在提升任务完成率和推理质量方面的优越性。

---



### 6: 引入 RRM 会带来哪些潜在的问题或挑战？

6: 引入 RRM 会带来哪些潜在的问题或挑战？

**A**: 主要的挑战包括：1. **数据标注成本**：获得高质量的推理过程标签比仅标注最终结果要昂贵且困难得多。2. **评估难度**：自动评估推理过程的合理性本身就是一个未完全解决的问题，如果 RRM 本身存在偏差，可能会误导 Agent 的优化方向。3. **计算开销**：在训练过程中实时评估推理轨迹会增加计算资源的消耗。4. **奖励黑客**：Agent 可能会学会生成看似高得分但实则无效的推理模式来欺骗 RRM。

---



### 7: RRM 与 Outcome Supervision（结果监督）相比，核心优势是什么？

7: RRM 与 Outcome Supervision（结果监督）相比，核心优势是什么？

**A**: 核心优势在于“过程反馈”和“可解释性”。结果监督只能告诉 Agent 做对了还是做错了，而 RRM 能告诉 Agent *哪里*做对了以及*哪里*做错了。这种细粒度的指导对于长链路推理任务至关重要，它能够加速收敛速度，并使 Agent 更容易从错误中恢复，而不是因为某一步走错就导致整个任务失败且无法获得有效的学习信号。
