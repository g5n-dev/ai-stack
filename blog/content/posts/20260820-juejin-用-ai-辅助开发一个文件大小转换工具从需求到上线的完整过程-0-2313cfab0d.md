## 核心结论

文件大小转换工具需同时支持 SI（十进制）和 IEC（二进制）两套标准，前者以 1000 为进率，后者以 1024 为进率。工具作者在开发过程中使用 Claude 进行辅助，通过多轮对话迭代完成了单位补全、精度优化和兼容性处理。关键技术实现包括使用静态数值作为转换因子、正则表达式去除尾随零、复制功能的降级方案以及基于 `prefers-color-scheme` 的自动深色模式适配。

## 能力机制

工具提供两种输入方式：直接输入数值或上传文件自动读取大小。输入任意有效数值后，页面同时展示 SI 和 IEC 两套标准下所有单位的换算结果。每行结果可独立复制，支持中英文界面切换。

转换因子采用预定义静态数值而非动态计算，原因有三：避免重复运算提升性能、减少浮点误差累积、代码可读性更高。精度处理先用 `toFixed()` 保留指定小数位，再用正则 `/?0+$/` 移除不必要的尾随零，使显示结果更为简洁。

复制功能采用条件判断实现降级：当 `navigator.clipboard.writeText` 可用时优先调用，否则回退到基于 `document.execCommand` 的传统方案。该降级方案确保在非 HTTPS 环境（如 localhost）下仍可正常工作。

人类可读格式功能自动选择最合适的单位呈现结果。实现逻辑是从最大单位起遍历，当数值大于等于该单位因子时执行除法并格式化，例如 1500000 bytes 显示为 1.5 MB。

## 快速开始

数值输入方式：在数字输入框中键入任意非负数值，页面即时更新所有单位的换算结果。

文件上传方式：通过拖拽或点击上传区域提交文件，工具自动读取 `file.size` 属性进行转换。上传空文件时结果直接显示为 0 B。

语言切换方式：通过 URL 参数 `?lang=en` 可手动指定为英文界面，工具默认根据 `navigator.language` 自动检测。

深色模式适配：工具自动读取系统级深色模式偏好并应用相应样式，无需手动操作。

## 适用边界

该工具适用于开发调试场景，如查看日志文件实际大小、验证上传接口的字节限制；适用于日常办公场景，如确认设计稿标注尺寸与实际文件大小是否一致；适用于存储规划场景，如估算备份文件在两种计量标准下的差异。

工具不支持大数加减运算，仅进行乘除转换以规避 JavaScript 安全整数范围外的精度问题。输入负数或非数值时，结果区域保持空白。工具未实现持久化存储功能，所有计算均在客户端完成。

## 核验清单

单位覆盖度确认：SI 标准应包含 B、KB、MB、GB、TB、PB 共六个单位，IEC 标准应包含 B、KiB、MiB、GiB、TiB、PiB、EiB 共七个单位，代码中使用静态数值作为各单位的转换因子。

精度显示确认：`1.50` 应显示为 `1.5`，`2.00` 应显示为 `2`，`3.140` 应显示为 `3.14`，尾随零通过正则表达式 `/\.?0+$/` 去除。

复制功能确认：支持主流程使用 `navigator.clipboard.writeText`，同时具备 `document.execCommand` 回退方案，确保在非 HTTPS 环境下可用。

国际化确认：内置中英文映射对象，默认通过 `navigator.language` 检测语言，支持 `?lang=en` 参数手动指定。

深色模式确认：通过 CSS 变量定义颜色，通过 `prefers-color-scheme` 媒体查询实现自动适配，无需手动切换。

边界情况确认：处理 `bytes === 0` 的空文件场景，过滤 `val < 0` 的无效输入，避开大数加减运算防止浮点精度损失。
