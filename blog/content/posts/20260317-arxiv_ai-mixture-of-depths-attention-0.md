## 导语

针对深层语言模型中常见的信号退化问题，本文提出了混合深度注意力机制。该方法在保持极低计算开销的前提下，允许注意力头同时访问当前层及前序层的特征，从而有效缓解关键信息的稀释。实验表明，该策略在多项基准测试中提升了模型性能，且具备接近 FlashAttention-2 的高效硬件利用率。此外，研究还建议将其与后归一化结合以获得更优表现，但具体理论成因无法从摘要确认。

---
## 摘要

以下是关于 **Mixture-of-Depths Attention (MoDA)** 的内容总结：

**核心问题**
随着大型语言模型（LLM）层数的加深，模型常面临**信号退化**（Signal degradation）问题。浅层形成的关键特征会经过多次残差更新而被逐渐稀释，导致深层难以有效恢复这些信息。

**解决方案**
研究团队提出了**混合深度注意力机制（MoDA）**。该机制允许每个注意力头不仅处理当前层的序列键值对，还能同时关注来自**前面层**的深度键值对。

**主要优势与实验结果**
1.  **性能提升**：在15亿参数的模型实验中，MoDA在10项基准测试中平均将困惑度降低了0.2，在10项下游任务中平均性能提升了2.11%。
2.  **计算高效**：仅需3.7%的极小浮点运算（FLOPs）开销。
3.  **硬件优化**：通过解决非连续内存访问问题，MoDA实现了极高的硬件效率，在64K序列长度下达到了FlashAttention-2效率的97.3%。
4.  **架构建议**：研究发现将MoDA与**后归一化**结合使用，比与前归一化结合效果更好。

**结论**
MoDA被证明是一种极具前景的深度扩展基础组件，代码已公开。

## 评论

以下是对论文《Mixture-of-Depths Attention》的深入学术评价。该研究针对深层Transformer中的信号退化问题，提出了一种跨层注意力机制MoDA，旨在通过增强特征的复用来提升模型性能。

---

### **1. 研究创新性**

**论文声称**：
现有的深层Transformer模型存在“信号退化”现象，即浅层提取的关键特征在经过多次残差连接和非线性变换后，在深层被稀释或丢失。MoDA提出了一种新的注意力范式，允许当前层的注意力头直接检索来自前面层的键值对。

**证据**：
作者在1.5B参数规模的模型上进行了实验，对比了标准Transformer与MoDA在下游任务上的表现。

**推断与评价**：
*   **机制创新**：MoDA在本质上是对**静态注意力图**的一种解构。传统模型中，注意力仅限于当前层（Layer-wise），而MoDA将其扩展为**时空混合**（Spatial-Temporal Mixture）。这与“跳跃连接”不同，Skip Connection是数据层面的捷径，而MoDA是查询层面的捷径。
*   **发现**：该研究隐含地提出了一个假设：**语义对齐在不同深度层间是存在的**。即，第 $L$ 层的 Query 可能与第 $L-k$ 层的 Key/Value 存在语义相关性。这是一个非平凡的假设，因为通常认为浅层关注语法/低级特征，深层关注语义/高级特征。MoDA的有效性暗示了不同尺度特征在深层网络中具有比以往预期更强的跨层互补性。

### **2. 理论贡献**

**论文声称**：
MoDA能够缓解深层网络中的信号退化，并提升模型的表达能力。

**证据**：
通过可视化或性能对比，展示了引入MoDA后模型在长序列理解和复杂推理任务上的提升。

**推断与评价**：
*   **特征流理论**：该工作对“信息瓶颈”理论提出了新的解决方案。传统观点认为增加深度是为了增加抽象层次，但MoDA表明，**深度不应仅意味着“更远的距离”，还应意味着“更广的视野”**。它将垂直的层与层之间的特征传递，转化为水平与垂直交织的特征检索网络。
*   **注意力机制的泛化**：从理论上看，MoDA将标准注意力视作一个特例（即只关注当前深度的KV）。它证明了注意力机制可以作为一个**通用的特征检索器**，其检索范围不应受限于网络的前向传播深度。

### **3. 实验验证**

**论文声称**：
在10项基准测试中，MoDA带来了平均性能的提升，且在1.5B模型上表现优异。

**证据**：
基于1.5B参数的模型训练，并在多个NLP基准测试上进行了评估。

**推断与评价（关键假设与失效条件）**：
*   **关键假设**：**跨层语义一致性假设**。假设第 $N$ 层的 Query 能够理解第 $N-1, N-2...$ 层的 Key/Value 编码的信息。
*   **潜在失效条件**：
    1.  **语义漂移**：在极深层的网络中，浅层的特征（如词法特征）可能过于具体，而深层的 Query 需要抽象语义。如果浅层KV引入过多噪声，注意力权重可能会被分配给无效的浅层信息，导致性能下降。
    2.  **位置编码干扰**：如果模型使用绝对位置编码，直接混合不同层的KV可能会导致位置信息的混淆（因为不同层代表不同的上下文窗口深度）。
*   **验证建议**：
    *   **消融实验**：必须进行“层距离”的消融实验，即限制MoDA只能回溯 $k$ 层（如 $k=1, 2, 4, 8$），观察性能曲线是否呈现倒U型。如果 $k$ 越大性能越差，说明浅层特征存在严重的语义不匹配。
    *   **注意力可视化**：分析MoDA头部的注意力分布。如果模型倾向于总是关注最邻近的层（退化为普通注意力）或总是关注第一层（退化为浅层特征），则说明机制未按预期工作。

*   **参数高效训练**：在固定参数预算下，MoDA提供了一种在不显著增加计算量的前提下提升性能的途径。这对于边缘端部署或中等规模模型（如1B-3B参数）具有极高的商业价值。

# Mixture-of-Depths Attention (MoDA) 深度分析报告

## 1. 研究背景与问题

### 核心问题：深层网络中的信号退化
该研究旨在解决深度 Transformer 模型（特别是大型语言模型 LLM）在层数加深时面临的**信号退化**问题。在标准的深层神经网络堆叠中，浅层提取的关键特征信息需要经过多次的残差连接和非线性变换才能传递到深层。随着层数的增加，这些关键信号会被逐渐稀释、遗忘或被后续层引入的噪声所覆盖，导致深层难以有效利用浅层建立的高质量语义表征。

### 研究背景与意义
当前 LLM 的发展趋势表明，增加模型深度是提升性能的关键路径之一（例如 DeepSeek-V3、GPT-4 等均采用了极深的架构）。然而，简单的堆叠层会带来“梯度消失”或“特征坍塌”的风险。虽然残差连接在一定程度上缓解了梯度问题，但**语义信息**的传递依然存在损耗。MoDA 的提出意义在于，它提供了一种在不显著增加计算负担的前提下，打通深层与浅层信息流的方法，这对于构建更高效、更深层的下一代基础模型具有重要的工程和理论价值。

### 现有方法的局限性
- **标准注意力机制**：仅关注当前层的特征，忽略了跨层信息的直接交互。
- **跨层注意力**：虽然存在一些跨层交互的工作，但通常涉及巨大的计算开销或需要复杂的架构重组（如循环反馈），难以在现有的并行训练框架中高效部署。
- **Mixture-of-Experts (MoE)**：虽然 MoE 通过稀疏激活增加了模型容量，但它主要解决的是**参数量与计算量的矛盾**，而非直接解决**深度方向上的信息传递衰减**问题。

## 2. 核心方法与创新

### 核心方法：混合深度注意力
MoDA 的核心思想是打破层与层之间的壁垒。在标准的 Multi-Head Attention (MHA) 中，每个头计算 Query ($Q$)、Key ($K$)、Value ($V$) 时，$K$ 和 $V$ 仅来源于当前层的输入。
MoDA 提出了一种**混合策略**：
- **深度键值对**：将模型前面若干层（例如前 $L-1$ 层）的 $K$ 和 $V$ 缓存下来，作为“深度键值对”。
- **混合检索**：在计算注意力时，当前层的 Query 不仅与当前层的 Key-Value 进行交互，还直接与来自前面层的 Key-Value 进行交互。
- 这意味着模型在处理当前 Token 时，可以“回溯”并直接利用浅层提取的原始特征，而不必依赖残差连接的层层传递。

### 技术创新点与优势
1. **即插即用**：MoDA 是对标准 Attention 模块的直接替换，不需要改变模型的主干架构。
2. **非连续内存访问优化**：直接访问多层历史 KV 会带来巨大的内存碎片和读取延迟。研究团队设计了特殊的内存管理策略，使得在处理 64K 长序列时，硬件利用率达到了 FlashAttention-2 的 97.3%，极大地降低了工程落地门槛。
3. **后归一化结合**：研究发现 MoDA 与 Post-Norm（后归一化）结合使用效果更好，这挑战了目前 Pre-Norm 占据主流的现状，表明在跨层连接增强的情况下，Post-Norm 能更好地稳定训练。

## 3. 理论基础

### 理论假设：特征的层级性与衰减
该方法基于以下理论假设：
1. **特征分层假设**：不同层提取的特征具有互补性。浅层通常包含更细粒度的句法和局部语义信息，而深层包含抽象的语义信息。深层直接访问浅层，类似于人类在思考时不仅依赖当前的逻辑，还会回顾原始的感官细节。
2. **信息流瓶颈假设**：在深层网络中，信息流经的层数越多，被噪声干扰或被非线性变换扭曲的概率越大。直接建立“高速通道”可以绕过中间层的干扰。

### 数学模型
MoDA 的数学形式可以表示为对注意力机制的扩展。设当前层为 $l$，标准的注意力计算为：
$$ \text{Attn}(Q_l, K_l, V_l) $$
而 MoDA 的计算形式为：
$$ \text{MoDA}(Q_l, \{K_{i}\}_{i=0}^{l}, \{V_{i}\}_{i=0}^{l}) $$
其中包含了从第 0 层到第 $l$ 层的所有 KV。为了保持计算高效，通常不会对所有历史层进行全量计算，而是采用采样或分组策略，或者利用硬件并行优化来掩盖访问延迟。

## 4. 实验与结果

### 实验设计
研究团队在 **1.5B 参数**规模的模型上进行了验证，这是一个验证架构有效性的黄金尺度（既不太小以至于看不出架构优势，也不太大以至于无法进行充分的消融实验）。
- **基准测试**：包括困惑度（PPL）验证和 10 项下游任务。
- **对比基线**：标准 Transformer 以及其他注意力变体。

### 主要结果
1. **性能增益显著**：在仅增加 **3.7% FLOPs** 的情况下，MoDA 在多个基准测试中平均将困惑度降低了 **0.2**（这是一个在 1.5B 模型上非常显著的提升），下游任务平均性能提升了 **2.11%**。
2. **长序列处理能力**：在 64K 长序列的测试中，MoDA 展现了极低的额外延迟开销，证明了其工程优化的成功。
3. **架构选择验证**：实验证实了 MoDA + Post-Norm 的组合优于 MoDA + Pre-Norm。这可能是因为 MoDA 提供了稳定的跨层梯度路径，缓解了 Post-Norm 通常面临的训练不稳定问题。

### 局限性
- **内存消耗**：虽然计算量（FLOPs）增加很少，但存储所有历史层的 KV Cache 会显著增加显存占用（VRAM）。论文中虽然提到了优化，但在极端长序列或极大_batch size_ 下，显存压力依然是瓶颈。
- **训练稳定性**：引入跨层连接可能会改变梯度的流动模式，虽然 Post-Norm 有所缓解，但如何在不同规模的模型（如 70B+）上保持训练稳定仍需验证。

## 5. 应用前景

### 实际应用场景
1. **长文本理解与生成**：由于 MoDA 能够有效回溯浅层信息，这对于需要保持长距离一致性的任务（如长篇小说写作、代码生成）尤为有利，因为模型可以直接“看到”早期的上下文细节。
2. **边缘侧小模型**：对于参数量受限的模型（如 1B-3B 规模），MoDA 提供了一种以极小计算代价换取性能提升的途径，非常适合端侧部署。

### 产业化可能性
极高。由于 MoDA 对 FLOPs 的增加微乎其微（3.7%），且主要优化在于内存访问模式，它非常适合集成到现有的推理引擎（如 vLLM, TensorRT-LLM）中。它不需要改变模型的并行策略，因此迁移成本较低。

## 6. 研究启示

### 对领域的启示
1. **深度架构的新方向**：过去的研究多集中在宽度或 MoE，MoDA 提醒我们“深度”本身也是一个未被充分挖掘的维度，如何优化深度的信息流是未来的热点。
2. **Post-Norm 的回归**：Pre-Norm 曾因为训练稳定性成为主流，但 MoDA 的研究表明，随着架构创新（如跨层连接），Post-Norm 可能会卷土重来，带来更好的收敛性能。

### 未来方向
- **动态混合深度**：目前的 MoDA 可能是静态地访问历史层，未来可以结合路由机制，动态决定当前层需要访问哪一层的历史信息。
- **与 MoE 的结合**：将 MoDA 与 Mixture-of-Experts 结合，构建一个既在深度上混合、在宽度上也稀疏的超大规模模型。

## 8. 相关工作对比

| 维度 | 标准 Transformer | Mixture-of-Experts (MoE) | Mixture-of-Depths (MoDA) |
| :--- | :--- | :--- | :--- |
| **核心目标** | 增加模型容量 | 稀疏激活，增加参数量而不增加计算量 | 解决深层信息衰减，增强跨层连接 |
| **计算开销** | 随深度线性增加 | 条件计算，主要增加参数量 | 极小 (3.7% FLOPs)，主要增加显存访问 |
| **主要瓶颈** | 深层特征丢失 | 专家负载均衡、通信开销 | KV Cache 显存占用 |
| **创新性** | 基准 | 架构层面的稀疏性 | **深度维度的注意力增强** |

**地位评估**：MoDA 填补了“深度优化”领域的空白。它不是像 MoE 那样激进的架构变革，而是一种精细化的内部改进。在追求极致性能的当下，MoDA 提供了一种性价比极高的优化手段。

## 9. 研究哲学：可证伪性与边界

### 关键假设与归纳偏置
- **假设**：浅层的特征包含深层所需的关键信息，且这些信息在通过残差连接传递时会受损。
- **归纳偏置**：模型倾向于从“历史”中寻找答案，而非仅从当前的抽象逻辑中推理。

### 失败条件
- **数据分布**：如果任务不需要长距离依赖或细粒度的局部特征（例如简单的分类任务），MoDA 引入的噪声可能超过其带来的收益，导致性能下降。
- **极端深度**：在超过 100 层的超深网络中，如果浅层特征包含过多低级噪声，直接引入可能会干扰深层的抽象逻辑。

### 经验事实 vs 理论推断
- **经验事实**：在 1.5B 模型上，PPL 降低了 0.2，Post-Norm 效果更好。这是可复现的实验结果。
- **理论推断**：认为 MoDA 解决了“信号退化”。这需要通过可视化每一层的激活值或梯度流来严格证明，目前更多是基于性能提升的间接推断。

### 方法 vs 理解
MoDA 更多地推进了**“方法”**。它并没有完全解释

## 研究最佳实践

## 最佳实践指南

### 实践 1：动态路由机制的配置

**说明**:
Mixture-of-Depths (MoD) 的核心在于打破传统 Transformer 中每一层都处理所有 Token 的限制。通过引入路由机制，模型需要决定哪些 Token 在当前层进行计算（即参与 Attention 和 MLP），哪些 Token 直接绕过（Residual Connection）传递到下一层。最佳实践要求根据模型规模和计算预算，设定一个合理的容量上限参数，即每一层最多只处理总 Token 数的一定比例（例如 50% 或 30%）。

**实施步骤**:
1. 在每个 Transformer 层的 Self-Attention 和 MLP 模块之前插入轻量级的路由器（通常为一个小型的线性层或简单的 TopK 选择器）。
2. 设定容量参数 $C$，该参数决定了每一层允许参与计算的 Token 数量上限（通常是序列长度 $L$ 的一个分数，如 $0.5L$）。
3. 确保未被选中的 Token 能够通过残差连接无损地传递到下一层，不经过复杂的矩阵运算。

**注意事项**:
路由决策必须保持可微分性或使用 Gumbel-Softmax 等技巧以支持梯度反向传播，或者直接使用直通估计器以确保训练稳定性。

---

### 实践 2：位置感知的 Token 选择策略

**说明**:
在实施 MoD 时，路由器不应仅仅基于 Token 的语义内容进行选择，还应考虑其位置信息。由于某些层倾向于处理局部上下文（如 N-gram 依赖），而其他层处理长距离依赖，确保路由器能够感知位置有助于模型学习到更合理的计算分配模式，避免关键的位置信息被丢弃。

**实施步骤**:
1. 将位置编码与 Token Embedding 进行加法或拼接操作，作为路由器的输入。
2. 在路由器的评分函数中显式加入位置偏置项，特别是在浅层网络中。
3. 监控不同层被选中的 Token 分布，确保并非总是集中在前面的 Token，而是根据任务需求动态分布。

**注意事项**:
如果使用相对位置编码，需确保路由器能正确解析相对位置关系，防止在长序列中出现位置漂移导致的选择性偏差。

---

### 实践 3：计算资源的动态重分配

**说明**:
MoD 的主要优势在于“回收”未被使用的计算量。当某一层只处理了少量 Token 时，原本节省下来的 FLOPs（浮点运算次数）不应被浪费，而应被重新分配给模型中更深层或更复杂的计算模块。最佳实践建议在训练和推理时，允许不同层之间动态调整计算预算，或者将节省下来的资源用于增加批次大小或上下文长度。

**实施步骤**:
1. 在训练框架中实现动态计算图分析，统计每一层的实际 FLOPs 消耗。
2. 如果硬件支持（如稀疏注意力算子），可以将节省下来的显存和算力用于增加模型的总体深度或宽度，而不是单纯减少总计算量。
3. 对于推理阶段，实现自适应批处理，利用 Token 数量较少的层的时间间隙来调度其他任务。

**注意事项**:
动态重分配需要底层硬件（如 GPU）对非均匀计算有良好的支持，否则可能会因为频繁的内存访问模式改变而导致延迟增加而非减少。

---

### 实践 4：辅助损失函数的设计与权重平衡

**说明**:
为了防止路由器“偷懒”（例如总是选择同一批 Token 或总是选择前面的 Token），必须引入辅助损失函数来鼓励负载均衡和多样性。这包括确保每个 Token 被选中的概率大致相等，以及每个层的计算容量被充分利用。

**实施步骤**:
1. 引入负载均衡损失，惩罚不同 Token 被选中频率的方差。
2. 引入辅助损失，确保每一层实际处理的 Token 数量接近预设的容量上限 $C$。
3. 将辅助损失与主任务损失进行加权求和，权重系数通常设定在 0.01 到 0.1 之间，具体取决于模型规模。

**注意事项**:
辅助损失的权重过大可能会主导模型的训练方向，导致模型为了平衡计算而牺牲预测精度，需要通过超参数搜索找到最佳平衡点。

---

### 实践 5：序列长度的自适应扩展

**说明**:
由于 MoD 允许模型跳过部分 Token 的计算，因此在相同的计算预算下，模型理论上可以处理比标准 Transformer 更长的序列。最佳实践建议在实施 MoD 时，逐步增加训练时的上下文窗口长度，以充分利用这种计算效率带来的红利。

**实施步骤**:
1. 在预训练初期，使用标准的序列长度进行训练，以稳定路由器的收敛。
2. 随着训练进程推进，逐步增加输入序列的长度（例如从 2K 增加到 8K 或更长）。
3. 监控模型在长序列下的困惑度（PPL）表现，调整路由器的容量参数，确保长序列依赖关系能够被有效捕获。

**注意事项**:
增加序列长度会显著增加显存占用（KV Cache），虽然计算量可能受控，但需确保显存带宽成为瓶颈

## 学习要点

- Mixture-of-Depths (MoD) 通过动态分配计算资源，使模型能够以相同的计算成本处理更长的序列或提升模型性能。
- 该方法在保持标准 Transformer 架构整体不变的前提下，通过引入路由机制和 Top-K 选择，仅让部分 Token 参与 Self-Attention 或 MLP 计算。
- MoD 证明了并非所有 Token 在每一层都需要被同等程度地处理，通过跳过部分计算可以显著降低推理时的 FLOPs。
- 这种设计不仅提高了训练和推理的吞吐量，还改善了模型在长上下文任务中的表现。
- MoD 将计算分配与数据绑定，而非像 MoE 那样将参数分配与数据绑定，从而在保持模型参数规模不变的情况下实现了计算效率的优化。

## 常见问题


### 1: 什么是 Mixture-of-Depths (MoD) 注意力机制，它与标准的 Transformer 架构有何不同？

1: 什么是 Mixture-of-Depths (MoD) 注意力机制，它与标准的 Transformer 架构有何不同？

**A**: Mixture-of-Depths (MoD) 是一种动态分配计算资源的 Transformer 架构变体。在标准的 Transformer（如 GPT-3 或 LLaMA）中，每一个 Token 在每一层都会完整地通过多头注意力（MHSA）和前馈网络（FFN）模块，这意味着计算量与序列长度和层数呈线性静态关系。

MoD 的核心区别在于它打破了这种“全量计算”的范式。它引入了一个路由机制，允许模型在每一层动态地选择一部分 Token 进行深度计算（即同时参与注意力和前馈传播），而其余的 Token 则通过残差连接直接传递到下一层（被跳过）。这种设计使得模型可以将计算能力集中在输入中最需要处理的部分，从而在不牺牲性能的情况下显著降低整体计算量。

---



### 2: MoD 如何决定哪些 Token 需要被计算，哪些被跳过？

2: MoD 如何决定哪些 Token 需要被计算，哪些被跳过？

**A**: MoD 使用轻量级的路由器来决定 Token 的命运。具体来说，对于序列中的每一个 Token，路由器会根据其当前的状态预测一个“路由权重”或“重要性分数”。

这个过程通常包含两个关键步骤：
1. **Top-k 选择**：模型设定一个容量参数，决定了每一层最多可以处理多少个 Token。路由器会对所有 Token 的分数进行排序，选出分数最高的 Top-k 个 Token。
2. **计算分配**：被选中的 Top-k 个 Token 将进入该层的注意力和前馈网络进行更新；未被选中的 Token 则保持原状态，直接通过残差连接合并到输出中。

这种机制类似于 Mixture-of-Experts (MoE) 中的门控网络，但 MoE 是选择“专家”，而 MoD 是选择“Token”。

---



### 3: Mixture-of-Depths 和 Mixture-of-Experts (MoE) 有什么本质区别？

3: Mixture-of-Depths 和 Mixture-of-Experts (MoE) 有什么本质区别？

**A**: 虽然两者都涉及条件计算和路由机制，但它们的优化目标和应用方式完全不同：

1. **计算对象不同**：
   * **MoE** 是**模型并行**的体现。它为每一层维护多个独立的专家网络（通常是 FFN），路由决定的是“哪个 Token 去哪个专家”。
   * **MoD** 是**时间/层维度**的动态化。它不增加额外的专家网络，而是决定“哪些 Token 值得在这一层被计算”。

2. **解决的问题不同**：
   * **MoE** 主要通过增加参数量来提升模型容量，同时通过稀疏激活控制推理时的计算成本。
   * **MoD** 旨在解决深度推理中的冗余问题。研究表明，并非所有 Token 都需要在每一层被处理，MoD 通过减少冗余计算来加速训练和推理，或者是在相同计算预算下训练更深的模型。

---



### 4: 使用 MoD 架构会对模型的训练稳定性产生什么影响？

4: 使用 MoD 架构会对模型的训练稳定性产生什么影响？

**A**: 引入 MoD 通常会带来训练稳定性方面的挑战，这主要源于路由机制的随机性。

1. **梯度中断**：由于大部分 Token 在某一层可能会跳过计算（仅通过恒等映射），这类似于随机深度的行为。虽然这有助于正则化，但如果跳过比例过高，可能导致梯度回流困难。
2. **路由噪声**：如果路由器的决策波动过大，模型可能难以收敛。

为了解决这些问题，论文中通常采用以下策略：
* **辅助损失**：类似于 MoE 中的负载均衡损失，确保路由器均匀地分配计算资源，防止所有 Token 都挤进同一个“计算槽位”。
* **平滑路由**：在训练初期使用较软的路由决策，或者在残差连接中保持一定的信息流，以确保深层网络能够有效学习。

---



### 5: 在推理阶段，MoD 能带来加速吗？还是说它主要用于训练效率提升？

5: 在推理阶段，MoD 能带来加速吗？还是说它主要用于训练效率提升？

**A**: 这是一个关键点。MoD 的加速效果取决于硬件的实现方式。

1. **理想情况（加速）**：如果硬件支持动态计算图或稀疏运算（例如专门设计的加速器），能够真正地“跳过”那些未被选中的 Token 的运算，那么 MoD 可以显著降低推理延迟，因为每一层的 FLOPs（浮点运算次数）确实减少了。
2. **实际情况（掩码）**：在标准的 GPU（如 NVIDIA A100/H100）上，由于 CUDA 核心通常针对密集矩阵运算进行了高度优化，处理不规则形状的稀疏数据（不同层选中的 Token 位置不同）可能会导致显存访问模式不连续。为了利用现有的高度优化的 FlashAttention，通常的做法是将未被选中的 Token“掩码”掉，但在底层可能仍需进行一定程度的填充或批处理。

因此，在通用硬件上，MoD 的主要优势往往在于**以相同的计算预算训练更深的模型**，从而获得更好的性能，或者是在**总计算量**上实现节约，而不一定能直接线性转化为端到端的推理速度提升。
