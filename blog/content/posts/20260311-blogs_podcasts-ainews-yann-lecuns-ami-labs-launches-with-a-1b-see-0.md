## 2. 关键技术要点

**涉及的关键技术或概念**
1.  **JEPA (Joint Embedding Predictive Architecture)：** 核心架构。与预测下一个 Token（离散空间）不同，JEPA 预测输入数据在潜在嵌入空间中的表征。
2.  **V-JEPA / I-JEPA：** 分别指视频和图像的联合嵌入预测架构，用于理解物理世界的因果关系。
3.  **World Models（世界模型）：** 一种内部模型，能够模拟环境的动态变化，预测行为的后果，从而辅助规划和推理。
4.  **Non-Generative AI（非生成式 AI）：** 该理念主张 AI 不一定需要生成像素或文本，而是生成抽象的理解和规划。

**技术原理和实现方式**
*   **原理：** 传统自回归模型（如 GPT）试图预测每一个细节（像素或词），计算成本高且易受噪声干扰。JEPA 试图在**高维抽象空间**进行预测。它不预测下一帧图像的每一个像素，而是预测下一帧图像的**特征向量**。
*   **实现：** 通过最大化输入数据（如当前视频帧）与未来数据在潜在空间中的互信息，同时忽略不相关的细节（如背景树叶的随机抖动），从而捕捉物理世界的本质规律（如物体的运动轨迹、碰撞逻辑）。

**技术难点和解决方案**
*   **难点：** 如何设计一个既能包含足够信息用于预测，又能过滤掉无关噪声的潜在空间？如何训练这种非生成式的模型？
*   **方案：** 使用 **I-JEPA**（Image Joint Embedding Predictive Architecture）进行掩码预测训练。引入 **EMD（Embedding Mismatch Distance）** 等损失函数，替代传统的生成损失（如 MSE Loss）。

**技术创新点分析**
主要的创新在于**“从像素级的精确预测转向语义级的一致性预测”**。这模仿了人类认知的过程：例如看到球滚向桌子，人类预测球会掉落，而不会精确预测球落地时每一粒灰尘的轨迹，即预测“掉落”这一物理事件的语义特征。
