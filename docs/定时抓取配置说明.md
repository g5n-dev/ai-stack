#### 1. GitHub Trending
```yaml

  enabled: true
  period: daily              # daily 或 weekly
  language: all             # all, python, javascript 等
  limit: 10                # 抓取数量
```

**调整选项**:
- `language`: 改为特定语言，如 `'python'`, `'javascript'`
- `period`: 改为 `'weekly'` 获取周榜
- `limit`: 增加/减少抓取数量

## 定时任务配置

### GitHub Actions Cron 表达式

**当前配置**:
```yaml
schedule:
  - cron: '0 2 * * *'
```

**时间说明**:
- UTC 时间：每天 02:00
- 北京时间：每天 10:00（UTC+8）
- 频率：每天一次

### Cron 表达式格式

```
分钟 小时 日期 月份 星期
*    *    *    *    *
```

**常用时间示例**:

| 表达式 | UTC 时间 | 北京时间 | 说明 |
|--------|---------|---------|------|
| `0 2 * * *` | 02:00 | 10:00 | 每天上午 10 点 |
| `0 6 * * *` | 06:00 | 14:00 | 每天下午 2 点 |
| `0 18 * * *` | 18:00 | 次日 02:00 | 每天凌晨 2 点 |
| `0 */6 * * *` | 每 6 小时 | 每 6 小时 | 一天 4 次 |
| `0 8,20 * * *` | 08:00, 20:00 | 16:00, 04:00 | 每天两次 |
| `0 2 * * 1` | 周一 02:00 | 周一 10:00 | 每周一 |

### 修改定时时间

编辑 `.github/workflows/daily-update.yml`:

```yaml
on:
  schedule:
    # 每天早上 8 点 UTC（北京时间 16:00）
    - cron: '0 8 * * *'
    # 或每天晚上 20 点 UTC（北京时间 04:00）
    - cron: '0 20 * * *'
  workflow_dispatch:
```

**注意事项**:
- GitHub Actions 最小间隔：5 分钟
- 多个 schedule 会在所有指定时间触发
- 修改后自动生效，无需手动触发

## 扩展其他数据源

### 添加 Reddit 数据源

1. 创建爬虫文件 `crawler/reddit.py`

```python
import requests
from typing import List, Dict

class RedditCrawler:
    def __init__(self, subreddit='programming', limit=5):
        self.subreddit = subreddit
        self.limit = limit

    def fetch(self) -> List[Dict]:
        url = f'https://www.reddit.com/r/{self.subreddit}/hot.json'
        response = requests.get(url, headers={'User-Agent': 'AI-Stack-Bot/1.0'})
        data = response.json()
        posts = []
        for post in data['data']['children'][:self.limit]:
            p = post['data']
            posts.append({
                'title': p['title'],
                'url': p['url'],
                'author': p['author'],
                'score': p['score'],
                'num_comments': p['num_comments'],
                'source': 'reddit',
            })
        return posts
```

2. 在 `config/sources.yaml` 添加配置

```yaml
reddit:
  enabled: true
  subreddits:
    - 'programming'
    - 'MachineLearning'
```

## 性能优化建议

### 1. API 限速和重试

```python
import time
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

def get_session_with_retries():
    session = requests.Session()
    retries = Retry(
        total=3,
        backoff_factor=1,
        status_forcelist=[500, 502, 503, 504]
    )
    adapter = HTTPAdapter(max_retries=retries)
    session.mount('http://', adapter)
    session.mount('https://', adapter)
    return session
```

### 2. 缓存机制

```python
import json
from datetime import datetime, timedelta
from pathlib import Path

class CacheManager:
    def __init__(self, cache_dir='cache', expire_hours=1):
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(exist_ok=True)
        self.expire_hours = expire_hours

    def get(self, key: str):
        cache_file = self.cache_dir / f'{key}.json'
        if not cache_file.exists():
            return None

        with open(cache_file) as f:
            data = json.load(f)

        cached_time = datetime.fromisoformat(data['timestamp'])
        if datetime.now() - cached_time > timedelta(hours=self.expire_hours):
            return None

        return data['content']

    def set(self, key: str, content):
        data = {
            'timestamp': datetime.now().isoformat(),
            'content': content
        }
        cache_file = self.cache_dir / f'{key}.json'
        with open(cache_file, 'w') as f:
            json.dump(data, f)
```

### 3. 并发爬取

```python
from concurrent.futures import ThreadPoolExecutor, as_completed

class CrawlerOrchestrator:
    def crawl_all(self) -> Dict:
        results = {}
        with ThreadPoolExecutor(max_workers=4) as executor:
            futures = {
                executor.submit(crawler.fetch): name
                for name, crawler in self.crawlers.items()
                if getattr(crawler, 'enabled', True)
            }

            for future in as_completed(futures):
                name = futures[future]
                try:
                    results[name] = future.result()
                except Exception as e:
                    logger.error(f"Failed to crawl {name}: {e}")
                    results[name] = []

        return results
```

## 故障排查

### 常见问题

**问题 1**: GitHub Actions 失败
- 检查 Secrets 是否正确配置
- 查看 Actions 日志中的错误信息
- 确认依赖项是否正确安装

**问题 2**: Hacker News 爬取失败
- 检查网络连接
- 确认 Hacker News API 状态（https://status.github.com/）
- 查看是否有 API 限速

**问题 3**: 定时任务未触发
- 确认 cron 表达式正确
- 检查仓库是否为 Public（Public 仓库才能免费使用 GitHub Actions）
- 查看 GitHub Actions 服务状态

**问题 4**: 文章未生成
- 检查爬虫返回的数据格式
- 查看 AI 处理步骤的日志
- 确认 `blog/content/posts/` 目录权限
